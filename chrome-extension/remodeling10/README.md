# 공실뉴스 리모델링 작성기 (remodeling10)

**건물 외관 리모델링 예측 시뮬레이터 + 공실뉴스 기사·블로그·유튜브 대본 작성기.**
유료회원(공실뉴스부동산·공실스터디부동산·비즈니스회원·최고관리자) 전용. API 를 쓰지 않고,
로그인해 둔 ChatGPT·Gemini 화면에 사진과 프롬프트를 넣어 결과를 가져온다.

기획: `docs/2026-09-28_remodeling_writer_extension_plan.md`
바탕: 공실뉴스 AI 기사 작성기(`chrome-extension/gongsilwriter20`) — 디자인·기사 전송·블로그·유튜브를 그대로 쓴다.


## v1.1.0 — 3번 탭 [블로그·SNS]: 페이스북 · 인스타그램 · 스레드

기사작성기 V30 의 SNS 를 옮겨 왔다 (`sns.js`, `shared/sns-prompt.js`, `shared/zip.js`, `shared/listing-source.js`). 다른 점:
- **유료회원 전용** (canRemodel) — 무료 체험 없음. 서버·DB 변경 없음.
- 글 끝에 늘 **"※ 공사 후 모습은 공실뉴스 리모델링 AI 예측 이미지이며 실제와 다를 수 있습니다."** — 예측 그림을 실제 모습으로 오해하지 않게.
- 예측 이미지(kind "ai", real 표시가 있어도)는 **AI 로 친다** → AI 레이블 안내, 대표(1번)는 현재 모습(실제 사진). 순서: 현재 모습 → 공사 후 예측.
- 출처: 공실뉴스 매물과 연결된 시뮬레이션이면 매물 링크 + 중개사무소 출처(표시·광고 필수 정보),
  아니면 공실뉴스 홈 링크 + "공실뉴스 리모델링 시뮬레이션" 출처 줄 ("매물"이라고 쓰지 않는다).
- AI 지시: 공사 후 모습·예상 공사비는 "예측"으로 쓰고, 시공 업체 추천·공사 권유 금지.

## 설치
1. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `remodeling10` 폴더 선택
3. 아이콘을 누르거나 **Alt+R** → 오른쪽 작업창이 열린다
4. `www.gongsilnews.com` 에 유료회원으로 로그인해 둔다 (기사 작성기와 함께 설치해도 된다)

## 흐름
```
1 · 시뮬레이션
   1단계 사진     [공실열람 페이지 이동] → [물건 가져오기]  또는  [사진 직접 올리기] → 최대 3장 고르기
   2단계 설계 조건 외장재·창호·색상·파사드·간판·조경·조명 / 버전 수 / 이미지 비율
   3단계 공사비 기준 전면 폭·층수·층고·외벽 면 → 예상 공사비 미리보기
   4단계 AI       Gemini(추천) / ChatGPT
   5단계          ① 설계 지시서 요청 ② 작성하기 ③ 지시서 가져오기
                  ④ 예측 이미지 요청(사진 자동 첨부) ⑤ 이미지 가져오기 — 버전 수만큼 ④⑤ 반복
   📋 결과표      [결과표 이미지 저장] [예측 이미지 저장] [이 결과로 기사 쓰기 →]
2 · 기사         ① AI 기사 작성 ② 작성하기 ③ 초안 보내기 → 다듬기 → 기사전송하기 (전·후 사진 포함)
3 · 블로그       결과표 + 기사로 네이버 블로그 글
4 · 유튜브       결과표 + 기사로 대본
```

## 파일
| 파일 | 내용 |
|---|---|
| `sim.js` · `sim.css` | 1 · 시뮬레이션 탭 |
| `panel.js` | 2 · 기사 탭 (기사 작성기 것, 원자료만 결과표) |
| `blog.js` · `youtube.js` | 3·4 탭 (원자료에 결과표를 더함) |
| `shared/remodel-spec.js` | 설계 조건 선택지 + 웹 시뮬레이터 프롬프트 원문 + 지시서 JSON 읽기 |
| `shared/remodel-cost.js` | 공사비 단가표(초안) + 계산 |
| `shared/remodel-sheet.js` | 결과표 한 장 그림(PNG) |
| `shared/remodel-prompt.js` | 결과표 → 기사·블로그·유튜브 지시문 |
| `shared/ai-common.js` | ChatGPT·Gemini 탭 조작 + **사진 첨부(GW_ATTACH)** |
| `shared/trial.js` | 권한 — 서버 `canRemodel` 하나로 가른다 (무료 체험 없음) |

## 공사비 단가 바꾸기
`shared/remodel-cost.js` 의 `RM_UNIT` 표만 고친다 (단위: 만 원). 결과표·기사·블로그·유튜브 모두 이 숫자를 쓴다.
모든 곳에 "대략적인 예상 공사비이며, 꼭 실질적인 확인이 필요합니다." 가 붙는다.

## 화면이 바뀌어 깨질 때
- ChatGPT·Gemini 입력칸·버튼: `shared/config.js`
- 사진 첨부: `shared/ai-common.js` 의 `attach()` — 붙여넣기 → 끌어다 놓기 → 숨은 파일칸 순서로 시도한다.
  모두 실패하면 작업창이 "사진을 AI 입력칸에 직접 끌어다 놓고 복사해 둔 프롬프트를 붙여넣으라"고 안내한다.
