### 3 · 블로그·SNS (v4.0.0)

3번 탭 위 선택 줄 `[블로그] [페이스북] [인스타] [스레드]`. 블로그는 `blog.js` 그대로, SNS 는 `sns.js`.

- **[AI SNS 3종 작성]** 한 번에 세 플랫폼 글을 받는다 (무료 체험 `sns` 1번 — 서버 `/api/extension/trial`).
  프롬프트·글 조립·사진 고르기 규칙은 `shared/sns-prompt.js` (테스트 `tests/sns-prompt.test.cjs`).
- 링크·출처(표시·광고 필수 정보)·해시태그는 AI 가 아니라 코드가 붙인다. 출처 문구는 블로그와 같다
  (`GWNaverBlog.sourceBlockLines`, 출처 API 는 `shared/listing-source.js` 를 블로그와 함께 쓴다).
- 사진: 2번 기사 사진을 플랫폼별로 다시 고른다 — 페이스북 1:1 최대 4장, 인스타 4:5 최대 10장, 스레드 원본 최대 4장.
  실제 사진이 있으면 AI 이미지는 1번(대표)이 될 수 없다. [복사·사진 받기]가 비율대로 잘라 `공실뉴스_인스타그램_01_대표.jpg` 식으로 내려받는다.
- 1단계는 **복사 + 바로가기**. 메타(페이스북·인스타·스레드) 글쓰기 화면에 자동으로 채우지 않는다 (계정 제한 위험).
- 상태는 `gw_sns_state`. 3번 탭의 [이 탭만 초기화]는 보고 있는 쪽(블로그 또는 SNS)만 지운다.
- [📋 복사]·[⬇ 받기]·[글·사진 받기] — 받기는 사진(비율대로 자름) + 글 TXT 를 ZIP 하나로 (`shared/zip.js`).
  AI 이미지·AI 영상이 섞이면 "게시할 때 AI 레이블을 켜세요" 안내.
- **영상 넣기는 블로그·SNS 모두 뺐다** (10월 03일). 버튼 이름("내 PC 영상")과 달리 업로드가 아니라 글 말투만 바꿔 헷갈렸고,
  사진 게시물에 "영상으로 보는…" 캡션이 올라가는 일이 실제로 생겼다. 영상을 올릴 때도 지금 글을 그대로 붙이고
  각 사이트에서 사진 대신 영상 파일만 고르면 된다. 블로그 영상은 네이버 편집기 자동 조작을 늘리지 않기 위해서도 뺐다.
  영상제작 프로그램(studio2)이 쇼츠까지 만들게 되면 "영상까지 한 번에" 흐름을 다시 설계한다.
- 아직: 인스타 표지(1번 사진 위 제목 한 줄) — 회의록 2-4.

**오른쪽 작업창이 주인이다.** 작업창은 한 번 열면 닫히지 않고, 탭을 옮겨도 떠 있다.
공실 매물을 가져와 · AI로 기사를 쓰고 · 작업창 안에서 다듬은 뒤 · 공실뉴스로 보낸다.
완성된 기사를 참조해 **별도 블로그 작성 탭**에서 네이버 블로그 초안도 만들 수 있다.

v3.0.0 부터 경매기사 작성기(auctionwriter20)를 합쳤고, **4 · 유튜브 대본** 탭을 더했다.

v3.0.1 — 2·3번 탭 하단 바를 콤팩트하게(한 줄 2칸, AI 이미지 설정은 [🎨 AI 이미지 만들기 ▾]를 눌러야 펼침).
새 초안이 오면 글 칸에 파란 테두리가 반짝이고 "🖱️ 마우스 휠을 아래로 내려서 글을 확인하세요" 안내가 뜬다 (`shared/dock-ui.js`).
버튼에 마우스를 올리면 "무엇을 하는지 · 언제 누르는지" 말풍선이 뜬다 — 문구는 `shared/tips.js` 의 `TIPS`.

v3.0.2 — [↺ 초기화 ▾]를 [이 탭만 초기화] / [전체 초기화]로 나눴다. 탭만 지워도 뒤 탭(블로그·대본)은 남고,
2번 탭은 초안·AI 사진만 지우고 가져온 물건은 남긴다. 설정(AI·스타일)은 어느 쪽이든 남는다.

- **일반 매물 / 경매·공매 자동 판별** — 1단계 [물건 가져오기] 때 서버(`/api/extension/auction-source`)에
  경매·공매 물건인지 묻는다. 경매·공매면 물건 정보를 서버에서 통째로 받고 `vacancy.saleKind`("경매"·"공매")가 붙는다.
  판별이 틀리면 1단계의 [일반 매물] / [경매·공매] 칩으로 직접 고른다.
- `saleKind` 가 있으면 기사·블로그·유튜브 대본·사진 설명·네이버 물건표·출처가 모두 경매용으로 바뀐다
  (`gwIsAuction`, `gwBlogStyles`, `gwYtVideoTypes`). 기사쓰기 폼에서는 섹션(공실뉴스 > 신축/분양/경매)까지 고른다.
- **4 · 유튜브 대본** — 공실뉴스 AI 유튜브작성기(youtubewriter10)의 3번 탭과 같은 기능 (장면·이미지는 넣지 않음).
  경매·공매 물건은 경매용 대본 지시문(`gwBuildYtAuctionScriptPrompt`)을 쓴다. 회원(`canYoutubeWriter`) 전용.

## 고장났을 때 어디를 보는가

이 확장은 **실패를 감추지 않는다.** 안 되면 작업창 위에 빨간 띠로 말한다.

| 작업창에 뜨는 말 | 원인 | 고칠 곳 |
|---|---|---|
| `탭과 연결되지 않았습니다` | 확장을 새로 로드한 뒤 그 탭을 새로고침하지 않았다 | 그 탭에서 F5 |
| `펼쳐 놓은 매물이 없습니다` | 공실열람에서 매물을 안 열었다 | 매물 클릭 |
| `매물 상세 표를 읽지 못했습니다` | 상세 표 구조가 바뀌었다 | `content-gongsil.js` 의 `collectFields` |
| `입력칸을 찾지 못했습니다` | ChatGPT·Gemini 화면이 바뀌었다 | `shared/config.js` 의 `INPUT` |
| `전송 버튼을 찾지 못했습니다` | 위와 같음 | `shared/config.js` 의 `SEND` |
| `AI 응답을 찾지 못했습니다` | 응답 말풍선 셀렉터가 바뀌었다 | `shared/config.js` 의 `ANSWER` |
| `JSON 을 찾지 못했습니다` | AI 가 형식을 안 지켰다 | AI 탭에서 "JSON 으로 다시" 요청 후 ③ 다시 |
| `기사작성 폼을 찾지 못했습니다` | 폼 placeholder 가 바뀌었다 | `shared/config.js` 의 `ADMIN` |
| `먼저 공실뉴스에 로그인하고 새 기사쓰기 화면을 열어 주세요` | 같은 창에 신규 기사쓰기 탭이 없다 | 로그인 후 [기사쓰기] 화면 열기 |
| `기사쓰기 탭을 새로고침(F5)한 뒤 다시 눌러 주세요` | 확장을 다시 로드한 뒤 열린 탭이 이전 확장과 연결돼 있다 | 기사쓰기 탭에서 F5 |
| `네이버 블로그 제목 또는 본문 입력칸을 찾지 못했습니다` | 네이버 SmartEditor ONE 화면이 바뀌었거나 아직 로딩 중이다 | 새 글쓰기 화면에서 F5 후 다시 전송 |
| `네이버 글쓰기 화면에 이미 내용이 있습니다` | 기존 글을 실수로 덮지 않도록 전송을 멈췄다 | 빈 새 글쓰기 화면을 열고 다시 전송 |

## 매물 정보를 더 정확하게 (다음 작업)

지금은 상세 표를 통째로 읽는다(라벨 이름을 찍지 않으므로 항목이 늘어도 따라온다).
다만 **사람 보라고 그린 표**라, 표 구조 자체가 바뀌면 틀어진다.

`GongsilDetailPanel.tsx` 의 `#detail-scroll-container` 에 이미 `data-vacancy-id` 와
`data-images` 가 붙어 있다. 같은 자리에 한 칸만 더 얹으면 긁기를 그만둘 수 있다.

```tsx
data-article-source={JSON.stringify({
  vacancyId, title, priceText,
  fields: [{ label, value }, ...],
  themes: [...], infra: "지하철: … / 학교: …",
})}
```

확장은 이 값이 있으면 **그것만 쓴다** (`content-gongsil.js` 의 `collectVacancy`).
없으면 지금처럼 표를 읽으므로, 사이트를 먼저 고치지 않아도 돌아간다.
