## 3. 웹스토어 상세 설명 (Detailed Store Listing Description)
```text
공실뉴스 회원을 위한 AI 부동산 기사·블로그·SNS·유튜브 대본 작성 도구입니다.
공실열람의 일반 매물과 경매·공매 물건을 자동으로 구분해, 물건에 맞는 전문 기사와 멀티채널 마케팅 콘텐츠(블로그, 페이스북, 인스타그램, 스레드, 유튜브)를 한 번에 만들어 줍니다.

[주요 기능]
1. 공실열람 매물·경매·공매 물건 원클릭 수집
   - 일반 매물과 경매·공매 물건 자동 판별 및 주변 환경 데이터까지 완벽 연동
2. ChatGPT · Gemini 연동 부동산 보도 기사 작성
   - 사실에 기반한 전문 부동산 기사 초안 생성
   - 공실뉴스 기사쓰기 화면 원클릭 자동 입력 및 대표 사진 자동 지정
3. 네이버 블로그 초안 작성 및 서식 자동 맞춤
   - 6가지 전문 문체(기본형, 브리핑형, 매거진형, 스토리텔링형, Q&A형, 뉴스기사형)
   - 네이버 스마트에디터 원클릭 전송 및 매물표·출처 자동 완성
4. SNS 3종(페이스북 · 인스타그램 · 스레드) 동시 발행 지원
   - 플랫폼별 글자 수 규격, 해시태그, 법적 표시·광고 필수 출처 자동 부착
   - 채널 규격에 맞춘 사진 최대 10장 자동 선별 및 비율 변환
   - 글과 사진을 한 번에 내려받는 원클릭 ZIP 패키지 다운로드 지원
5. 유튜브 내레이션 대본 작성
   - 매물 소개·부동산 뉴스·지역 입지 분석
   - 60초 쇼츠(Shorts)부터 5분 롱폼 영상까지 맞춤형 대본 완성
6. 경매·공매 물건 전용 특화 모드
   - 감정가·최저입찰가·유찰 횟수·입찰 일정 중심의 팩트 기반 전용 기사·블로그·SNS·대본
7. AI 실사 & 맞춤 화풍 이미지 생성
   - 원하는 스타일(실사, 일러스트, 수채화 등)을 자유롭게 입력하여 기사와 SNS에 어울리는 이미지 즉시 생성

[이용 안내]
- 기사 작성은 누구나 무료로 사용할 수 있습니다.
- 블로그·SNS 작성과 유튜브 대본은 공실뉴스 회원이면 매월 무료로 체험할 수 있으며,
  공실스터디부동산 회원은 제한 없이 사용할 수 있습니다.
```
