# 공실뉴스 AI 기사작성기 (gongsilwriter10)

**오른쪽 작업창이 주인이다.** 작업창은 한 번 열면 닫히지 않고, 탭을 옮겨도 떠 있다.
공실 매물을 가져와 · AI로 기사를 쓰고 · 작업창 안에서 다듬은 뒤 · 공실뉴스로 보낸다.
완성된 기사를 참조해 **별도 블로그 작성 탭**에서 네이버 블로그 초안도 만들 수 있다.

---

## 흐름

```
확장 아이콘 클릭 (또는 Alt+G)
   ↓
[작업창] 열림 ── 닫히지 않는다
   ↓
① [공실열람 페이지 이동]   →  gongsilnews.com/gongsil
② [물건 가져오기]          →  펼쳐 놓은 매물 + 주변환경까지
③ ChatGPT / Gemini 선택
④ [AI 기사 작성]           →  AI 탭이 열리고 프롬프트가 채워진다
⑤ [작성하기]               →  전송을 눌러 AI가 글을 쓴다
⑥ [초안 보내기]            →  ★ 작업창 안에 기사 미리보기로 뜬다
   ↓
⑦ 작업창에서 다듬는다 (몇 번이고)
     · 제목·부제·본문을 직접 타이핑
     · [수정 요청] → 같은 대화에 이어서 AI에게
     · 본문 사진의 [대표지정] → 기사 대표 이미지 변경
     · 이미지 스타일 선택 + 기사 일부나 추가 요청 입력
     · [AI 이미지 만들기] / [이미지 삽입]
     · Gemini JSON 줄바꿈·괄호 오류는 초안 전송 때 자동 복구
   ↓
⑧ [기사작성바로가기 >>]    →  공실뉴스 부동산회원 기사쓰기 화면을 새 탭으로 연다
⑨ [기사전송하기]           →  같은 창에 열어 둔 새 기사쓰기 폼에 바로 입력
                               로그인 회원의 기자명으로 선택한 대표 이미지와 초안 자동 입력
                               ★ [기사 등록] 은 사람이 누른다
   ↓
⑩ [3 · 블로그 작성]        →  완성된 기사를 참조하되 기사 원문은 변경하지 않는다
⑪ 스타일 6종 + 분량 3종 선택
⑫ [AI 블로그 초안 작성]    →  별도 AI 탭에서 블로그 글을 작성한다
⑬ [완성 글 가져오기]       →  블로그 전용 미리보기에서 제목·본문을 확인한다
⑭ 수정 요청 · AI 이미지 만들기 · 이미지 삽입
⑮ [글쓰기]                 →  네이버 블로그 새 글쓰기 화면을 연다
⑯ [블로그글 전송하기]      →  제목·본문을 채운다. 최종 발행은 사람이 누른다
```

**④⑤⑥을 한 버튼으로 묶지 않은 이유** — 사이사이 사람이 눈으로 확인할 자리를 둔다.
옛 확장에서 에러가 가장 잦던 곳이 *화면이 준비되기 전에 다음 단계로 넘어가는 지점*이었다.

---

## 파일

| 파일 | 하는 일 |
|---|---|
| `panel.html` `panel.css` `panel.js` | **작업창.** 판단·상태·화면 전부 여기 |
| `blog.js` `shared/blog-prompt.js` | **블로그 작성 탭.** 기사 초안과 분리된 상태·프롬프트·이미지 |
| `background.js` | 작업창 열기 + 같은 창의 새 기사쓰기 탭에 초안 전달 |
| `content-gongsil.js` | `GW_GET_VACANCY` 하나에만 답한다 |
| `content-chatgpt.js` `content-gemini.js` | 고유 사정만. 실제 동작은 `ai-common.js` |
| `content-admin.js` | 기사쓰기 폼 자동 입력 |
| `content-naver.js` `shared/naver-blog.js` | 네이버 새 글쓰기 화면 확인 + 제목·본문 자동 입력 |
| `shared/config.js` | **셀렉터·저장 키 전부.** 깨지면 여기만 고친다 |
| `shared/prompt.js` | **기사 기본틀 전부.** 작성·수정요청·이미지 세 가지 |
| `shared/ai-common.js` | `GW_FILL` `GW_SUBMIT` `GW_READ` `GW_GET_IMAGE` |
| `shared/ui.js` | React 입력칸 채우기, 토스트 (콘텐츠 스크립트용) |

페이지들은 시키는 일만 한다. **버튼과 모달을 페이지에 심지 않는다.**

## 설치

1. `chrome://extensions` → **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더

```text
C:\Users\user\Desktop\gongsilnews\chrome-extension\gongsilwriter10
```

3. 고칠 때마다 카드의 **새로고침(🔄)**

> **옛 `gongsilwriter` 는 꺼 두십시오.** 같이 켜면 어느 쪽이 도는지 알 수 없습니다.

### 돌고 있는지 확인

공실열람 페이지에서 **F12 → Console** 에 파란 딱지가 떠야 한다.

```
공실뉴스 AI 기사작성기 v2.1.1  붙었습니다 · ...
```

## 고장났을 때 어디를 보는가

이 확장은 **실패를 감추지 않는다.** 안 되면 작업창 위에 빨간 띠로 말한다.

| 작업창에 뜨는 말 | 원인 | 고칠 곳 |
|---|---|---|
| `탭과 연결되지 않았습니다` | 확장을 새로 로드한 뒤 그 탭을 새로고침하지 않았다 | 그 탭에서 F5 |
| `펼쳐 놓은 매물이 없습니다` | 공실열람에서 매물을 안 열었다 | 매물 클릭 |
| `매물 상세 표를 읽지 못했습니다` | 상세 표 구조가 바뀌었다 | `content-gongsil.js` 의 `collectFields` |
| `입력칸을 찾지 못했습니다` | ChatGPT·Gemini 화면이 바뀌었다 | `shared/config.js` 의 `INPUT` |
| `전송 버튼을 찾지 못했습니다` | 위와 같음 | `shared/config.js` 의 `SEND` |
| `AI 응답을 찾지 못했습니다` | 응답 말풍선 셀렉터가 바뀌었다 | `shared/config.js` 의 `ANSWER` |
| `JSON 을 찾지 못했습니다` | AI 가 형식을 안 지켰다 | AI 탭에서 "JSON 으로 다시" 요청 후 ③ 다시 |
| `기사작성 폼을 찾지 못했습니다` | 폼 placeholder 가 바뀌었다 | `shared/config.js` 의 `ADMIN` |
| `먼저 공실뉴스에 로그인하고 새 기사쓰기 화면을 열어 주세요` | 같은 창에 신규 기사쓰기 탭이 없다 | 로그인 후 [기사쓰기] 화면 열기 |
| `기사쓰기 탭을 새로고침(F5)한 뒤 다시 눌러 주세요` | 확장을 다시 로드한 뒤 열린 탭이 이전 확장과 연결돼 있다 | 기사쓰기 탭에서 F5 |
| `네이버 블로그 제목 또는 본문 입력칸을 찾지 못했습니다` | 네이버 SmartEditor ONE 화면이 바뀌었거나 아직 로딩 중이다 | 새 글쓰기 화면에서 F5 후 다시 전송 |
| `네이버 글쓰기 화면에 이미 내용이 있습니다` | 기존 글을 실수로 덮지 않도록 전송을 멈췄다 | 빈 새 글쓰기 화면을 열고 다시 전송 |

## 매물 정보를 더 정확하게 (다음 작업)

지금은 상세 표를 통째로 읽는다(라벨 이름을 찍지 않으므로 항목이 늘어도 따라온다).
다만 **사람 보라고 그린 표**라, 표 구조 자체가 바뀌면 틀어진다.

`GongsilDetailPanel.tsx` 의 `#detail-scroll-container` 에 이미 `data-vacancy-id` 와
`data-images` 가 붙어 있다. 같은 자리에 한 칸만 더 얹으면 긁기를 그만둘 수 있다.

```tsx
data-article-source={JSON.stringify({
  vacancyId, title, priceText,
  fields: [{ label, value }, ...],
  themes: [...], infra: "지하철: … / 학교: …",
})}
```

확장은 이 값이 있으면 **그것만 쓴다** (`content-gongsil.js` 의 `collectVacancy`).
없으면 지금처럼 표를 읽으므로, 사이트를 먼저 고치지 않아도 돌아간다.
