# 공실뉴스 인테리어 작성기 (interior10)

**아파트 내부 인테리어 예측 시뮬레이터 + 공실뉴스 기사·블로그·유튜브 대본 작성기.**
유료회원(공실뉴스부동산·공실스터디부동산·비즈니스회원·최고관리자) 전용. API 를 쓰지 않고,
로그인해 둔 ChatGPT·Gemini 화면에 사진과 프롬프트를 넣어 결과를 가져온다.

바탕: 공실뉴스 리모델링 작성기(`chrome-extension/remodeling10`)를 그대로 복사했다. 흐름·디자인·기사 전송·블로그·유튜브가 같고,
시뮬레이션 대상만 **건물 외관 → 아파트 실내**로 바꿨다.
프롬프트 원본: 웹 시뮬레이터 `marketing/home-interior` 에서 옮겨 왔다. 웹 시뮬레이터는 2026-10-01 삭제했고, 이제 `shared/interior-spec.js` 가 원본이다.


## v1.1.0 — 3번 탭 [블로그·SNS]: 페이스북 · 인스타그램 · 스레드

기사작성기 V30 의 SNS 를 옮겨 왔다 (`sns.js`, `shared/sns-prompt.js`, `shared/zip.js`, `shared/listing-source.js`). 다른 점:
- **유료회원 전용** (canRemodel) — 무료 체험 없음. 서버·DB 변경 없음.
- 글 끝에 늘 **"※ 공사 후 모습은 공실뉴스 인테리어 AI 예측 이미지이며 실제와 다를 수 있습니다."** — 예측 그림을 실제 모습으로 오해하지 않게.
- 예측 이미지(kind "ai", real 표시가 있어도)는 **AI 로 친다** → AI 레이블 안내, 대표(1번)는 현재 모습(실제 사진). 순서: 현재 모습 → 공사 후 예측.
- 출처: 공실뉴스 매물과 연결된 시뮬레이션이면 매물 링크 + 중개사무소 출처(표시·광고 필수 정보),
  아니면 공실뉴스 홈 링크 + "공실뉴스 인테리어 시뮬레이션" 출처 줄 ("매물"이라고 쓰지 않는다).
- AI 지시: 공사 후 모습·예상 공사비는 "예측"으로 쓰고, 시공 업체 추천·공사 권유 금지.

## 설치
1. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `interior10` 폴더 선택
3. 아이콘을 누르거나 **Alt+I** → 오른쪽 작업창이 열린다
4. `www.gongsilnews.com` 에 유료회원으로 로그인해 둔다 (기사 작성기·리모델링 작성기와 함께 설치해도 된다)

## 흐름
```
1 · 시뮬레이션
   1단계 사진       [공실열람 페이지 이동] → [물건 가져오기]  또는  [사진 직접 올리기] → 최대 3장 고르기
   2단계 인테리어 조건 공간 유형(하나) · 스타일 · 천장 · 바닥재 · 벽면 · 가구 톤 · 조명 / 이미지 비율
   3단계 공사비 기준  공간 바닥 면적(m²) · 천장 높이 → 예상 공사비 미리보기
   4단계 AI         ChatGPT(추천) / Gemini
   5단계            ① 설계 지시서 요청 ② 작성하기 ③ 지시서 가져오기
                    ④ 예측 이미지 요청(사진 자동 첨부) ⑤ 이미지 가져오기
   📋 결과표        [결과표 이미지 저장] [예측 이미지 저장] [이 결과로 기사 쓰기 →]
2 · 기사           ① AI 기사 작성 ② 작성하기 ③ 초안 보내기 → 다듬기 → 기사전송하기 (전·후 사진 포함)
3 · 블로그         결과표 + 기사로 네이버 블로그 글
4 · 유튜브         결과표 + 기사로 대본
```

| `shared/interior-cost.js` | 공사비 단가표(초안) + 계산 |
| `shared/interior-sheet.js` | 결과표 한 장 그림(PNG) |

코드 안의 함수·변수 이름(`rm…`, `RM_…`, `S.remodel`, `rm:result`)은 리모델링 작성기와 같게 두었다.
두 확장을 나란히 고치기 쉽게 하려는 것이다. 저장소(chrome.storage)는 확장마다 따로라 겹치지 않는다.

## 프롬프트 원칙
- 웹 시뮬레이터 프롬프트 원문은 **글자·공백 하나 바꾸지 않는다.** 채팅 화면용 문장은 원문 **뒤에만** 덧붙인다.
  - 프롬프트 1 뒤: 스키마(웹의 responseSchema 를 글로), "imagePrompt 에 카메라·시점을 쓰지 말 것", "JSON 하나만 출력"
  - 프롬프트 2 뒤: "첨부한 방 사진을 고칠 것 — 같은 카메라 위치·각도·구도, 창·문·벽 위치 유지", "지금 이미지를 만들 것"
- 버전 수는 1개로 고정, 이미지 비율 기본값은 **원본(같은 구도)** — 리모델링 작성기에서 정한 것과 같다.

## 공사비 단가 바꾸기
`shared/interior-cost.js` 의 `RM_UNIT` 표만 고친다 (단위: 만 원). 결과표·기사·블로그·유튜브 모두 이 숫자를 쓴다.
```
바닥   = 바닥 면적 × 바닥재 단가(여러 개면 평균)
벽     = 4√면적 × 천장 높이 × (1 − 창·문 25%) × 벽 마감 단가
천장   = 바닥 면적 × 천장 단가
조명   = 고른 조명 한 공간당 금액 합
설비   = 욕실(방수·도기·수전) · 주방(싱크대·상판) · 현관(중문·신발장) 한 건
철거·폐기물·보양 = 위 합계 × 15~25%   → 10만 원 단위 반올림
```
가구·가전·소품 구입비와 부가세·설계비는 넣지 않는다.
모든 곳에 "대략적인 예상 공사비이며, 꼭 실질적인 확인이 필요합니다." 가 붙는다.

## 화면이 바뀌어 깨질 때
- ChatGPT·Gemini 입력칸·버튼: `shared/config.js`
- 사진 첨부: `shared/ai-common.js` 의 `attach()` — 붙여넣기 → 끌어다 놓기 → 숨은 파일칸 순서로 시도한다.
  모두 실패하면 작업창이 "사진을 AI 입력칸에 직접 끌어다 놓고 복사해 둔 프롬프트를 붙여넣으라"고 안내한다.
