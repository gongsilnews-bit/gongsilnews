# 공실뉴스 AI 유튜브작성기

공실뉴스 기사·매물 또는 직접 입력한 자료로 장면별 유튜브 대본과 이미지를 만드는 독립 Chrome 확장 프로그램입니다. 기존 `gongsilwriter10`과 저장 공간 및 화면을 공유하지 않습니다.

## 현재 범위

- 공실뉴스부동산, 공실스터디부동산, 최고관리자 권한 확인
- 공실뉴스 기사·공실 매물·직접 입력 자료 가져오기
- ChatGPT 또는 Gemini를 이용한 장면별 대본 생성·수정
- 장면 길이 `짧게 / 중간 / 길게`와 영상 길이에 따른 가변 장면 수
- 기사·매물 실제 이미지 우선 연결
- 장면별 AI 이미지 생성, 직접 교체, 이전 후보 복원, 삭제
- 여러 이미지를 파일명 또는 자연 정렬 순서로 장면에 일괄 삽입
- 한국형 이미지 스타일 7종과 프리미엄 PPT 렌더링
- 썸네일 문구·배경 제작 및 이미지 다운로드
- 프로젝트 메타데이터와 원본 이미지의 브라우저 로컬 복원

AI 음성, 영상 렌더링, 유튜브 자동 업로드는 이번 범위에 포함하지 않습니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `chrome-extension/youtubewriter10` 폴더를 선택합니다.
5. 공실뉴스와 사용할 AI 사이트(ChatGPT 또는 Gemini)에 로그인합니다.
6. 확장 아이콘 또는 `Alt+Y`로 사이드패널을 엽니다.

## 사용 순서

1. `1 자료`에서 기사·매물을 연 뒤 `열린 페이지에서 가져오기`를 누르거나 직접 내용을 입력합니다.
2. `2 대본`에서 영상·장면 설정을 고르고 AI에 대본 작성을 요청합니다.
3. AI 응답이 끝나면 `완성 대본 가져오기`로 장면을 불러와 필요한 내용을 수정합니다.
4. `3 이미지`에서 실제 사진을 확인하고, 비어 있는 장면을 AI 생성 또는 직접 삽입으로 채웁니다.
5. 완성된 장면 이미지와 썸네일을 내려받습니다.

## 주의

- AI 사이트의 화면 구조가 바뀌면 입력·응답 선택자를 조정해야 할 수 있습니다.
- 생성 이미지에는 정확한 한글을 직접 그리게 하지 않고, PPT·썸네일 문구는 확장프로그램에서 별도 합성합니다.
- 이미지 생성은 AI 사이트에서 선택한 계정의 사용량과 정책을 따릅니다.
