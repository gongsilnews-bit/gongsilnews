# 공실뉴스 매물기사초안 V1.0 (크롬 확장프로그램)

> **유료 API 결제 0원! 구글 로그인 연동 & 무료/유료 차등 서비스 탑재!**  
> 크롬 브라우저에 이미 로그인되어 있는 **ChatGPT(`chatgpt.com`)**와 **Gemini(`gemini.google.com`)**를 그대로 활용하여,  
> 웹서핑 중 클릭 한 번으로 **공실뉴스 정식 기사(나레이션 대본/정통분석)**와 **네이버 블로그 원고**를 생성하고,  
> 발행 전에 **스마트폰(모바일)·PC·네이버 블로그 실시간 미리보기**로 글과 사진을 완벽 검토한 뒤 **1초 만에 자동 발행**합니다.

---

## 🌟 핵심 신규 기능 (Dual System & Live Preview)

### 1. 🔄 기사 & 블로그 듀얼 모드 (Dual System)
- **📰 공실뉴스 정식 기사 모드**:
  - 🎙️ **방송 나레이션 대본형**: 소제목 없는 1~2줄 단위 존댓말 대본체 (쇼츠, 릴스, TTS 낭독 최적화)
  - 📰 **정통 신문 분석형**: 경제 전문기자 평서체 + 3대 맞춤 소제목 + `[■ 공실뉴스 시장전망 & 체크포인트]`
- **📝 네이버 블로그 원고 모드**:
  - ✨ 친근한 대화체 칼럼 + 시각적 이모지(✨, 🏢, 📌, 💡)
  - 3줄 요약 불릿포인트 + 인용구 박스(`"..."`)
  - 하단 네이버 검색 최적화 추천 해시태그 10개

### 2. 👁️ 전송/발행 전 [글·사진 실시간 미리보기] (Live Visual Preview)
- 📱 **모바일 뷰 (375px 아이폰 프레임)**: 스마트폰 화면에서 제목 줄바꿈과 자막 가독성 100% 동일 검토
- 💻 **PC 데스크탑 뷰**: 웹사이트 기사 상세 페이지 레이아웃
- 📗 **네이버 블로그 뷰**: 실제 네이버 블로그 모바일 앱과 동일한 초록색 테마 및 프로필 프리뷰
- **📷 16:9 사진 검토 & 교체**:
  - DALL-E 3 / Imagen 3로 생성된 고화질 한국형 보도사진(16:9) 및 캡션 즉시 확인
  - `[📷 사진 교체/업로드]` 버튼으로 원하는 사진 직접 업로드 가능
  - 제목, 부제, 캡션, 본문 실시간 직접 수정 지원

### 3. 🔐 구글 로그인 & 무료/유료 회원 차등 서비스 (BM 연동)
- 공실뉴스 웹사이트의 **Supabase 구글 로그인**과 완벽 연동
- **🥉 무료 회원**: 1일 3~5회 생성, 기본 텍스트 복사, 네이버 블로그 초안 작성
- **👑 유료 회원 (공실뉴스부동산 / 관리자)**:
  - 무제한 작성 + 롱폼 심층 리포트
  - **공실뉴스 메인 실시간 원클릭 자동 발행**
  - **16:9 AI 실사 보도사진 자동 생성**
  - **네이버 스마트에디터 ONE 서식 100% 보존 복사**

### 4. 🚀 원클릭 파이프라인 액션
- **`[🚀 공실뉴스 실시간 자동 발행]`**:
  - 버튼 클릭 시 공실뉴스 백엔드(`/api/extension/publish`)를 통해 DB에 `status: 'APPROVED'`로 즉시 저장
  - 메인 뉴스 및 모바일 뉴스에 1초 만에 실시간 노출!
- **`[📋 네이버 스마트에디터 ONE 서식 복사]`**:
  - Rich HTML 포맷으로 클립보드에 복사되어, 네이버 블로그 글쓰기 창에서 `Ctrl + V` 한 번으로 폰트, 볼드, 인용구, 이모지가 깨짐 없이 쏙 들어감!

## 🛠️ 10초 만에 크롬에 설치/업데이트하는 방법

1. 크롬 브라우저를 열고 주소창에 아래 주소를 입력하고 엔터를 칩니다:
   ```text
   chrome://extensions
   ```
2. 우측 상단의 **[개발자 모드]** 스위치를 **ON(켜기)** 합니다.
3. 이미 로드되어 있다면 **[공실뉴스 매물기사초안 V1.0]** 카드의 **새로고침(🔄)** 아이콘을 클릭합니다.  
   *(처음 설치하시는 경우 좌측 상단 [압축해제된 확장 프로그램을 로드합니다] 클릭 후 아래 폴더 선택)*
   ```text
   c:\Users\user\Desktop\gongsilnews\chrome-extension
   ```
4. 크롬 우측 상단 퍼즐 조각(🧩)을 눌러 고정(📌)해 두시면 됩니다.
5. 단축키: 언제 어디서나 **`Alt + G`**를 누르면 사이드패널이 즉시 열립니다!

## 💡 사용 시나리오 예시

1. 네이버 뉴스나 부동산 매물 페이지에서 **`Alt + G`**를 누릅니다.
2. **`[현재 공실 물건 정보 가져오기]`** 클릭 ➡️ 현재 공실 물건 정보를 자동 추출!
3. 발행 목적 선택:
   - **`[📰 공실뉴스 정식 기사]`** 선택 시 ➡️ 나레이션 대본형 or 정통 신문형
   - **`[📝 네이버 블로그 원고]`** 선택 시 ➡️ 네이버 블로그형
4. **`[🚀 AI 자동 작성 & 실시간 미리보기]`** 클릭:
   - 챗GPT / 제미나이 웹에서 글과 16:9 실사 사진 동시 렌더링
   - 1.5초 후 **`[👁️ 2. 글·사진 실시간 미리보기]`** 탭으로 자동 전환!
5. 스마트폰 화면으로 사진과 본문을 눈으로 쓱 훑어보고:
   - 기사 모드: **`[🚀 공실뉴스 실시간 자동 발행]`** 클릭 ➡️ 공실뉴스 메인에 즉시 발행 완료! 🎉
   - 블로그 모드: **`[📋 네이버 스마트에디터 ONE 서식 복사]`** 클릭 ➡️ 네이버 블로그에 `Ctrl + V` 붙여넣기 끝! ✨
