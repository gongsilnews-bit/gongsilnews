# 스튜디오 영상 편집기 — 타임라인(캡컷식) 편집 추가 회의

- 날짜: 2026-10-17
- 대상: 공실뉴스 스튜디오 [동영상제작] 편집기
- 상태: 회의 중 (사장님 결정 대기 항목 있음) — **7-1에서 "처음에 방식 고르기, 교차 없음"으로 변경 결정**
- 이어받는 문서: `docs/2026-10-15_studio_video_editor_plan.md` (브루식 편집기 계획)

## 1. 안건

편집기에서 브루 스타일(글로 편집)도 하고, 캡컷 스타일(타임라인 편집)도 할 수 있게 하려면 어떻게 할까?

## 2. 결론

**편집기를 두 개 만들지 않는다. 한 프로젝트를 두 가지 보기로 편집한다.**

- 편집 화면 위 전환 단추: **[글로 편집]** (지금의 브루식) ↔ **[타임라인 편집]** (캡컷식)
- 데이터는 하나. 글에서 문장을 지우면 타임라인도 잘리고, 타임라인에서 자르면 글 쪽 클립도 나뉜다.
- 편집 중 언제든 오갈 수 있다. (말은 글로 다듬고, 사진·효과·음악은 타임라인에서 맞추는 식)
- 미리보기·굽기(내보내기)는 지금 것을 그대로 쓴다.

## 3. 근거 — 지금 구조가 이미 절반은 캡컷

- **클립 목록** = 순서대로 이어 붙는 영상 줄 → 캡컷의 "메인 트랙"과 같은 개념.
- **레이어**(음악·사진·화면 글자) = "몇 번 클립부터 몇 번 클립까지"에 붙음 (`src/components/admin/studio-video/types.ts` 의 `Layer`).
- 따라서 타임라인 화면은 이 데이터를 가로 막대로 그리는 것부터 시작할 수 있다.

### 캡컷에 있고 지금 없는 것

| 없는 것 | 해결 방법 |
|---|---|
| 레이어를 아무 시각에나 놓기 | 레이어 위치를 "시작 클립 + 몇 초 뒤 + 길이"로 저장. 앞에서 글을 지우면 레이어도 따라 움직임 (브루식 장점 유지) |
| 여러 줄(트랙)에 겹쳐 놓기 | 레이어마다 줄 번호 추가 |
| 영상 위 영상 겹치기(PIP), 효과음 줄 | 레이어 종류에 "영상", "효과음" 추가 |

## 4. 진행 순서

1. **1단계 — 타임라인 보기 화면**: 큰 미리보기 + 아래 큰 타임라인(클립 썸네일·소리 파형·레이어 줄) + 오른쪽 설정 칸. 데이터는 그대로, 보여 주기·선택·재생만.
2. **2단계 — 타임라인 조작**: 재생 위치에서 자르기, 클립 끝 다듬기, 순서 바꾸기, 레이어 옮기기·늘이기, 확대·축소, 자석 붙이기.
   - 60세 원칙: 끌기만으로 되게 하지 않는다. 늘 보이는 단추 **[여기서 자르기] [앞 다듬기] [뒤 다듬기]** 함께.
3. **3단계 — 데이터 넓히기**: 초 단위 레이어 위치, 여러 줄, 영상 겹치기, 효과음 줄.
4. **4단계 (나중)**: 키프레임(시간별 움직임 지정), 속도 곡선 등 고급 기능.

## 5. 주의할 점

- 타임라인에서 말하는 도중을 자르면 단어가 반쯤 잘린다 → 자를 때 **가장 가까운 단어 경계에 자동으로 붙게**(기본 켜짐). 정밀하게 자를 때만 끈다. 이렇게 해야 글 보기와 어긋나지 않는다.

## 6. 사장님 결정 대기

- [ ] 1단계 바로 시작 여부

## 7. 이어서 논의할 것

### 7-1. [변경 결정] 교차 없이 처음에 방식을 고른다 (사장님, 2026-10-17)

> 위 2~5장의 "한 프로젝트 두 보기(교차 가능)" 안은 **폐기**. 아래로 대체.

- 새로 만들 때 **[텍스트식 (브루)]** 또는 **[타임라인식 (캡컷)]** 중 하나를 고른다.
- 한번 고르면 그 프로젝트는 끝까지 그 방식으로만 편집한다. 교차 없음.
- 이유: 안전. 단어 기준 편집과 초 기준 편집을 계속 맞출 필요가 없어 버그 위험이 작고, **지금 잘 되는 브루식 편집기를 건드리지 않는다.**

**같이 쓰는 것 (두 번 만들지 않기)**: 미리보기 그리기, 굽기(내보내기), 자료함, 글꼴·자막 서식, 애니메이션·효과음, 화면전환, AI 목소리, 저장·최근 프로젝트 목록.

**따로인 것**: 편집 화면, 프로젝트 데이터 모양. 프로젝트 파일에 방식(텍스트식/타임라인식)을 적고, 열 때 맞는 편집 화면을 띄운다. 최근 목록에 방식 표시.

**타임라인식 규칙 (캡컷과 같게)**
- 모든 것을 초 단위로. 아무 데서나 자르고, 아무 줄에나 놓는다.
- 자막: [자동 자막] 단추로 말소리를 받아써서 자막 줄에 블록으로 깐다. 이후 블록을 따로 옮기고 늘일 수 있다.
- 60세 원칙은 그대로: 끌기 + 늘 보이는 단추 [여기서 자르기] [앞 다듬기] [뒤 다듬기].

**나중에 검토 (지금 범위 아님)**: 텍스트식 프로젝트를 "타임라인식 복사본으로 내보내기" (한 방향, 원본은 그대로).

### 7-2. [결정] 캡컷식은 캡컷, 텍스트식은 브루 — 키프레임은 기본 기능 (사장님, 2026-10-17)

- **텍스트식 = 지금 편집기 그대로 (브루)**, **타임라인식 = 캡컷 그대로 (캡컷)**.
- 쓸 수 있는 부품은 같이 쓴다. 하지만 편집 방식은 각자 원래 프로그램을 따른다 — 한쪽을 다른 쪽 규칙에 맞추지 않는다.
- 캡컷식의 장점은 **키프레임**과 **컷 편집**. 그래서 키프레임은 "나중(4단계)"이 아니라 **기본 기능**으로 올린다.

**컷 편집**: 재생 위치에서 자르기, 앞·뒤 다듬기, 빈칸 자동 붙이기(자석), 여러 줄 겹치기(영상·사진·글자), 프레임 단위 이동(←→), 확대·축소.

**키프레임**: 아무 시각에 ◆ 점을 찍고 그 시각의 위치·크기·회전·투명도·소리 크기를 정하면 점 사이를 부드럽게 잇는다.
- 예: 매물 사진 3초 동안 천천히 확대 / 로고 2초에 나타나 4초에 사라지기 / 말할 때만 음악 줄이기
- 60세 원칙: 설정 칸 항목마다 [◆ 여기에 점 찍기] 단추, 타임라인 블록 위 ◆ 표시, 눌러서 옮기기·지우기.

**타임라인식 개발 순서 (4장 대체)**
1. 편집 화면 + 컷 편집 (여러 줄 타임라인, 자르기·다듬기·옮기기·겹치기, 재생)
2. 키프레임 (위치·크기·회전·투명도·소리 크기, 잇는 방법: 일정하게·천천히 시작·천천히 끝)
3. 자동 자막 줄 + 공통 부품 연결 (서식·애니메이션·효과음·화면전환·AI 목소리)
4. (나중) 속도 곡선, 색 보정, 마스크
