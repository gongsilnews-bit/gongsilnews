# 실거래 새 거래 알림 — 회의 정리 (2026-11-03)

> 상태: **회의 중 (아직 만들지 않음)**. 사장님이 "그렇게 해줘"로 정하면 시작한다.
> 관련 문서: [2026-11-02_apt_price_map_cost.md](2026-11-02_apt_price_map_cost.md) (실거래 받기·매일 밤 갱신)

## 1. 하려는 것

국토부 실거래에 **새 거래가 신고되면 알림으로 알려 준다.**
회원이 고른 **단지**나 **지역**에 새 매매·전세 거래가 올라오면, 다음 날 아침 사이트 알림창(🔔)에 뜬다.

## 2. 사장님이 정한 것

| 항목 | 정한 내용 |
|---|---|
| 받는 곳 | **사이트 알림창(🔔 종)**. 카카오 알림톡은 쓰지 않는다 |
| 고르는 단위 | **단지**와 **지역** 둘 다 |
| 누가 쓰나 | **유료 서비스.** 공실마케팅studio 유료 회원만 |

## 3. 제안 (아직 확정 아님)

| 항목 | 제안 |
|---|---|
| 단지 걸기 | 단지·건물 창에 **[🔔 새 거래 알림]** 단추 |
| 지역 걸기 | 공실마케팅studio 앱 안 **"실거래 알림"** 화면 — 시·군·구 → 동 고르기, 걸어 둔 단지 목록 보기·빼기 |
| 종류 | 아파트 · 오피스텔 · 빌라 / 매매 · 전세 (월세는 기본 끔 — 건수가 많고 시세 흐름에 덜 중요) |
| 받는 시간 | **매일 아침 한 번 묶음** — 새벽 갱신이 끝난 뒤 "관심 단지·지역 새 거래 N건" → 누르면 거래 목록 |
| 알림 내용 예 | 논현동 아크로힐스논현 · 전용 84㎡ · 매매 29억 7천 · 26.07.03 계약 · 12층 |
| 무료 회원 | 단추는 보이고, 누르면 "공실마케팅studio 회원 전용" 안내 → 금액안내 |
| 걸 수 있는 수 | 단지 30곳 · 지역(동) 5곳 정도 (너무 많으면 알림이 쏟아져 안 보게 됨) |

알아 둘 점: 실거래는 계약 뒤 **최대 30일 안에 신고**된다. 알림은 계약 당일이 아니라 **국토부에 올라온 다음 날 아침**에 간다.

## 4. 지금 있는 알림창 (그대로 쓴다)

- 표: `notifications` (받는 회원 `recipient_id` 또는 역할 `recipient_role`, 종류 `type`, 제목·내용·링크)
- 만들기: [src/app/actions/notification.ts](../src/app/actions/notification.ts) `createNotification()`
  - **특정 회원 한 명**(`recipientId`)에게도, **역할 전체**(`recipientRole: "ADMIN"` = 최고관리자 전원)에게도 보낼 수 있다
- 화면: [src/components/common/NotificationBell.tsx](../src/components/common/NotificationBell.tsx) — 종류마다 아이콘·색 (`member_signup: 👤` 등)
- 예: 회원가입하면 최고관리자 전원에게 "👤 새 회원이 가입했습니다 — 이름 (이메일)" → 누르면 `/admin?menu=members` (모바일 `/m/admin/member`) — [src/app/actions/member.ts](../src/app/actions/member.ts)

→ 실거래 알림은 **새 알림창을 만들지 않고** 종류 하나(예: `trade_alert`, 📈)만 더해 회원 각자에게 보낸다.

## 5. 먼저 필요한 것

1. **새로 들어온 거래 기록** — 지금 매일 밤 갱신(`syncRecent`)은 "바뀐 단지"만 알고 "어느 거래가 새로 들어왔는지"는 적지 않는다.
   매일 새 거래를 따로 남기는 표가 필요하다. (나중에 "오늘 새로 올라온 거래" 화면에도 쓸 수 있다)
2. **빌라 실제 기능** — 빌라 알림은 빌라가 실제 기능이 된 뒤에 된다. 지금 빌라는 강남구 논현동 견본뿐 (내 PC에서만).
3. **앱 공개 상태** — 공실마케팅 앱은 지금 AI 매물보고서만 공개, 나머지 "작업중". 실거래 알림도 처음엔 "작업중"으로 두고 사장님만 써 본다.

## 6. 순서 제안

1. 새로 들어온 거래 기록하기 (서버, 매일 밤 갱신에 붙이기)
2. 사장님 계정으로만 단지 알림 써 보기
3. 지역 알림 + 앱 "실거래 알림" 화면
4. 빌라 실제 기능 → 빌라 알림 추가
5. 공실마케팅studio 유료 회원에게 공개
