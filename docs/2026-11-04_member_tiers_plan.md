# 부동산 회원 등급 다시 짜기 — 공실뉴스부동산(무료) · 공실뉴스부동산 PRO(유료)

- 날짜: 2026-11-04 (사장님 회의)
- 상태: **확정** (2026-11-04 사장님 "그렇게 확정하자"). 6장 "아직 안 정한 것"만 남았습니다.
- 같은 날 바꿈: 무료도 공실로 SNS·유튜브 대본까지 씁니다. 블로그·SNS·유튜브를 묶어 공실 하나 = 1건, 한 달 3건 (사장님: "3건 주는 거니까 블로그만 말고 3개 다 되게").
- 배경: 같은 날 "앱은 쓰지 않는다 · 웹에서 다 되게"로 정했습니다. 그래서 앱(공실마케팅studio)을 기준으로 만든 등급(마케팅회원·스튜디오회원)을 웹 기준으로 다시 짭니다.

## 2. 혜택표

| 혜택 | 공실뉴스부동산 (무료) | 공실뉴스부동산 PRO |
|---|---|---|
| 딱지 | 없음 | 주황 PRO |
| 공실뉴스에 거는 공실 | **광고 중 3건** | **광고 중 20건** |
| 내 홈페이지 전용 공실 | 안 됨 | **광고 중 20건** |
| 공실로 블로그·인스타그램·스레드·페이스북·유튜브 대본 (뉴스·SNS자동화) | **한 달에 공실 3건** (공실 하나로 다 써도 1건) | 제한 없음 |
| 뉴스칼럼 (블로그·SNS·유튜브) | 안 됨 | 됨 |
| 기사 작성 | 안 됨 | **월 4건** |
| 매물보고서 | 등록한 공실 3건으로, **표지·개요만** | 모든 쪽·디자인·AI 채우기 |
| 유리창홍보지 | 등록한 공실 3건으로, **"숫자 크게" 디자인만** | 모든 디자인 |
| 물건접수홈페이지 | 안 됨 | 다 됨 (집주인 접수·로고·색상·첫 화면 사진 3장·영상) |
| 포토studio | 안 됨 | 다 됨 (AI 포함) |
| 고객관리 | 안 됨 | 다 됨 |
| 기사 아래 광고·배너 | 안 됨 | 다 됨 |

정리하면, 무료부동산은 **공실 3건 등록 → 그 공실로 블로그(한 달 3건) · 매물보고서 표지·개요 · 유리창홍보지 "숫자 크게"**까지 씁니다. 나머지는 모두 PRO입니다. PRO는 공실 건수와 기사 월 4건 말고는 제한이 없습니다.

### 세는 방법
- **공실 건수:** 광고 중인 공실만 셉니다. 광고를 내렸거나 거래가 끝난 공실은 빼고 세므로, 하나를 내리고 새것을 올릴 수 있습니다.
- **노출을 바꾸면:** 그쪽 한도로 옮겨 셉니다. 옮겨 갈 칸이 꽉 찼으면 바꿀 수 없다고 알려 줍니다.
- **블로그 한 달 3건:** 매달 1일에 다시 3건이 됩니다. 같은 공실의 블로그를 고쳐 쓰거나 다시 받는 것은 다시 세지 않습니다. 화면에는 "이번 달 블로그 3건 중 2건 남음"처럼 보여 줍니다. "무료 체험"이라는 말은 쓰지 않습니다.
- **기사 월 4건:** 매달 1일에 다시 4건이 됩니다. 지금 코드의 값과 같습니다.
- 지금 무료에 걸린 "1주일에 3번" 자동화 한도는 위 규칙으로 바뀝니다.

### 잠긴 기능의 모습
- 무료에서 안 되는 메뉴와 단추(인스타그램·스레드·페이스북·유튜브 칸, 뉴스칼럼 탭, 기사쓰기, 보고서 나머지 쪽, 홍보지 나머지 디자인, 물건접수홈페이지, 포토studio, 고객관리)는 **숨기지 않고 PRO 딱지와 자물쇠를 붙여** 보이게 둡니다.
- 누르면 "PRO에서 쓸 수 있어요"와 금액안내를 띄웁니다.
- 물건접수홈페이지와 포토studio는 들어가면 화면 모습을 미리 보여 준 뒤 안내를 띄웁니다.

### 지우지 않는 것
- 무료 회원이 예전에 써 둔 기사, 적어 둔 고객 정보, 꾸며 둔 홈페이지 내용은 지우지 않습니다.
- PRO가 끝나도 그대로 남고, 다시 PRO가 되면 그대로 보입니다.

## 3. 내 홈페이지 전용 공실 (새로)

공실 등록 화면의 **노출** 칸에 값을 하나 더합니다.

| 노출 | 누가 보나 |
|---|---|
| 부동산노출 | 공실뉴스의 다른 부동산 회원만 (공동중개용) |
| 부동산노출 + 일반인노출 | 모두 (공실뉴스 지도·목록 + 내 홈페이지) |
| **내 홈페이지만** (새로) | **내 물건접수홈페이지에서만.** 공실뉴스 지도·목록·다른 부동산에는 안 보임 |

- **누가:** PRO만 고를 수 있습니다. 물건접수홈페이지가 PRO 전용이기 때문입니다.
- **왜:** 집주인이 여기저기 올리지 말라고 한 물건, 단독 물건, 수수료를 따로 정한 물건을 내 홈페이지에만 걸 수 있게 하려는 것입니다.
- **한도:** 광고 중 20건이고, 공실뉴스에 거는 20건과 따로 셉니다. 그래서 내 홈페이지에는 최대 40건이 보입니다.
- **홍보:** 블로그·인스타그램·스레드·페이스북·유튜브·매물보고서·유리창홍보지 모두 됩니다. 링크는 내 홈페이지로 갑니다.
- **공실뉴스 기사에는 연결할 수 없습니다.** 기사는 공실뉴스에 모두에게 공개되기 때문입니다. 기사에 연결할 수 있는 공실은 지금처럼 "부동산노출 + 일반인노출"만입니다.
- 글 끝에 "이 매물은 ○○ 홈페이지에서만 볼 수 있어요"를 넣어도 좋습니다.

## 4. 링크와 글 끝 "부동산 프로필" 칸

### 원칙
- **본문:** 채널마다 요즘 유행하는 글 모양으로 씁니다(블로그는 정보 글, 인스타그램은 짧고 감성 있게, 스레드는 대화하듯). 무료와 PRO가 같습니다. 본문에는 지금처럼 부동산 티를 내지 않습니다.
- **글 끝:** 표시·광고 규정(공인중개사법)상 꼭 넣어야 하는 **사무소 정보**와 **유도 링크**를 한 칸에 모읍니다. 무료와 PRO의 차이는 이 칸의 링크뿐입니다.

### PRO — 모든 링크는 본인 부동산 홈페이지로
> ▶ 물건 상세 확인하기 → 내 홈페이지의 그 물건 화면
> ▶ 이 동네 다른 매물 더 보기 → 내 홈페이지 첫 화면
>
> ○○공인중개사사무소 · 대표 공인중개사 ○○○
> 등록번호 ○○○○-○○○○○ · (소재지) · ☎ (전화)
> 홈페이지 (내 홈페이지 주소)

| 어디서 만든 링크 | 가는 곳 |
|---|---|
| 공실로 쓴 블로그·인스타그램·스레드·페이스북·유튜브 | 내 홈페이지의 그 물건 화면 |
| 매물보고서·유리창홍보지의 QR·링크 | 내 홈페이지의 그 물건 화면 |
| 뉴스칼럼 글의 "기사 전문 보기" | 내 홈페이지의 그 기사 화면 (지금도 그렇게 되어 있음) |
| 홈페이지 전용 공실 | 내 홈페이지의 그 물건 화면 |

### 무료부동산 — 다 공실뉴스로 보이고 공실뉴스로 유도
> ▶ 물건 상세 확인하기 → 공실뉴스의 그 물건 화면
> ▶ 이 동네 다른 매물 더 보기 → 공실뉴스 우리동네부동산
>
> ○○공인중개사사무소 · 대표 공인중개사 ○○○
> 등록번호 ○○○○-○○○○○ · (소재지) · ☎ (전화)
> 공실뉴스에서 보기 → 그 부동산의 공실뉴스 사무소 화면

- 매물보고서와 유리창홍보지의 QR·링크도 공실뉴스의 그 물건 화면으로 갑니다.
- 법정 표시는 무료도 똑같이 넣습니다.

### 채널마다
| 채널 | 글 끝 칸 |
|---|---|
| 네이버 블로그 · 페이스북 · 스레드 | 위 칸 그대로 |
| 인스타그램 | 글 안의 링크가 눌리지 않으니 줄여서 넣습니다. 사무소 이름·등록번호·전화와 "프로필 링크에서 매물 더 보기". PRO는 프로필 링크를 내 홈페이지로 두라고 안내합니다. |
| 유튜브 | 설명란 첫 줄에 물건 화면 링크, 다음 줄에 홈페이지(무료는 공실뉴스) 링크, 그 아래 법정 표시 |

### 값 채우기
- 회원 정보(사무소 이름, 대표 이름, 등록번호, 주소, 전화, 홈페이지 주소)에서 자동으로 채웁니다.
- **빠진 값은 지어내지 않고 빈칸으로 둡니다.** 글을 쓰기 전에 "정보설정에서 등록번호를 넣어 주세요"처럼 알려 줍니다.
- 법정 표시 항목: 사무소 명칭, 소재지, 연락처, 등록번호, 개업공인중개사 성명이 필요하고, 물건마다 넣을 항목(소재지·면적·가격·거래 형태 등)도 따로 있습니다. 지금 블로그의 법정 표시가 이 항목을 다 담고 있는지는 코드 반영 때 확인합니다.

## 5. 홈페이지가 닫힐 때 (권고, 아직 안 정함)

- **대상:** 10월 30일에 무료로 열었던 홈페이지, PRO가 끝난 홈페이지
- **처리:** 이미 퍼진 링크가 헛걸음이 되지 않게, 그 주소로 들어온 손님을 넘겨 줍니다.
  - 물건 화면 → 공실뉴스의 같은 물건 화면
  - 홈페이지 전용 공실 → 그 부동산의 공실뉴스 사무소 화면 (공실뉴스에는 물건 화면이 없으므로)
  - 첫 화면 → 그 부동산의 공실뉴스 사무소 화면
- 꾸며 둔 내용은 남겨 두었다가, 다시 PRO가 되면 그대로 엽니다.

## 7. 지금 코드의 실제 상태 (2026-11-04 조사)

| 혜택 | 지금 무료 부동산 | 지금 유료 | 비고 |
|---|---|---|---|
| 공실 등록 | 제한 없음 | 제한 없음 | 부동산은 막지 않음 (`actions/vacancy.ts`). 소개 페이지의 "공실 3건" 글은 표시만 있음 |
| 기사쓰기 | 월 0건 | 월 4건 (비즈니스 10건) | `actions/article.ts`, 기본값 `admin/actions.ts` |
| 뉴스·SNS자동화 | 1주일에 3번 | 무제한 | `utils/studioUsage.ts` |
| AI 이미지·인테리어·리모델링 | 안 됨 | 됨 | `utils/studioUsage.ts`, `utils/extensionMember.ts` |
| 포토studio | AI만 막힘 | 다 됨 | `realty_admin/page.tsx` aiLock |
| 물건접수홈페이지 | 기본만 (색 하나, 전화·문자, 첫 화면 1장) | 다 됨 | `utils/planCheck.ts` canUseHomepage·canOpenHomepage |
| 기사 아래 광고·배너 | 안 됨 | 됨 | `actions/articleAd.ts`, `actions/articleVacancy.ts` |
| 지도에 공실·수수료 | 됨 | 됨 | 차이 없음 |

- 유료 판정은 지금 모두 `studio_end_date`(이용 기간) 하나로 합니다(`studioAlive`, `isStudioMember`).

### 코드 반영 때 같이 고칠 것
1. **이용 기간을 안 보는 곳 두 군데:** `isReporterEligible`(광고관리 메뉴)와 `getPermissionLevel` 4단계가 `plan_type`만 읽습니다. 그래서 기간이 끝나도 유료로 봅니다.
2. **비즈니스회원 판정이 곳마다 다름:** `getEffectivePlan`은 기간이 있어야 유료로 보는데, `myTier`는 늘 유료로, `extensionMember`는 역할로 판정합니다.
3. **기사 한도 대체값이 거꾸로 보임:** `actions/article.ts` 59번째 줄 근처에서, 유료를 산 적이 없는 회원이 0건으로 막힐 수 있습니다.

## 8. 코드 반영 순서 (승인 뒤)

1. **등급 판정 한곳으로:** 무료 / PRO / 비즈니스 / 최고관리자를 돌려주는 함수 하나를 만들고, 위 3가지 문제를 고칩니다.
2. **보이는 이름과 PRO 딱지:** 관리자 머리줄, 금액안내, 회원 목록, 지도·카드·기자란
3. **공실 한도:** 광고 중 3건 / 20건, 노출 "내 홈페이지만"과 그 20건, 지도·목록·기사 연결에서 빼기
4. **뉴스·SNS자동화:** 무료는 블로그 한 달 3건, SNS·유튜브·뉴스칼럼 잠금
5. **기사쓰기:** 무료 잠금, PRO 월 4건
6. **매물보고서·유리창홍보지:** 무료는 표지·개요 / "숫자 크게"만 (예전 웹 잠금 장치 `webLimit.tsx`를 고쳐 씀)
7. **물건접수홈페이지·포토studio·고객관리·광고배너:** PRO 잠금과 미리 보기 화면, 닫힌 홈페이지 넘겨 주기
8. **글 끝 부동산 프로필 칸과 링크:** PRO는 내 홈페이지, 무료는 공실뉴스. 채널별 모양, 빈 값 알림
9. **안내 글 정리:** 소개 페이지·금액안내·FAQ의 등급 이름과 숫자
