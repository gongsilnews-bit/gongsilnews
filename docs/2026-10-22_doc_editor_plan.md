# 공실마케팅 › 문서편집 계획 (2026-10-22 회의)

## 1. 목표
- 공실마케팅에 **[문서편집]** 메뉴를 넣는다 (AI 매물보고서 아래).
- **MS 워드(.docx)·한글(.hwp/.hwpx) 문서를 가져와 열고, 고치고, 워드·한글로 다시 저장**한다.
- **한글 프로그램이 없는 회원**도 쓸 수 있어야 한다 (회원 대부분이 한글 미설치).
- 화면·메뉴는 **MS 워드와 똑같이** (워드를 쓰던 회원이 헛갈리지 않게).
- 추가 저장: **PDF · 이미지(PNG/JPG)**.
- 나중에: 공실 정보 채우기 (편지 탭 = 메일 병합 자리).

## 2. 저장·열기 형식
| 형식 | 열기 | 저장 | 비고 |
|---|---|---|---|
| .docx | O | O | 편집기에서 직접 |
| .hwpx | O | O | 편집기에서 직접 (한글 2014+ · 한컴 무료 뷰어에서 열림) |
| .hwp | O | O | **앱에서만** — 변환기(hwplib)로 .hwp ↔ .hwpx, 편집은 늘 .hwpx 로 |
| PDF | - | O | 화면에 그린 종이 그대로 |
| PNG/JPG | - | O | 쪽마다 한 장 · 한 장으로 이어 붙이기 · 보통/고화질(300dpi) · [내 자료]에도 담기 |

- 웹 화면: .docx · .hwpx · PDF · 이미지까지. .hwp 는 데스크톱 앱(PC 안에서 변환)에서만.
- 처리는 회원 PC 안에서 — 계약서·확인설명서 개인정보를 서버로 보내지 않는다.
- 한글이 깔린 회원용 [한글로 열기]는 나중에 덧붙일 수 있음 (필수 아님).

## 3. 화면 — MS 워드와 같은 구성
| 탭 | 내용 | 단계 |
|---|---|---|
| 파일 | 처음 화면(새 문서·양식, 최근 항목), 열기, 저장, 다른 이름으로 저장(.hwp·.hwpx·.docx·PDF·PNG·JPG), 인쇄 | 1 |
| 홈 | 붙여넣기·복사·서식 복사, 글꼴·크기·굵게·기울임·밑줄·취소선·위첨자·아래첨자·색·형광펜, 정렬·줄 간격·들여쓰기·번호·글머리표·테두리·음영, 스타일(표준·제목1·제목2·제목·부제), 찾기·바꾸기 | 1 |
| 삽입 | 새 페이지·페이지 나누기, 표, 그림, 아이콘, 링크, 머리글·바닥글·페이지 번호, 기호, 날짜 / 도형·텍스트 상자 | 1 / 2 |
| 레이아웃 | 여백, 용지 방향, 크기(A4·B5 …), 단, 나누기, 들여쓰기·간격 | 1 |
| 보기 | 인쇄 모양·웹 모양, 눈금자, 확대·축소(100%·한 페이지·여러 페이지·페이지 너비) | 1 |
| 디자인 | 문서 서식, 색, 글꼴 묶음, 워터마크, 페이지 색, 페이지 테두리 | 2 |
| 그리기 | 펜·형광펜, 지우개 | 2 |
| 검토 | 맞춤법, 단어 개수, 메모 / 변경 내용 추적 | 2 / 3 |
| 참조 | 목차, 각주·미주, 캡션 | 3 |
| 편지 | 메일 병합 → **공실 정보 채우기** | 나중 |
| 도움말 | 도움말, 단축키 | 1 |
| Acrobat 자리 → **AI** | 문장 다듬기, 소개글 쓰기, 요약, 번역, 표 만들기 (회원 AI · 서버 Gemini 안 씀) | 3 |

- 단축키 워드와 같게 (Ctrl+B·I·U, Ctrl+Z·Y, Ctrl+F·H, Ctrl+Enter, Ctrl+P …).
- 아래 상태줄: 페이지 1/3 · 단어 수 · 보기 단추 · 확대 막대.
- 저장: 문서\공실뉴스 문서 (기본), 최근 문서, 자동 저장·복구 (이미지 편집과 같은 방식).

## 4. 기술 분석
- **지금 상태**: 공실마케팅 메뉴는 [AI 매물보고서] 하나 — 붙이기 쉬움. 편집기·docx·PDF 도구는 아직 없음 (새로 들임).
- **Java 없음**: 사장님 PC(와 회원 PC 대부분)에 Java 가 없다 → hwplib(Java)을 그대로는 못 씀.
- **편집기 엔진**: TipTap (MIT, 상업 사용 문제 없음). 글·서식·표·사진은 안정적.
  A4 종이가 한 장씩 나뉘는 화면(쪽 나누기)은 직접 만든다.
  OnlyOffice 등 워드 흉내 공개 편집기는 AGPL 이라 제외 (서비스 코드 공개 의무 위험).
- **.hwp 처리 (한글 없이)**
  | 방법 | 장점 | 단점 |
  |---|---|---|
  | A. 앱에 작은 Java 실행기 + hwplib | 가장 검증됨, 읽기·쓰기 | 설치 파일 약 +40MB |
  | B. hwplib 을 실행 파일 하나로 굳히기 (GraalVM native-image) | Java 없이, 약 20~30MB | 굳히기가 될지 시험 필요 |
  | C. 읽기 전용 JS(hwp.js) + 저장은 .hwpx | 가볍고 웹에서도 | .hwp 저장 불가, 읽기 품질 낮음 |
  → **B 를 먼저 시험, 안 되면 A.** hwplib·hwpxlib 은 Apache 라이선스 (상업 사용 가능).

## 5. 위험 (어려운 순서)
1. .hwp 변환 품질 — 부동산 양식의 복잡한 표·칸 합치기·글상자.
2. 쪽 나누기 화면 — 표가 쪽 경계에 걸릴 때.
3. 글꼴 — 한글 문서의 함초롬바탕·돋움이 PC 에 없으면 줄이 바뀔 수 있음. 함초롬체 동봉은 **라이선스 확인 필요**.
4. 워드식 메뉴 전체 — 양은 많지만 어렵지 않음.

## 6. 순서
0. **시제품 시험** (본 개발 전)
   - hwplib 실행 파일 굳히기 → Java 없이 .hwp → .hwpx → .hwp
   - 실제 부동산 양식(확인설명서·계약서)이 편집기에서 얼마나 그대로 보이는지
   - A4 쪽 나누기 + 표
1. 1단계: 편집기 + 파일·홈·삽입·레이아웃·보기·도움말 + .docx·.hwpx 열기·저장 + PDF·이미지 저장
2. .hwp 열기·저장 (앱)
3. 2단계: 디자인·그리기·검토·도형·텍스트 상자
4. 3단계: 참조·변경 추적·AI 탭
5. 실제 양식으로 시험·맞추기
6. 나중: 공실 정보 채우기 (편지 탭)

## 7. 정할 것 · 필요한 것
- 시제품 시험부터 할지.
- 시험용 실제 빈 양식: .hwp 2~3개, .docx 1~2개 (개인정보 없는 것).
- Acrobat 탭 자리를 AI 탭으로 바꿀지 (권고: 바꿈).
- 함초롬체 등 한글 글꼴 동봉 가능 여부 (라이선스).
