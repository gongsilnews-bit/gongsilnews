# 공실뉴스 스튜디오 영상 편집기 개발 계획 (브루식)

- 작성일: 2026-10-15
- 대상: 공실뉴스 스튜디오(Electron 데스크톱 앱) [동영상제작] 메뉴
- 상태: 계획안 (사장님 확인 전)
- 이어받는 문서: `docs/2026-10-07_reel_desktop_local_architecture_meeting.md` (로컬 우선 원칙), `docs/2026-10-15_gongsil_studio_desktop_app_meeting.md` (스튜디오 앱)

## 1. 한 줄 결론

**브루(Vrew)처럼 "말·글로 편집하는" 영상 편집기를 공실뉴스 스튜디오 안에 만든다. 원본 영상은 회원 PC에 두고, 편집·미리보기·굽기를 모두 PC에서 한다.**
릴스·유튜브·매물 소개 영상은 이 편집기가 만드는 결과물(틀)이다. 공실스튜디오의 가장 큰 장점으로 삼는다.

## 2. 무엇을 만드나 — 브루식 편집의 핵심

1. **말이 곧 클립**: 영상을 불러오면 말소리를 받아써서 문장마다 클립으로 나눈다. 화면에는 영상 대신 **글 목록**이 보인다.
2. **글을 지우면 영상도 잘린다**: 문장·단어를 지우면 그 구간이 잘린다. 말 없는 구간·"음, 어" 같은 군더더기는 한 번에 지운다.
3. **자막이 자동**: 받아쓴 글이 그대로 자막. 고치면 자막도 바뀐다. 글꼴·색·위치·강조는 틀로.
4. **글로 시작**: 대본(매물 정보·기사·유튜브 대본)을 넣으면 문장마다 AI 성우 + 사진·영상·AI 그림을 붙여 영상이 된다. 지금의 릴스 편집기가 이 방식.
5. **보이는 그대로 굽기**: 미리보기와 완성 MP4가 같다. 세로(9:16)·가로(16:9)·정사각(1:1).

## 3. 공실뉴스만의 강점 (브루에 없는 것)

- **매물과 연결**: 공실을 고르면 사진·가격·위치·표시광고 문구가 들어간 틀이 바로 시작된다.
- **숫자 보호**: 가격·면적·층수는 AI가 아니라 DB 값으로 (틀린 금액이 영상에 나가지 않게).
- **표시·광고 자동**: 공인중개사법 필수 항목 마무리 카드 자동, 호수·연락처 차단.
- **한 앱 안에서**: 같은 매물로 기사·블로그·SNS·유튜브 대본을 쓴 것이 그대로 영상 대본이 된다. 결과물은 같은 매물 폴더에.
- **회원 AI**: 대본·요약·제목은 회원이 고른 AI(ChatGPT·Claude·Gemini)로 — 공실뉴스 비용 없음.

## 4. 왜 앱인가

- 회원이 찍은 영상은 크다(수백 MB~수 GB). 서버에 올리지 않고 PC에서 바로 쓴다.
- 미리보기가 즉시 된다 (올리기·변환 기다림 없음).
- 굽기를 PC의 FFmpeg로 하면 서버 비용·대기열이 없다.
- 스튜디오 앱에 이미 있는 것: 설치·자동 업데이트, 한 번 연결 로그인, 회원 AI, FFmpeg, 매물별 저장 폴더.

```text
├──────────────────────────────┬───────────────────────────────────┤
│ 클립 목록 (글로 편집)          │  미리보기 (재생·자막·스티커 끌기)    │

│ ▶ 02 오늘 소개할 매물은 …      │                                   │
│   ~~(무음 1.2초)~~  ← 지움     │                                   │
│ ▶ 03 논현동 빌라 전세 5억 …    ├───────────────────────────────────┤
│   [성우][사진 바꾸기][효과]     │ 오른쪽 칸: 자막 스타일·음악·스티커·  │
│                               │ 내 사진·영상·AI 그림                │
├──────────────────────────────┴───────────────────────────────────┤

```

## 6. 시작하는 세 가지 길

| 시작 | 회원이 하는 것 | 편집기가 하는 것 |
|---|---|---|
| **내 영상으로** | PC 영상 불러오기 | 받아쓰기 → 문장 클립 → 무음·군더더기 표시 → 자동 자막 |
| **글(대본)로** | 대본 붙여넣기 또는 AI로 쓰기 | 문장마다 AI 성우 + 사진·AI 그림 배치 |
| **공실로** | 공실 고르기 → 틀 고르기(릴스·유튜브·매물 소개) | 매물 사진·숫자·표시광고 넣은 대본 초안(회원 AI) → 성우 → 틀 |

세 길 모두 같은 프로젝트 형식이라, 내 영상에 성우 문장을 끼우거나 대본 영상에 내 영상 클립을 섞을 수 있다.

## 8. 전체 구조

```text
공실뉴스 스튜디오 앱
├─ [동영상제작] 메뉴 — 편집 화면 (웹 화면을 앱 안에서, 고치면 바로 반영)
│    └─ window.gongsilStudio.video.*  ← 앱이 주는 로컬 통로
├─ 로컬 통로 (Electron 본체)
│    ├─ 파일 고르기 (원본 경로는 PC에만)
│    ├─ studio-media:// — 로컬 영상·사진·음성을 편집 화면에서 바로 재생 (구간 탐색)
│    ├─ FFmpeg: 정보(ffprobe) · 편집용 가벼운 사본(프록시) · 썸네일 · 파형 · 소리만 뽑기
│    ├─ 프로젝트 저장/불러오기 (project.json, 자동 저장·복구)
│    └─ 굽기: 틀 HTML + 클립 컷 → MP4 (진행률 · 그래픽카드 가속 · 실패 시 일반 인코딩)
└─ 공실뉴스 서버 (작은 일만)
     ├─ 받아쓰기 (소리만 받음 → 단어·시간)
     ├─ 성우 음성 만들기·보관
     ├─ 매물 정보·등록 사진
     └─ (선택) 완성본 올리기 → 매물 페이지·SNS
```

## 9. 로컬 프로젝트 폴더

```text
문서\공실뉴스 스튜디오\
  논현동 빌라 연립_88633\영상\매물소개_10월15일 22시10분\   ← 공실로 시작
  영상\내 영상_10월16일 09시30분\                          ← 매물 없는 영상
      project.json   클립(글·시작·끝·원본)·자막·스티커·음악·성우·틀·비율, 원본 목록(이름·크기·해시·마지막 경로)
      autosave\  proxy\  thumbnails\  waveform\  audio\  voice\
      output\        완성 MP4 · 자막 파일(SRT)
```

- 원본은 복사하지 않고 있는 자리 그대로. 옮겨지면 "파일 다시 찾기"(해시 비교).
- 실행취소/다시실행, 자동 저장, 앱이 꺼져도 복구.

## 10. AI 역할 나누기

| 일 | 누가 | 이유 |
|---|---|---|
| 받아쓰기 (자동 자막·글 편집) | 서버, **소리만** 보냄 | 한국어 정확도. 원본 영상은 안 보냄. 나중에 PC 받아쓰기(무료·오프라인) 선택지 |
| 대본·제목·요약 | **회원 AI** (기본 글쓰기 AI) | 공실뉴스 비용 없음 |
| 가격·면적 숫자 | **코드** (DB 값) | AI가 숫자를 바꾸지 못하게 |
| 성우 | 서버 Gemini TTS (지금 그대로) | 같은 문장·목소리는 한 번만 만들고 재사용 |
| AI 그림 | **회원 AI** (기본 이미지 생성 AI) | 지금 기사·블로그와 같음 |

## 11. 굽기 (렌더링)

- 기본은 **PC에서**. 컷(원본 구간 잇기)은 FFmpeg, 자막·스티커·효과는 틀(HTML)로 그려 겹친다.
  - 0단계에서 두 방법을 시험: A) hyperframes 도구를 앱에서 실행, B) 앱 숨은 창에서 틀을 재생하며 프레임 떠서 FFmpeg로 잇기.
- 출력: 9:16 1080×1920 · 16:9 1920×1080 · 1:1 1080×1080, H.264/AAC MP4 (+ SRT 자막 파일).
- 그래픽카드 가속(NVENC·QSV·AMF) 자동 → 실패 시 일반 인코딩(OpenH264·MediaFoundation)으로 다시.
- 진행률·남은 시간, 꺼져도 이어 굽기.

## 12. 단계

| 단계 | 내용 | 끝났다고 보는 기준 |
|---|---|---|
| **0. 검증** (1~2일) | 로컬 영상 재생(studio-media://), FFmpeg 프록시·파형, 받아쓰기 정확도·시간, 틀 → MP4 굽기 시간 | 10분 영상 받아쓰기 1분 안팎, 30초 영상 보통 PC에서 2분 안에 굽기 |
| **1. 편집기 뼈대** | [동영상제작] → 새 프로젝트(비율) → 내 영상 불러오기 → 클립 나누기·자르기·순서 → 미리보기 → PC 굽기 → 폴더 | 서버 없이 컷 편집 영상 완성 |
| **2. 브루식 핵심** | 받아쓰기 → 문장 클립·단어 자막 → 글 지우면 영상 잘림 → 무음·군더더기 한 번에 지우기 → 자막 스타일 | 1시간 촬영본을 글로 편집해 10분 영상 |
| **3. 글로·공실로 시작** | 대본 → 성우 + 사진·AI 그림 (지금 릴스 편집기를 옮김), 공실 틀(릴스·유튜브·매물 소개), 회원 AI 대본 | 공실 하나로 릴스·유튜브 영상을 각각 완성 |
| **4. 꾸미기** | 전환·효과·스티커·음악 줄·소리 크기·배경 제거 없는 범위의 기본 효과, 틀 추가 | 브루 기본 기능 수준 |
| **5. 더하기** | 내 목소리 녹음, 번역 자막, SRT 내보내기, 완성본 올리기·SNS 연결, 프로젝트 백업 | |

## 13. 정할 것 (제 권고)

1. **받아쓰기 엔진** → 서버(소리만)로 시작. PC 받아쓰기는 나중 선택지 (빠른 PC용, 무료).
2. **받아쓰기·성우 비용** → 공실스터디 멤버십에 포함, 무료 회원은 월 시간 제한 (예: 받아쓰기 월 30분).
3. **첫 결과물 틀** → 릴스(9:16)와 유튜브(16:9) 두 개.
4. **편집 화면** → 서버의 웹 화면을 앱 안에서 연다 (다른 메뉴와 같은 방식). 로컬 파일은 앱 통로로만. 앱 밖 웹 브라우저에서는 열리지 않거나 "앱에서 열기" 안내.
5. **완성본 올리기** → 회원이 [공실뉴스에 올리기]를 누를 때만.
6. **기존 웹 `/reels`** → 3단계에서 편집기로 옮길 때까지 웹에서 그대로 둔다.

## 14. 지킬 것

- 원본 영상을 서버에 올리지 않는다 (받아쓰기는 소리만).
- 서버 비밀키를 앱에 넣지 않는다. 로컬 절대경로를 서버에 보내지 않는다.
- FFmpeg 인자는 배열로 (경로를 명령 문자열에 끼우지 않음).
- 표시·광고 필수 항목, 호수·연락처 차단은 영상에도 그대로.
- FFmpeg LGPL 고지와 대응 소스 안내 (설치 파일·앱 정보 화면).
- 편집기 안 용어: 장면 대신 **클립**.
