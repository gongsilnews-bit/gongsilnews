# 공실뉴스 스튜디오 영상 편집기 개발 계획 (브루식)

- 작성일: 2026-10-15
- 대상: 공실뉴스 스튜디오(Electron 데스크톱 앱) [동영상제작] 메뉴
- 상태: 계획안 (사장님 확인 전)
- 이어받는 문서: `docs/2026-10-07_reel_desktop_local_architecture_meeting.md` (로컬 우선 원칙), `docs/2026-10-15_gongsil_studio_desktop_app_meeting.md` (스튜디오 앱)

## 1. 한 줄 결론

**브루(Vrew)처럼 "말·글로 편집하는" 영상 편집기를 공실뉴스 스튜디오 안에 만든다. 원본 영상은 회원 PC에 두고, 편집·미리보기·굽기를 모두 PC에서 한다.**
릴스·유튜브·매물 소개 영상은 이 편집기가 만드는 결과물(틀)이다. 공실스튜디오의 가장 큰 장점으로 삼는다.

## 2. 무엇을 만드나 — 브루식 편집의 핵심

1. **말이 곧 클립**: 영상을 불러오면 말소리를 받아써서 문장마다 클립으로 나눈다. 화면에는 영상 대신 **글 목록**이 보인다.
2. **글을 지우면 영상도 잘린다**: 문장·단어를 지우면 그 구간이 잘린다. 말 없는 구간·"음, 어" 같은 군더더기는 한 번에 지운다.
3. **자막이 자동**: 받아쓴 글이 그대로 자막. 고치면 자막도 바뀐다. 글꼴·색·위치·강조는 틀로.
4. **글로 시작**: 대본(매물 정보·기사·유튜브 대본)을 넣으면 문장마다 AI 성우 + 사진·영상·AI 그림을 붙여 영상이 된다. 지금의 릴스 편집기가 이 방식.
5. **보이는 그대로 굽기**: 미리보기와 완성 MP4가 같다. 세로(9:16)·가로(16:9)·정사각(1:1).

## 3. 공실뉴스만의 강점 (브루에 없는 것)

- **매물과 연결**: 공실을 고르면 사진·가격·위치·표시광고 문구가 들어간 틀이 바로 시작된다.
- **숫자 보호**: 가격·면적·층수는 AI가 아니라 DB 값으로 (틀린 금액이 영상에 나가지 않게).
- **표시·광고 자동**: 공인중개사법 필수 항목 마무리 카드 자동, 호수·연락처 차단.
- **한 앱 안에서**: 같은 매물로 기사·블로그·SNS·유튜브 대본을 쓴 것이 그대로 영상 대본이 된다. 결과물은 같은 매물 폴더에.
- **회원 AI**: 대본·요약·제목은 회원이 고른 AI(ChatGPT·Claude·Gemini)로 — 공실뉴스 비용 없음.

## 4. 왜 앱인가

- 회원이 찍은 영상은 크다(수백 MB~수 GB). 서버에 올리지 않고 PC에서 바로 쓴다.
- 미리보기가 즉시 된다 (올리기·변환 기다림 없음).
- 굽기를 PC의 FFmpeg로 하면 서버 비용·대기열이 없다.
- 스튜디오 앱에 이미 있는 것: 설치·자동 업데이트, 한 번 연결 로그인, 회원 AI, FFmpeg, 매물별 저장 폴더.

## 5. 화면 — 브루와 같은 짜임·순서, 공실뉴스 생김새

### 5-1. 디자인 원칙 (2026-10-15 사장님)

- **브루(Vrew)를 그대로 따라간다**: 화면 짜임, 단계 순서, 단추 위치, 쓰는 방식은 브루와 같게. 회원이 "브루랑 똑같네" 하고 바로 쓸 수 있게.
  - **어두운 화면**(브루 실제 캡처 기준) + 위쪽 탭 메뉴 + 리본(아이콘 + 글자)
  - 가운데 **클립 목록**(왼쪽 작은 화면 + 오른쪽 문장, 글을 고치면 영상이 바뀜), 오른쪽 위 미리보기, 아래 얇은 타임라인
  - 새로 만들기 창의 큰 카드, 단계식 만들기(비율 → 스타일 → 대본 → 목소리 → 자동 배치)
- **생김새는 공실뉴스 스튜디오**: 남색(#1a3a6b)·초록(#16a34a), Pretendard, 스튜디오 공통 단추·카드·칩, AI 연결 표시, 점점점 로딩 표시, 다크 모드. 스튜디오 왼쪽 메뉴 안에서 열리고 편집 화면에서는 작게 접힌다.
- **편집 프로그램다운 정밀함**: 시간 `00:12.40` 고정폭 숫자, 타임라인 파형·재생 위치·확대축소·클립 끝 끌기, 단축키(스페이스 재생, ←→ 한 프레임, Ctrl+Z, Delete, 자르기), 패널 크기 조절, 조밀한 화면.
- **베끼지 않는 것**: 브루 이름·로고·아이콘 그림·고유 색 조합·화면 그림 그대로 복사는 하지 않는다 (공실뉴스가 회원에게 파는 앱이라 문제가 될 수 있음). 아이콘은 우리가 고른 공개 아이콘 묶음으로.
- 기존 웹 릴스 편집기(`/reels`)의 주황색·별도 창 디자인은 쓰지 않는다 — 기능만 가져온다.
- 브루 캡처를 받아 화면별로 맞춘다 (새로 만들기, 텍스트로 만들기 단계, AI 목소리, 편집 화면, 탭 메뉴별, 자막 서식, 내보내기, 녹화·쇼츠).

**② [새로 만들기] 창**

```text
┌ 새로 만들기 ─────────────────────────────────────────────────────── ✕ ┐
│ ⚡ 최근 사용   [텍스트로 비디오 만들기]                                 │

│ 비디오·오디오 불러오기 ▾│ 텍스트로 비디오 만들기 │ AI로 숏폼 만들기 NEW ▾ │
│   [그림: 하늘색]       │   [그림: 보라]         │   [그림: 분홍]         │
├──────────────────────┼──────────────────────┼──────────────────────┤
│ AI 목소리로 시작하기   │ 템플릿으로 시작하기 NEW │ 이미지로 비디오 만들기  │
```

- 가운데 뜨는 창(뒤는 어둡게), 카드마다 작은 아이콘 + 이름, 큰 카드는 아래에 색 그림. ▾ 는 세부 고르기(예: 비디오/오디오, 숏폼 종류).
- **공실뉴스판**: 사장님이 정한 4가지를 큰 카드 4개로 (6장).
  - 텍스트로 영상 만들기 ← 브루 "텍스트로 비디오 만들기"
  - 촬영한 영상으로 편집하기 ← 브루 "비디오·오디오 불러오기"
  - 롱폼으로 자동 숏폼 만들기 ← 브루 "AI로 숏폼 만들기"
  - 영상 녹화하고 바로 편집하기 ← 브루 "녹화·녹음으로 시작하기"
  - 위에 **최근 사용**, 아래에 데모 프로젝트. 브루의 나머지(AI 목소리로 시작·템플릿·이미지·슬라이드)는 나중에 작은 카드로 더할 자리.
  - 방법을 고르면 그 방법의 단계로 (텍스트는 스타일 → 대본 → 꾸미기, 꾸미기에서 화면 비율 16:9 · 9:16 · 1:1 · 4:5 · 4:3).

**③ 맨 위 메뉴 (사장님: "우리도 맨 위 메뉴와 상단 메뉴가 있으면 좋겠다")**

- 편집기에서도 **맨 위 탭 메뉴 + 그 아래 리본**을 브루처럼 그대로 둔다: 파일 · 홈 · 편집 · 자막 · 서식 · 삽입 · AI 목소리 · 템플릿 · 효과 · 도움말 (+ 오른쪽 설정 · 의견 보내기 · 멤버십).
- 탭을 누르면 리본 단추 묶음이 바뀐다 (홈: 새로 만들기·프로젝트 열기·재생·되돌리기·잘라내기·클립 합치기/나누기·무음 구간 줄이기 …). 다른 탭의 리본 내용은 캡처를 받아 채운다.
- [동영상제작]에 들어가면 스튜디오 왼쪽 메뉴는 작게 접히고, 이 탭 메뉴·리본이 화면 맨 위를 차지한다.


- 가운데 큰 창, 위에 3단계 표시(지금 단계 강조), 오른쪽 아래 [다음 >].
- 카드를 **누르면 고른 표시(강조색 테두리)** → [다음 >]으로 넘어간다. 마우스를 올리면 카드 오른쪽 아래 **[자세히]**(그 스타일 예시 미리보기).
- 추천 스타일 예(브루): 정보 전달 · 다큐멘터리 · 명언 · 뉴스 · 공포 · 어린이 학습 … (사진 카드, 아래로 계속).
- **공실뉴스판**:
  - 같은 3단계: ① 스타일 고르기 → ② 대본 작성 → ③ 영상 꾸미기.
  - 추천 스타일은 부동산용: 매물 소개 쇼츠 · 부동산 뉴스 해설 · 경매·공매 브리핑 · 동네·상권 소개 · 인테리어 전후 등 (스타일 = 대본 말투 + 그림 스타일 + 자막 틀 + 음악 묶음).
  - 나만의 스타일: 회원이 만든 스타일을 계정에 저장 (유리창홍보지 "내 디자인"처럼). 사장님이 브루에 만들어 둔 "공실뉴스쇼츠", "부동산 매물 정보 전달형 분석 스타일"을 기본 추천으로 옮길 후보.
  - 화면 비율을 어느 단계에서 고르는지는 다음 캡처로 확인해 브루와 같은 자리에.

**공실뉴스판 — 2026-10-15 사장님 결정**

- **대본은 회원 AI로 쓴다** (기본 글쓰기 AI: ChatGPT · Claude · Gemini). 단추는 "[Claude로 글쓰기]"처럼 고른 AI 이름, 쓰는 동안 점점점 + 걸린 시간. 공실뉴스 비용 없음.
  - 브루가 유료로 막은 **대본 프롬프트(말투·대상·형식 요청)**와 **최신 정보 반영**(회원 AI의 웹 검색)이 그냥 된다.
- **길이는 글자 수로 정한다** (브루와 같음): [글자 수 설정] 켜기 + 숫자. 오른쪽 아래 "350 / 10,000자" 옆에 **예상 길이(약 1분 10초, 성우 빠르기 기준)**를 작게 함께 보여 준다.
- 화면은 브루와 같게 (왼쪽 AI 칸 · 오른쪽 대본 칸 · 이전/다음).
- 제안 (확인 전): 왼쪽 위에 **대본 가져올 곳** — 주제로 쓰기(브루와 같음) · 공실로 쓰기(가격·면적은 DB 값) · 내 글 가져오기(기사·블로그·유튜브 대본) · 직접 쓰기.
- 추천 주제는 진짜 자료에서만 (최근 공실뉴스 기사 제목·내 공실·부동산 소식). AI가 지어낸 주제 금지.
- 대본 칸은 문단(빈 줄)마다 클립으로 나뉜다. 공실 대본의 숫자 문장은 잠금 표시.

**⑥ 텍스트로 만들기 — 3단계 "비디오 꾸미기"**

```text
┌──────────── ① 스타일 고르기 ┄┄ ② 대본 작성 ┄┄ ③ 비디오 꾸미기 ──────────── ✕ ┐
│ [그림] 뉴스 스타일 ▾                      │                                  │
│ 화면 비율 [16:9][9:16✓][1:1][4:5][4:3]     │            예시 화면              │
│ 자막      [중단·짧게·애니메이션 >]  (켜기) │   ┌──────────────┐              │
│ AI 목소리 [심성욱 (빠르게) >]       (켜기) │   │ 샘플 그림      │              │
│ 배경음악                            (끄기) │   │ 자막은 이 위치에│              │
│ AI 이미지                           (켜기) │   └──────────────┘              │
│  생성 모델 [SDXL · 1크레딧/이미지 ▾]        │                                  │
```

- 왼쪽 = 설정 줄(이름 · 지금 값 단추 > · 켜기), 오른쪽 = 고른 비율·자막 위치로 바로 바뀌는 예시 화면 + 아래 요약.
- [자막 >], [AI 목소리 >]는 누르면 세부 창(위치·길이·애니메이션 / 성우·빠르기). 캡처 받아 채운다.
- 브루의 "무료 비디오" = 문장에 맞는 무료 영상 자료를 가져오는 기능으로 보임.
- 대본 칸의 빈 줄 문단이 클립 묶음이 된다 (2단계 캡처: 문단 4개, 658/10,000자).
- **공실뉴스판 메모 (회의 전)**:
  - AI 이미지는 회원 이미지 AI(ChatGPT·Gemini) — 한 장 약 30초라 **공실 사진이 있으면 사진 먼저, 모자란 곳만 AI 그림**. 생성 모델 고르기 자리는 "이미지 AI(ChatGPT/Gemini)" 고르기로.
  - 무료 비디오: 무료 영상 자료(Pexels 등) 연결을 따로 검토.

- 위 탭(내 목소리·전체·추천·즐겨찾기) + 검색, 왼쪽 필터(태그·언어·성별·연령대), 오른쪽 성우 카드(얼굴·이름·표시·해시태그), 아래 고른 성우 막대(효과·음량·속도·높이·미리듣기·즐겨찾기) + [확인].
- **공실뉴스판 메모**:
  - 성우: 지금 Gemini 12명 → Gemini 약 30명(모두 한국어)으로 늘리고, 더 많은 한국어 성우는 성우 회사(네이버 클로바 보이스·타입캐스트 등)를 나중에 붙인다 (성우 회사 바꿔 끼우기 구조 — 릴스 회의 결정).
  - 속도·음량·높이·효과(전화·라디오·울림)는 녹음된 목소리를 FFmpeg로 조정 (속도는 높이 그대로).
  - 성우 얼굴은 브루 사진 대신 공실뉴스 성우 캐릭터 그림을 새로 만든다. 해시태그는 #아나운서 #또박또박 #부동산설명 처럼 부동산 쓰임새로.
  - 즐겨찾기·최근 쓴 성우는 계정에 저장. "AI 내 목소리"(목소리 복제)는 마지막 단계(내 목소리)로.

**⑧ [자막 >] → 자막 작은 창(팝업)**

```text
┌ 자막 ───────────────────────────── ✕ ┐
│ 위치  [상단][중단][중하단][하단✓]       │
│ 길이            [길게✓][짧게]          │
│ 자동 애니메이션                 (끄기) │
└──────────────────────────────────────┘
```

- 설정 줄 옆에 작은 창으로 뜬다. 고르면 오른쪽 **예시 화면이 바로 바뀐다** (비율 4:3이면 가로 예시, 자막 위치 이동). 설정 줄 단추 글자도 "하단 · 길게 >"처럼 바뀐다.
- 길이: 길게 = 한 화면에 긴 한 줄, 짧게 = 짧게 끊어 여러 번.
- **공실뉴스판**: 같은 작은 창. 자동 애니메이션 = 지금 릴스 틀의 단어별 자막(노란 강조)을 쓴다. 자막 글꼴·색·테두리는 편집 화면 [서식] 탭에서.

**⑨ [배경음악 >] → 배경음악 작은 창**

```text
┌ 배경음악 ─────────────────────────── ✕ ┐
│ [활기찬 ▶] [감성적인 ▶] [유쾌한 ▶]      │
│ [잔잔한 ▶✓] [무서운 ▶] [랜덤 ▶]         │
└────────────────────────────────────────┘
```

- 분위기 단추 6개, 단추마다 ▶ 미리듣기. 고르면 설정 줄이 "잔잔한 >", 아래 요약에 "♫ 잔잔한"이 더해진다. (켜기/끄기는 설정 줄 오른쪽)
- **공실뉴스판**: 같은 작은 창. 분위기는 부동산 영상용(예: 활기찬 · 감성적인 · 고급스러운 · 잔잔한 · 신뢰감 · 랜덤) + **내 음악 올리기**. 음악은 지금 릴스 음악 목록(`music-catalog.ts`) + **자료 창고에 저작권 걱정 없는 음악**(분위기 태그)으로 채운다. 성우가 말할 때 음악 소리를 자동으로 줄인다.

**⑩ 비디오 꾸미기 — 아래쪽 나머지 설정**

```text
│ 고화질  +1 크레딧/이미지                     (켜기) │
├──────────────────────────────────────────────────┤
│ 무료 비디오                                  (켜기) │
│ 자동 음소거                                  (켜기) │
│ 채우기          [▣ 꽉 채우기✓] [☺ 맞추기] [▣☺ 배경 채우기] │
```

- 고화질: AI 그림을 더 좋은 화질로 (브루는 이미지당 크레딧 추가).
- 무료 비디오: 문장에 맞는 무료 영상 가져오기 켜기/끄기. 자동 음소거: 가져온 영상의 원래 소리 끄기.
- 채우기(아이콘 3개, 아이콘으로 본 추정): 꽉 채우기(넘치는 곳 잘림) · 맞추기(전체 보이고 여백) · 맞추고 배경 채우기(여백을 흐린 배경 등으로).
- **공실뉴스판**:
  - 채우기 세 가지, 기본 꽉 채우기. 세로 공실 사진을 가로(16:9·4:3) 영상에 넣을 때 **흐린 배경 채우기**를 권한다.
  - 무료 비디오 = 10-1장 "자료 창고 + 무료 사이트" 켜기/끄기. 자동 음소거 기본 켜기.
  - 고화질: 회원 이미지 AI는 화질이 정해져 있어 "화질 키우기(업스케일)"로 둘지 나중에 정한다.
- 설정 칸 끝. 아래 요약(비율 · 성우 · 음악 · AI 이미지 · 무료 비디오) + [이전] [완료 >].

**⑪ [완료 >] → 확인 창**

- 브루: 작은 창 "확인 — 비디오 생성을 시작할까요?" [확인] [취소].
- **공실뉴스판**: 같은 확인 창 + 한 줄 요약 — 클립 수 · 성우 · 화면 자료(공실 사진 n장 · 자료 창고/무료 영상 n개 · AI 그림 n장과 그리는 AI) · **예상 시간**. 회원 AI로 그림을 그리면 오래 걸리므로 미리 알린다.

**⑫ 만들어지는 중 화면**

```text
┌──────────────────────────────────────────────────── ✕ ┐
│              [움직이는 예시 그림]                        │
│        ━━━━━━━━━━━━━━━━━━━━━━━━━━━  1%                  │
│        🖼 영상에 어울리는 이미지를 만들고 있어요            │
│        ⓘ 이 화면을 닫으면 영상이 만들어지지 않아요          │
└────────────────────────────────────────────────────────┘
```

- 큰 창, 가운데 기다리는 동안의 그림, 진행 막대 + %, 지금 하는 일(아이콘 + 글), 닫지 말라는 안내.
- **공실뉴스판**: 같은 모양 + 지금 하는 일을 단계별로 — 대본 나누는 중 → 성우 녹음 중 → 화면 자료 찾는 중 → AI 그림 그리는 중 (3/4, 회원 AI 이름) → 편집 화면 준비 중. 가운데는 **방금 만든 그림·찾은 사진을 차례로** 보여 준다. 점점점 + 걸린 시간도 (StudioWorking 과 같은 모양).

### 5-3. 편집 화면 (브루 캡처 기준 — 만들기를 마치면 열리는 화면)

```text
┌ [로고] 계정 · 파일 · [홈] · 편집 · 자막 · 서식 · 삽입 · AI 목소리 · 템플릿 · 효과 · 도움말 ……… 🔍 ⚙ 의견 보내기 · 업그레이드 · ^ ┐
├ [새로 만들기▾][프로젝트 열기] │ [영상 추가하기▾] │ 되돌리기 · 다시실행 │ 잘라내기 · 복사하기 · 붙여넣기 │ (AI 도우미) │       │
│ 클립 합치기 · 클립 나누기 │ [글꼴 ▾][크기 150 ▾][글자 색] […서식 메뉴로 이동] │ 무음 구간 줄이기        [  내보내기  ] │
├──────────────────────┬────────────────────────────────────────────────────────────────────────────┤
│ ┌ 미리보기 (자막 포함) ┐│                                                     [개요 | 상세✓]  👁  │
│ └──────────────────┘ │ ♪  씬 1                                               00:00 + 1분 26초      │
│ ▶ 00:00 / 01:26  1x ⊞ ⋯│ ┌──────────────────────────────────────────────────────┐ ┌썸네일┐    │
│ ┌ 클립1 ─────────── ↗ ┐│ │ 1 │ 🔊 심성욱 ≡ │ [국내][주식시장에서][급격한][매도세가]…[·] ✏ │ │      │    │
│ │ 🎞 비디오      클립 1 ││ │ ☐ │ [작은 그림] ▭ 국내 주식시장에서 급격한 매도세가 …   ↻ │ │00:00 │    │

│ └──────────────────┘ ›│ ┌ 2 │ 🔊 심성욱 ≡ │ [2026년][10월][15일][오후]…[·] ✏ ──────┐ └──────┘    │

```

**맨 위**
- 탭 + 리본(아이콘 위·글자 아래, 묶음마다 구분선). 리본 오른쪽 끝에 큰 **[내보내기]**. ^ 로 리본 접기.
- 홈 리본에 **자주 쓰는 서식(글꼴 · 글자 크기 · 글자 색)**이 바로 있다 — 고른 클립 자막에 적용.

**왼쪽 칸**
- 위: **미리보기**(고른 비율, 자막 포함) · 진행 막대 · ▶ 시간 `00:00 / 01:26` · 재생 속도 `1x` · 안내선 ⊞ · ⋯
- 아래: **고른 클립 정보** — 이 클립에 들어간 것(🎞 비디오 · ♪ 음악 "곡명" 클립 1-17처럼 어디부터 어디까지 깔렸는지). ↗ 로 크게 보기, › 로 칸 접기.

**가운데 — 클립 목록 (브루의 핵심)**
- 오른쪽 위 **[개요 | 상세]** 보기 바꾸기 (개요 = 간단히, 상세 = 단어까지), 👁(미리보기 관련).
- **씬** 묶음: "씬 1" + 전체 길이(`00:00 + 1분 26초`), 왼쪽 ♪ = 이 씬의 음악. 대본의 문단(빈 줄)이 씬이 되는 것으로 보임.
- **클립 카드** (문장 하나):
  - 왼쪽: 번호 + 고르기 칸(여러 개 골라 합치기·지우기)
  - 1줄: 🔊 **성우 이름** + ≡ 메뉴(성우·속도 바꾸기 등) → **문장을 단어 단추로** 나열 → 끝에 **[·]**(쉬는 구간으로 보임) → ✏ 고치기

- 미리보기 옆에 **세로 도구 막대**: 고르기 · 순서(레이어) · 색 · 자르기 · 반전 · 교체.
- **작은 그림에 마우스를 올리면** 그 자료가 **크게 떠서 미리 보인다**(영상이면 재생). 클립을 누르면 왼쪽 칸에 그 클립의 자료 목록(🎞 비디오 클립 2 · 🎞 비디오 클립 1-2 · ♪ 음악 클립 1-17)과 적용 범위 막대(회색)가 보인다 — 한 클립에 자료가 여러 겹 깔릴 수 있다.
- **공실뉴스판**: 같은 메뉴. **교체** = 공실 사진 · 자료 창고 · 무료 영상 · AI 그림(회원 이미지 AI) · 내 파일. **비디오 생성**(AI 영상)은 나중 단계. 용어는 "에셋" 대신 **"화면 자료"**(회원이 알기 쉽게).

## 6. 시작 화면 — ① 만들 방법 고르기 → ② 화면 비율 고르기

[동영상제작]을 누르면 먼저 시작 화면이 나온다 (최근 프로젝트 목록은 그 아래).

### ① 만들 방법 (4가지 중 하나)

```text
┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│  ✍ 텍스트로      │  🎬 촬영한 영상   │  ✂ 롱폼으로      │  ⏺ 영상 녹화하고  │
│   영상 만들기     │   으로 편집하기   │ 자동 숏폼 만들기  │   바로 편집하기   │
│ 대본만 있으면     │ 찍은 영상을 글로  │ 긴 영상에서 좋은  │ 화면·카메라를    │
│ AI 성우·그림으로  │ 자르고 자막 자동  │ 구간을 뽑아 숏폼  │ 녹화하면 바로    │
│                  │                  │ 여러 개           │ 편집기로          │
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘
```

| 방법 | 회원이 하는 것 | 편집기가 하는 것 |
|---|---|---|
| **1. 텍스트로 영상 만들기** | 대본을 넣는다 — ⓐ 직접 쓰기/붙여넣기 ⓑ AI로 쓰기(회원 AI) ⓒ **공실 고르기**(매물 사진·숫자·표시광고 자동) ⓓ 이미 쓴 기사·유튜브 대본 가져오기 | 문장마다 클립 → AI 성우 → 사진·영상·AI 그림 자동 배치 → 자막 (지금 릴스 편집기 방식) |
| **2. 촬영한 영상으로 편집하기** | PC의 영상 파일 불러오기 (여러 개 가능) | 받아쓰기 → 문장 클립 → 무음·군더더기 표시 → 자동 자막 → 글을 지우면 영상도 잘림 |
| **3. 롱폼으로 자동 숏폼 만들기** | 긴 영상 하나 불러오기 (강의·매물 투어·유튜브 원본 등) + 몇 개 만들지(예: 3개) | 받아쓰기 → AI가 볼만한 구간 고르기(회원 AI가 글을 읽고 추천) → 숏폼 후보 여러 개(제목·자막·세로 화면 맞춤) → 회원이 고르고 다듬기 |
| **4. 영상 녹화하고 바로 편집하기** | 앱 안에서 녹화 — 화면 / 카메라 / 화면+카메라(작은 원), 마이크 | 녹화 파일을 PC에 저장 → 끝나면 바로 2번(촬영 영상 편집)과 같은 화면으로, 받아쓰기·자막까지 |

### 텍스트로 영상 만들기 — 단계 (방법마다 흐름이 다르다)

텍스트는 영상이 없는 데서 시작하므로 편집기 전에 성우부터 정한다. (촬영 영상 편집은 성우 단계 없이 받아쓰기부터.)

```text
비율 → 영상 스타일 → ① 대본 → ② AI 목소리 → ③ 화면 자료·자막·음악 → ④ 자동 만들기 → 편집 화면
```

| 단계 | 내용 |
|---|---|
| ① 대본 | 직접 쓰기 / AI로 쓰기(주제만 넣으면 회원 AI가) / 공실 고르기 / 기존 기사·유튜브 대본. 문장마다 한 클립으로 미리 나눠 보여 줌 |
| ② AI 목소리 | 성우 고르기(여성 6·남성 6, 지금 릴스의 12가지) · **▶ 미리듣기**(대본 첫 문장) · **빠르기 0.8~1.5배**(기본 1.0, 쇼츠 1.1~1.2) · 문장 사이 쉬는 시간 · "성우 없이"도 가능. 편집기에서 클립마다 목소리·빠르기를 따로 바꿀 수 있음 |
| ③ 화면 자료 | 공실 사진 / 내 사진·영상 / AI 그림(기본 이미지 AI)을 문장마다 자동 배치, 자막 틀, 배경 음악 |
| ④ 자동 만들기 | 성우 녹음·자료 배치를 마치고 편집 화면을 연다 (점점점 + 걸린 시간) |

- 빠르기는 소리 높낮이를 바꾸지 않고 속도만 바꾼다 (녹음된 성우를 FFmpeg로). 빠르기가 바뀌면 클립 길이·자막 시간도 다시 맞춘다.
- 나머지 세 방법의 단계도 같은 식으로 정한다 (다음 회의).

네 방법 모두 **같은 편집기·같은 프로젝트 형식**으로 들어간다. 그래서 녹화 영상에 AI 성우 문장을 끼우거나, 텍스트 영상에 촬영 클립을 섞을 수 있다.

### ② 화면 비율 (5가지 중 하나 — 브루와 같음, 2026-10-15 사장님)

| 비율 | 크기 | 주로 쓰는 곳 |
|---|---|---|
| **16:9** (가로) | 1920×1080 | 유튜브, 강의, 매물 투어 |
| **9:16** (세로) | 1080×1920 | 릴스, 쇼츠, 틱톡 |
| **1:1** (정사각) | 1080×1080 | 인스타그램 피드, 카카오·블로그 |
| **4:5** (세로 피드) | 1080×1350 | 인스타그램 피드 세로 (피드에서 가장 크게 보임) |
| **4:3** (가로) | 1440×1080 | 블로그·카페 본문, 매물 설명 영상 |

- 고르는 자리: 브루처럼 **텍스트로 만들기 ③ 비디오 꾸미기**에서 (다른 방법은 시작할 때). 편집 중에도 바꿀 수 있다.

- 방법에 따라 처음 고르는 값을 미리 정해 둔다: 롱폼→숏폼은 9:16, 녹화는 16:9, 나머지는 마지막에 쓴 비율.
- 편집하다가 비율을 바꿀 수 있다 (자막·스티커 위치는 비율별로 다시 맞춤, 영상은 가운데 기준 잘라 맞춤 + 회원이 위치 조정).
- 롱폼→숏폼은 원본이 16:9여도 9:16으로 만들고, 말하는 사람이 가운데 오게 화면을 따라가는 자르기는 나중 단계.

## 10-1. 화면 자료 찾기 (2026-10-15 사장님 결정: 무료 사이트 + 공실뉴스 자료 창고)

텍스트로 만들 때 문장(클립)마다 맞는 사진·영상을 **자동으로** 붙인다. 분석은 두 군데서 한다.

### ① 대본 분석 — 문장마다 "어떤 화면이 필요한지"

- 대본을 쓸 때 **회원 AI가 문단마다 화면 설명 · 검색어 · 종류(사진/영상)를 같이 쓴다** (같은 요청 안에서, 추가 비용·시간 없음).
  - 예) "강남역 도보 5분 역세권 오피스텔" → 화면: 역 출구 앞 거리, 출퇴근 인파 / 검색어: `subway station exit, Seoul street, commuters` / 종류: 영상
- 직접 쓴 대본·가져온 글이면 [다음]을 누를 때 회원 AI가 이 칸만 한 번에 채운다.
- 숫자·주소 등 개인정보는 검색어에 넣지 않는다.

### ② 자료 찾기 — 순서대로 찾고 걸러서 넣기

| 순서 | 어디서 | 찾는 법 |
|---|---|---|
| 1 | **공실 사진** (공실로 쓴 대본) | 그 매물 사진 그대로 — 가장 정확 |
| 2 | **공실뉴스 자료 창고** (서버) | 창고 설명·태그를 "뜻으로 찾기"(벡터 검색) |
| 3 | **무료 사이트** (Pexels · Pixabay · 사진은 Unsplash 등) | 영어 검색어로 찾고 **비율**(세로/가로) · **길이**(영상이 클립보다 길게) · **화질**로 거름 |
| 4 | **AI 그림** (회원 이미지 AI: ChatGPT · Gemini) | 위에서 못 찾은 문장만 (한 장 약 30초) |

- 같은 자료가 여러 클립에 겹치지 않게 고른다.
- 편집 화면에서 클립마다 **[다른 자료로 바꾸기]** → 후보 몇 개 중 고르기, 내 사진·영상으로 바꾸기.
- 무료 사이트 검색은 서버를 거쳐 한다 (사이트 API 키를 앱에 넣지 않음, 같은 검색은 잠시 보관해 재사용).
- 내려받은 자료는 프로젝트 폴더에 저장 (다시 열 때 그대로).

### ③ 공실뉴스 자료 창고 — 올릴 때 딱 한 번 분석

- 공실뉴스(최고관리자)가 사진·영상을 창고에 올린다 → 서버가 **AI로 한 번 보고** 설명·태그·종류·비율·길이를 자동으로 붙인다 (영상은 몇 장면을 뽑아서 본다).
  - 예) "서울 아파트 단지 저녁 전경, 드론, 가로" / 태그: 아파트, 야경, 드론, 단지
- 설명을 **뜻으로 찾기**가 되게 저장 (Supabase pgvector). "역세권"으로 찾아도 "지하철역 출구" 영상이 나온다.
- 이 분석만 공실뉴스 서버 AI 비용이 든다 — 자료 하나에 한 번, 아주 적다.
- 창고 관리 화면 (최고관리자): 올리기 · 설명/태그 고치기 · 지역(구·동)·종류(아파트·오피스텔·상가·빌딩·거리·역세권·드론·실내) 분류 · 쓰인 횟수.
- 왜 중요한가: 무료 사이트엔 **한국 아파트·오피스텔·지하철역·강남 거리** 화면이 거의 없다. 공실뉴스가 직접 찍은 **드론·역세권 거리 영상**이 공실뉴스만의 강점이 된다.
- 저장: Supabase Storage (원본) + 미리보기용 작은 사본·썸네일. 회원 앱은 필요한 것만 내려받는다.

### ④ 지킬 것

- 무료 사이트는 상업 이용이 무료지만 **사이트마다 조건이 다르다** — 정식으로 넣기 전에 각 약관 확인 (출처 표시 필요 여부 · 인물·상표가 나오는 자료 · 재배포 금지 등).
- 창고에는 **공실뉴스가 권리를 가진 자료만** (직접 촬영 · 구매 · 사용 허락받은 것). 사람 얼굴·차 번호판이 또렷한 자료는 흐림 처리 또는 제외.
- 자료마다 출처·권리 메모를 남긴다.

## 11. 굽기 (렌더링)

- 기본은 **PC에서**. 컷(원본 구간 잇기)은 FFmpeg, 자막·스티커·효과는 틀(HTML)로 그려 겹친다.
  - 0단계에서 두 방법을 시험: A) hyperframes 도구를 앱에서 실행, B) 앱 숨은 창에서 틀을 재생하며 프레임 떠서 FFmpeg로 잇기.
- 출력: 9:16 1080×1920 · 16:9 1920×1080 · 1:1 1080×1080, H.264/AAC MP4 (+ SRT 자막 파일).
- 그래픽카드 가속(NVENC·QSV·AMF) 자동 → 실패 시 일반 인코딩(OpenH264·MediaFoundation)으로 다시.
- 진행률·남은 시간, 꺼져도 이어 굽기.

## 12. 단계

| 단계 | 내용 | 끝났다고 보는 기준 |
|---|---|---|
| **0. 검증** (1~2일) | 로컬 영상 재생(studio-media://), FFmpeg 프록시·파형, 받아쓰기 정확도·시간, 틀 → MP4 굽기 시간, 앱 안 화면·카메라 녹화 | 10분 영상 받아쓰기 1분 안팎, 30초 영상 보통 PC에서 2분 안에 굽기 |
| **1. 시작 화면 + 편집기 뼈대** | 시작 화면(방법 4가지 · 비율 5가지 · 최근 프로젝트) → 편집기 → 클립 나누기·자르기·순서 → 미리보기 → PC 굽기 → 폴더 | 네 방법 모두 편집기까지 들어가고, 서버 없이 컷 편집 영상 완성 |
| **2. 촬영한 영상으로 편집 (브루식 핵심)** | 받아쓰기 → 문장 클립·단어 자막 → 글 지우면 영상 잘림 → 무음·군더더기 한 번에 지우기 → 자막 스타일 | 1시간 촬영본을 글로 편집해 10분 영상 |
| **3. 영상 녹화하고 바로 편집** | 화면 / 카메라 / 화면+카메라, 마이크 → PC 저장 → 2번 흐름으로 | 녹화 끝나고 바로 자막 달린 편집 화면 |
| **4. 텍스트로 영상 만들기** | 대본(직접·회원 AI·공실·기존 기사/유튜브 대본) → 성우 + 화면 자료 자동(공실 사진 → 자료 창고 → 무료 사이트 → AI 그림, 10-1장), 자료 창고 관리 화면 | 공실 하나로 16:9·9:16·1:1 영상을 각각 완성 |
| **5. 롱폼으로 자동 숏폼** | 받아쓰기 → 회원 AI가 구간 추천 → 숏폼 후보 여러 개 → 고르고 다듬기 | 30분 영상에서 9:16 숏폼 3개 |
| **6. 꾸미기·더하기** | 전환·효과·스티커·음악 줄·소리 크기, 틀 추가, 내 목소리 녹음, 번역 자막, SRT 내보내기, 완성본 올리기·SNS 연결, 프로젝트 백업 | 브루 기본 기능 수준 |

## 13. 정할 것 (제 권고)

1. **받아쓰기 엔진** → 서버(소리만)로 시작. PC 받아쓰기는 나중 선택지 (빠른 PC용, 무료).
2. **받아쓰기·성우 비용** → 공실스터디 멤버십에 포함, 무료 회원은 월 시간 제한 (예: 받아쓰기 월 30분).
3. **첫 틀(자막·스티커 모양)** → 비율마다 기본 틀 1개씩 (16:9 · 9:16 · 1:1 · 4:5 · 4:3). 9:16은 지금 릴스 틀을 그대로 쓴다.
7. **단계 순서** → 촬영 영상 편집(브루식 핵심) → 녹화 → 텍스트 → 롱폼→숏폼. 시작 화면에는 네 개를 처음부터 다 보이고, 아직 안 된 것은 "준비 중"으로.
4. **편집 화면** → 서버의 웹 화면을 앱 안에서 연다 (다른 메뉴와 같은 방식). 로컬 파일은 앱 통로로만. 앱 밖 웹 브라우저에서는 열리지 않거나 "앱에서 열기" 안내.
5. **완성본 올리기** → 회원이 [공실뉴스에 올리기]를 누를 때만.
6. **기존 웹 `/reels`** → 3단계에서 편집기로 옮길 때까지 웹에서 그대로 둔다.

## 14. 지킬 것

- 원본 영상을 서버에 올리지 않는다 (받아쓰기는 소리만).
- 서버 비밀키를 앱에 넣지 않는다. 로컬 절대경로를 서버에 보내지 않는다.
- FFmpeg 인자는 배열로 (경로를 명령 문자열에 끼우지 않음).
- 표시·광고 필수 항목, 호수·연락처 차단은 영상에도 그대로.
- FFmpeg LGPL 고지와 대응 소스 안내 (설치 파일·앱 정보 화면).
- 편집기 안 용어: 장면 대신 **클립**.
