- 날짜: 2026-11-05 (사장님 회의, "알았어 그럼 내일 할 수 있게 md 만들어줘")
- 상태: **방향 확정.** 내일 이 문서 순서대로 시작한다.
- 바뀐 점: 11-01 일반판 계획(코드 하나 + 앱 안 "부동산판/일반판" 스위치)을 **서버·DB·저장소까지 완전히 따로**로 바꿈.

## 1. 정한 것

| 항목 | 정한 내용 |
|---|---|
| 무엇 | 공실마케팅studio 앱을 공실뉴스에서 떼어 **따로 파는 마케팅 스튜디오** |
| 누가 쓰나 | **자영업자** (카페·음식점, 미용실·네일, 학원, 꽃집, 소매점 등) |
| 나중에 | **전 세계 사람**이 쓰게 (언어팩) |
| 이름 | **SSAM Marketing Studio** (한국에서는 "쌤 마케팅 스튜디오") — 영어 이름이라 세계판에도 그대로 |
| 형태 | **설치하는 앱** (윈도우 먼저, 맥은 영어판 때). 웹은 소개·가입·결제·앱 받기만 |
| 서버·DB | **공실뉴스와 따로** — 새 Supabase · 새 Vercel · 새 GitHub 저장소 |
| 공실뉴스 쪽 | 그대로 웹 + 크롬 확장. 이번 일로 공실뉴스 코드는 건드리지 않는다 |
| 부동산 기능 | 기본에서 뺀다. 나중에 "부동산 팩"(공실뉴스 계정 연결)으로만 |

### 설치 앱으로 가는 이유
- 동영상 편집·굽기는 PC 힘을 써야 빠르다
- 사진·영상·작업 파일을 PC 폴더에 바로 저장·열기
- 화면 캡처·녹화, 전용 글꼴
- 앱은 확장 없이 ChatGPT·Gemini 창을 직접 다룬다 (자영업자가 확장을 따로 깔 필요 없음)
- 지금 앱(`studio-app`)이 이미 이렇게 만들어져 있어 이어 쓸 수 있다

## 3. 내일 제가 할 일 (순서)

### 3-1. 새 저장소 만들기 (공실뉴스 저장소는 그대로)
- 지금 저장소에서 앱에 필요한 것만 **복사**해 새 저장소의 뼈대를 만든다
  - `studio-app/` — Electron 앱 본체 (설치·자동 업데이트·창 관리·AI 창 다루기·캡처)
  - `src/components/admin/studio-video/` · `src/lib/studio-video/` — 동영상studio
  - `src/components/admin/studio-photo/` — 포토studio
  - `src/components/admin/studio-doc/` — 문서 편집
  - SNS 글쓰기에 필요한 프롬프트·채우기 부분 (`studio-app/prompts`, `chrome-extension/gongsilwriter30/helper` 의 채우기 코드 참고)
- 공실·부동산 부분을 걷어 낸다: 공실관리·기사관리·물건접수홈페이지·보고서·홍보지·공실뉴스 에피소드·단지 시세·부동산 표시광고 그래픽
- 작업 파일(.gsn 등)은 그대로 열리게 둔다 (파일 호환)

### 3-2. 처음부터 해 둘 것 (세계판 준비)
- **화면 글을 언어 파일로** (`ko.json` 먼저, 나중에 `en.json` …). 11-01 기준 한국어 글 줄 수: 동영상 약 4,500 · 포토 약 1,400 · 앱 약 2,300
- **올릴 곳(채널)을 부품처럼** — 한국: 네이버 블로그·인스타그램 / 해외: 인스타그램·페이스북·틱톡·구글 비즈니스 프로필·유튜브
- **AI 는 회원 본인 계정** (ChatGPT·Gemini) — 서버 AI 쓰지 않음. 글은 회원이 고른 언어로
- 돈·날짜·단위·주소·전화 형식은 설정으로 (한국에 박아 두지 않음)

### 3-3. 새 Supabase 표 (처음 것)
- `profiles` — 회원 (이름, 언어, 나라)
- `shops` — 내 가게 (이름, 업종, 위치, 영업시간, 대표 메뉴·상품, 사진)
- `subscriptions` — 이용권·결제
- `usage` — 무료 횟수 세기
- (원본 사진·영상·작업 파일은 서버에 두지 않고 회원 PC — 공실뉴스 때와 같은 원칙)

### 3-4. 새 Vercel (웹)
- 소개 페이지 · 가입/로그인 · 결제 · 앱 받기 · 계정 관리만

## 4. 1단계 (한국 자영업자판) 기능

공실 자리에 **"내 가게"** 를 넣는다.

| 지금 (부동산) | SSAM (자영업자) |
|---|---|
| 공실 등록 | **내 가게 등록** — 이름·업종·위치·영업시간·대표 메뉴·사진 |
| 공실로 기사·블로그·SNS | **신메뉴·이벤트로 블로그·인스타그램·스레드·페이스북 글 한 번에** |
| 매물보고서·유리창홍보지 | **메뉴판 · 전단 · 가게 앞 배너 · 쿠폰** |
| 공실 영상뉴스 | **릴스·쇼츠 홍보 영상** (사진 + AI 성우 + 자막) |
| 포토studio | **인스타 카드뉴스 · 썸네일 · 명함** (업종별 템플릿) |
| 물건접수홈페이지 | (나중) 가게 한 장짜리 홈페이지 · 예약·문의 |

**첫 판에 먼저 낼 세 가지**
1. 신메뉴·이벤트 → 인스타그램·블로그 글 한 번에 (앱이 AI 창·글쓰기 칸을 직접 채움)
2. 릴스·쇼츠 영상 (사진 몇 장으로)
3. 메뉴판·전단·카드뉴스 (업종 템플릿 + 가게 정보 자동)

업종 템플릿 순서: 카페·음식점 → 미용실·네일 → 학원 → 꽃집 → 소매점
