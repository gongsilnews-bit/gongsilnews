## 1. 세 SNS는 글 모양이 완전히 다르다

블로그를 짧게 줄인다고 SNS 글이 되지 않는다. 플랫폼마다 **보이는 방식·글자 수·링크·해시태그 규칙**이 다르다.

| | 페이스북 | 인스타그램 | 스레드 |
|---|---|---|---|
| 중심 | 글 + 링크 | **사진** (글은 설명) | **짧은 글** |
| 글자 수 | 사실상 제한 없음 (앞 2~3줄만 보이고 "더 보기") | 캡션 최대 2,200자 | 글 1개 최대 500자 |
| 링크 | 클릭 가능, 미리보기 카드가 뜸 | **캡션 링크는 클릭 안 됨** → "프로필 링크" 안내 | 클릭 가능 |
| 해시태그 | 3~5개면 충분 | 5~15개 (최대 30개) | **글 하나에 주제 태그 1개** |
| 사진 | 선택 (1~4장 좋음) | **필수** · 세로 4:5(1080×1350) 권장 · 여러 장 넘김 | 선택 |
| 어울리는 말투 | 소식 전달 + 정보 | 핵심만 짧게, 줄 바꿈 많이 | 대화하듯, 질문으로 끝내기 |

※ 글자 수·태그 수는 개발 직전에 각 플랫폼 최신 기준으로 다시 확인한다.

## 2. 플랫폼별 글 구성 (제안)

공통 원칙: **블로그와 같은 객관 보도 형식** — "공실뉴스에 이런 매물이 나왔다". 과장 광고 문구("급매! 놓치면 후회!") 금지,
중개사무소 정보는 끝에 출처로. 2번 기사에 없는 숫자·사실은 만들지 않는다.

### 2-1. 페이스북 — "기사 소개 + 링크"

```
[첫 줄: 결론 한 문장 — 더 보기 전에 보이는 곳]
양재역 도보 5분, 36평 사무실이 공실뉴스에 나왔습니다.

[본문 3~5문단, 문단은 2~3줄]
위치·면적·가격 → 특징 → 주변 교통·상권

[링크]
▶ 기사 전문: (공실뉴스 기사 주소)

[출처] 자료: 공실뉴스 · ○○공인중개사사무소
#양재역사무실 #서초구사무실 #공실뉴스
```

- 길이 3~6백 자. 링크 미리보기 카드가 사진 역할을 하므로 사진은 선택.
- 부동산 **페이스북 그룹**(지역 카페 같은 곳)에 올리기도 좋은 형식.

### 2-2. 인스타그램 — "사진 여러 장 + 짧은 캡션"

```
[첫 줄: 훅 — 피드에서 잘리기 전에 보이는 곳]
양재역 5분, 36평 사무실 📍

[핵심 정보 3~5줄, 줄마다 하나씩]
📐 전용 119㎡ (약 36평)
💰 보증금 ○ / 월 ○
🚇 양재역·신분당선 도보 5분
✅ 룸·회의실, 시스템에어컨

[행동 안내]
자세한 내용은 프로필 링크 → 공실뉴스

[출처] + 해시태그 8~12개 (지역·매물종류·용도)
```

- 사진은 2번 기사의 사진을 **4:5로 잘라** 순서대로(대표 → 내부 → 위치) 내려받게 한다.
- 2단계 아이디어: **카드뉴스**(표지 + 핵심 정보 카드 + 사진)를 이미지로 만들어 주기. 인스타그램에서 가장 반응이 좋은 형식이지만 작업량이 크니 1단계에서는 빼자.

### 2-3. 스레드 — "짧은 글 + 이어 쓰기"

```
[글 1 — 500자 이내, 이것만 읽어도 이해되게]
양재역 도보 5분 거리에 36평 사무실이 나왔네요.
룸·회의실까지 갖춰져 있어서 10~15명 팀이면 바로 들어갈 수 있는 구조입니다.
보증금 ○, 월 ○.
이 가격이면 요즘 양재 시세에서 어떻게 보이세요?

[글 2 — 선택, 이어 쓰기]
교통·주변 정보 + 기사 링크

주제 태그 1개: #양재역사무실
```

- 말투는 대화하듯, **질문으로 끝내서 댓글을 유도**한다. 단 사실 원칙은 같다.
- 이어 쓰기는 1~3개. 링크는 마지막 글에.

## 2-4. 사진 — 플랫폼마다 다시 고르고, 비율에 맞게 잘라 준다 (제안)

글처럼 사진도 플랫폼마다 쓰는 방식이 다르다. 2번 기사 사진을 **원자료**로 가져와 플랫폼별로 다시 정리한다.
블로그가 지금 기사 사진을 복사해 따로 갖는 것과 같은 방식이다 — SNS 에서 사진을 바꿔도 기사·블로그 사진은 그대로다.

| | 페이스북 | 인스타그램 | 스레드 |
|---|---|---|---|
| 사진 필요 | 선택 (기사 링크를 넣으면 미리보기 카드가 사진 역할) | **필수** | 선택 |
| 장수 | 1~4장 | 5~10장 (넘겨 보기) | 1~4장 |
| 비율 | 정사각 1:1 (1080×1080) | **세로 4:5 (1080×1350)** | 원본 비율 |
| 순서 | 대표 → 내부 | 대표 → 내부 → 시설 → 위치·지도 | 대표 1장 중심 |

- **자동 정리:** 기사 사진에서 장수만큼 골라 위 순서로 놓고, 비율에 맞게 가운데를 잘라 미리보기로 보여 준다.
- **손으로 고치기:** 블로그처럼 사진마다 [대표지정] [사진 바꾸기] [삭제], 순서 바꾸기.
- **내려받기:** 인스타·페이스북은 잘린 사진을 순서 번호를 붙여 한 번에 내려받는다 (`01_대표.jpg`, `02_내부.jpg` …).
- **인스타 표지 (선택):** 1번 사진 위에 제목 한 줄("양재역 5분 · 36평 사무실")과 공실뉴스 표시를 얹은 표지 1장을 만들어 준다.
  카드뉴스 전체는 2단계로 미루되, 표지 한 장은 가볍게 만들 수 있어 1단계에 넣을 만하다.

### AI 이미지 만들기 — 지금처럼 쓸 수 있다

하단 바의 [🎨 AI 이미지 만들기 ▾]와 [🖼️ 이미지 삽입]을 SNS 에서도 그대로 쓴다.
다르게 하는 것은 **플랫폼 비율로 요청**하는 것 하나다 (인스타 4:5, 페이스북 1:1).

**주의 — 매물 사진을 AI 로 대신하지 않는다.**
매물 광고에서 AI 가 그린 실내·건물 사진을 실제 사진처럼 쓰면 실제와 다른 매물로 오해받을 수 있다 (표시·광고 문제).

- AI 이미지는 **지역 분위기·교통·통계 도표·안내 그림**에만 쓴다.
- AI 이미지에는 "AI 생성 이미지" 표기를 붙인다.
- **대표 사진(인스타 1번)에는 AI 이미지를 쓰지 않는다** — 실제 매물 사진이 있으면 그것이 대표.

## 2-5. 영상 — 세로 쇼츠 1편을 세 곳에 함께 쓴다 (제안)

세 SNS 모두 지금 영상을 가장 많이 보여 주는 자리는 **세로(9:16) 짧은 영상**이다
(인스타 릴스 · 페이스북 릴스 · 스레드 글의 영상). 그래서 플랫폼마다 영상을 따로 만들지 않는다.

| | 페이스북 | 인스타그램 | 스레드 |
|---|---|---|---|
| 넣는 곳 | 릴스, 또는 일반 글에 영상 | 릴스 (사진과 섞은 넘겨 보기도 가능) | 글에 영상 첨부 |
| 권장 모양 | 세로 9:16 · 1080×1920 | 세로 9:16 · 1080×1920 | 세로 9:16 또는 원본 |
| 권장 길이 | 30~60초 | 30~60초 | 30~60초 |
| 유튜브 링크 | 붙이면 미리보기 카드로 재생 | **링크 안 됨** → 영상 파일을 직접 올려야 함 | 붙이면 미리보기 카드 |

※ 플랫폼별 최대 길이·용량은 계속 바뀐다. 개발 직전에 다시 확인한다.

### 영상은 어디서 오나

작성기(크롬 확장)는 **영상을 만들지 않는다.** 확장 안에서 영상을 만들면 무겁고 품질도 낮다.

1. **공실뉴스 영상제작 프로그램(studio2)에서 만든다.** 같은 기사로 유튜브용 가로(16:9)와 **SNS용 세로 쇼츠(9:16)**를 함께 뽑는다.
   (영상제작 프로그램 회의의 "가로·세로 동시 출력" 안건과 같은 이야기 — 그 결정이 여기서 쓰인다.)
2. 이미 올린 **유튜브 영상 링크**가 있으면 페이스북·스레드 글에는 링크로 붙인다.
3. 중개사가 직접 찍은 매물 영상 파일도 그대로 쓸 수 있다.

### 작성기가 해 주는 것

- 각 SNS 화면에 **[영상 넣기]**: 내 PC 의 영상 파일을 고르거나 유튜브 링크를 붙인다.
- 영상이 있으면 **글을 영상용으로 바꿔 쓴다** — 릴스 캡션은 더 짧게, 첫 줄은 "영상 첫 3초"와 같은 말로.
  유튜브 링크가 있으면 페이스북·스레드 글 끝에 넣고, 인스타는 "프로필 링크" 안내로 바꾼다.
- 영상 파일 자체는 1단계 원칙대로 **사용자가 각 사이트에 직접 올린다** (자동 업로드 없음).

## 2-6. 블로그에도 영상을 넣을 수 있나 (회의 중)

**넣을 수 있다.** 네이버 블로그 편집기(SmartEditor ONE)는 영상을 두 가지로 받는다.

| 방법 | 어떻게 | 작성기가 자동으로? | 네이버 검색 |
|---|---|---|---|
| A. 유튜브 링크 | 본문에 유튜브 주소를 붙이면 영상 카드로 바뀜 | **가능할 것으로 보임** — 지금 글·사진을 붙여넣는 방식 그대로 주소를 붙인다 (실제 편집기에서 시험 필요) | 영상은 유튜브 조회수로 쌓임 |
| B. 영상 파일 직접 올리기 | 편집기의 [동영상] 버튼 → 업로드 창 | **어렵다** — 사진과 달리 붙여넣기로 안 들어가고 업로드·변환 창을 거친다 | 블로그 자체 영상이라 네이버 검색 영상 노출에 유리할 것으로 보임 (확인 필요) |

블로그는 PC 에서도 많이 읽으므로 **가로 16:9 영상**(유튜브용 본편)이 어울린다. 세로 쇼츠는 SNS 용.

### 제안

1. **유튜브 링크는 자동으로 넣는다.** 3번 블로그 화면의 [영상 넣기]에 유튜브 주소를 넣으면,
   블로그 글의 정해진 자리(도입 다음 "▶ 영상으로 보기" 소제목 아래)에 함께 전송한다.
2. **영상 파일은 자리만 잡아 준다.** 파일을 고르면 그 자리에 "📹 여기에 영상을 올려 주세요" 안내 문구를 넣어 전송하고,
   사용자가 편집기 [동영상] 버튼으로 올린 뒤 안내 문구를 지운다.
3. 영상이 있으면 블로그 글에 영상 소개 2~3줄을 AI 가 함께 쓴다 (영상에서 무엇을 보여 주는지).

### 개발 전 확인할 것

- SmartEditor ONE 이 붙여넣은 유튜브 주소를 영상 카드로 바꾸는지, 지금의 숨은 붙여넣기 방식에서도 그런지 실제로 시험한다.
- 네이버 블로그 영상 업로드의 최대 길이·용량.

## 3. 화면 구성 — 탭을 7개로 늘릴 수 없다

작업창 폭이 좁아서 지금 4개 탭도 꽉 찬다. 탭 3개를 더하면 글자가 안 들어간다.

**제안: 3번 탭을 [3 블로그·SNS]로 바꾸고, 안에 4칸 선택 줄을 둔다.**

```
 1 물건·AI │ 2 초안 다듬기 │ 3 블로그·SNS │ 4 유튜브 대본
 ─────────────────────────────────────────────
  [ 블로그 ] [ 페이스북 ] [ 인스타 ] [ 스레드 ]   ← 선택 줄
 ─────────────────────────────────────────────
  (고른 것의 스타일 · 미리보기 · 하단 바)
```

하단 바는 지금 블로그와 같은 모양으로, 플랫폼만 바뀐다.

| | 왼쪽 버튼 | 오른쪽 버튼 |
|---|---|---|
| 블로그 | 블로그 바로가기 | 블로그글 전송하기 (지금 그대로) |
| 페이스북 | 페이스북 바로가기 | 글 복사하기 |
| 인스타그램 | 인스타그램 바로가기 | 캡션 복사 + 사진 내려받기 |
| 스레드 | 스레드 바로가기 | 글 복사하기 |

수정 요청 줄, [AI 이미지 만들기] · [이미지 삽입]은 블로그와 같이 쓴다.

## 4. SNS 3종은 AI 에 한 번에 요청 (제안)

블로그처럼 플랫폼마다 따로 AI 에 요청하면 3번 기다리고, 무료 체험 횟수도 3번 쓴다.

**제안: [SNS 3종 만들기] 한 번 → AI 가 페이스북·인스타·스레드 글을 한 답변에 함께 쓴다.**
그다음 선택 줄로 하나씩 보며 각자 수정 요청한다. 무료 체험은 "SNS" 1번으로 센다.

## 5. 글 넣는 방식 — 1단계는 "복사 + 바로가기"

| 방식 | 장점 | 위험 |
|---|---|---|
| A. 복사 + 바로가기 (사용자가 붙여넣기) | 확실히 동작, 계정 위험 없음 | 붙여넣기 한 번은 사람이 해야 함 |
| B. 블로그처럼 자동 채우기 | 편함 | 메타(페이스북·인스타·스레드) 글쓰기 화면이 자주 바뀌어 잘 깨지고, 자동 입력을 **비정상 활동으로 보고 계정을 제한**할 수 있음 |

**제안: 1단계는 A.** 써 보고 불편하면 2단계에서 페이스북부터 자동 채우기를 시험한다.
블로그(네이버)는 지금처럼 자동 채우기를 유지한다.
