# 공실뉴스 스튜디오 — AI 편집 "화면 채우기" 계획

- 작성: 2026-10-21 회의
- 결정: **AI 편집은 화면 채우기부터 집중한다.** 화면이 비어 있으면 자막·음악을 아무리 잘 골라도 영상이 안 된다.
- 꾸미기(테마·음악·자막·그래픽)는 화면 채우기가 끝난 뒤 **다음 차례**로 미룬다.
- 대상 파일: `src/components/admin/studio-video/AiEdit.tsx` (지금 AI 편집 창), 관련 회의 자료 `docs/2026-10-20_studio_ai_edit_meeting.md`

---

## 1. AI 편집을 2단계로

| 단계 | 하는 일 | 이번 작업 |
|---|---|---|
| **1단계 · 화면 채우기** | 영상 종류·화면 비율 → 채우는 순서 → [화면 채우기] → 오른쪽 **화면 편집판**에서 확인·고치기 | **이번에 만든다** |
| 2단계 · 꾸미기 | 테마(스타일 팩) / 음악 분위기 / 자막 스타일 / 정보 바 / 그래픽·효과음 — 각각 [AI에 맡기기] 또는 직접 고르기 → [AI 편집 시작] | 다음 차례 (지금 있는 스타일 팩 그대로 둠) |

- 1단계를 확인하고 넘어가는 것이 기본. [화면 채우기부터 끝까지 한 번에]도 둔다.

---

## 2. 왼쪽 — 채우기 설정

```
① 영상 종류   [매물 소개] [뉴스·보도자료] [자유 주제]
   화면 비율  [쇼츠·릴스 9:16] [유튜브 16:9] …   (위쪽 화면 비율 단추와 같은 값)
② 채우는 순서 (순서마다 켜기·끄기)
   1. 내 사진·영상   ✓  넣는 방식 [AI가 문장에 맞춰] [넣은 순서대로]   [PC에서 추가] [내 자료] [공실 불러오기]
   2. 무료 영상·사진 ✓
   3. 그래도 빈 곳   (●) AI 그림  스타일 [스타일 팩에 맞춤 ▾ / 심리학 · 공실이 · 실사 · K-웹툰 …]  최대 [2][4][8][12]장
                    ( ) 빈칸으로 두기
   [화면 채우기]
```

- **순서 고정:** 내 사진·영상 → 무료 영상·사진 → (회원이 고른) AI 그림 또는 빈칸. (2026-10-21 결정)
- **내 사진·영상이 모자랄 때:** 회원이 고른다 — 빈 곳은 **빈칸으로 두기** 또는 **AI 그림 만들기**. (결정 2)
- **AI 그림 스타일 고르기:** [AI 사진] 칸과 같은 스타일 칸(같은 부품)을 쓴다. 맨 앞 [스타일 팩에 맞춤]이 기본. 지금 저장값 `aiStyle: "auto"`를 쓴다. AI 사진 칸과는 따로 기억한다.
- **내 영상이 그 문장보다 짧을 때:** 영상 마지막 장면에서 멈춘다. (결정 3)
- 회원이 이미 넣어 둔 화면은 건드리지 않는다 (지금 규칙 그대로).

## 3. 오른쪽 — 화면 편집판

```
[+ 인트로]                                  ← 기본 인트로가 정해져 있으면 자동으로 들어가 있음
 1 [🖼 내 사진]  조용한 골목입니다.           [바꾸기 ▾] [🗑]
 2 [무료]       하나님의 사랑이…              [바꾸기 ▾] [🗑]
   ── [+ 중간 쉼] ──
 3 [빈칸]       …                             [+ 넣기 ▾]
 4 [AI 그림]    …                             [바꾸기 ▾] [🗑]
[+ 아웃트로]                                ← 기본 아웃트로 자동
[📋 표시·광고 정보 화면]                     ← 켜기·끄기 (매물 소개 = 기본 켬)
```

- 클립마다 **어디서 온 화면인지** 표시: 내 사진 / 내 영상 / 무료 / AI 그림 / 매물 사진 / 빈칸
- **[🗑]** — 화면만 빼서 빈칸으로 (글·목소리는 그대로)
- **[바꾸기 ▾] · [+ 넣기 ▾]** — 내 PC / 내 자료 / 무료 검색 / AI 그림 1장 / 매물 사진
- 바꾼 것은 [화면 채우기]를 다시 눌러도 덮어쓰지 않는다 (회원이 고른 것 우선)

### 넣기 칸 (2026-10-21 결정)

| 칸 | 내용 | 보관 | 넣는 법 |
|---|---|---|---|
| **인트로** | 채널 이름·로고 2~3초 | 회원이 만들어 **내 자료(내 영상·사진)**에 보관 | ① [기본 인트로]로 정해 두면 AI 편집 때마다 자동 ② 화면 편집판 [+ 인트로]로 직접 — **둘 다** (결정 1) |
| **아웃트로** | 구독·좋아요·다음 영상 안내 | 내 자료 | 인트로와 같음 |
| **표시·광고 정보 화면** | 중개사무소 이름·등록번호·대표·연락처 (기존 "부동산 표시광고" 그래픽) | — | **회원이 켜고 끈다** — 기본값: 매물 소개 = 켬, 뉴스·자유 = 끔 (결정 2) |
| **중간 쉼** | 클립 사이 짧은 쉼 | **하나의 클립** — 내 자료에 보관해 다시 씀 (결정 3) | 클립 사이 [+ 중간 쉼] |

- 인트로·아웃트로·중간 쉼은 내 자료 안에서 따로 모아 볼 수 있게 표시를 단다 (예: 내 자료 › [인트로] [아웃트로] [쉼] 칩).

## 4. 만드는 순서

1. **화면 편집판** — 오른쪽 클립별 출처 표시 + [바꾸기] [🗑] [+ 넣기]
2. **채우기 순서** — 내 사진·영상 → 무료 → AI 그림(스타일 고르기) / 빈칸, 순서마다 켜기·끄기
3. **짧은 영상 처리** — 마지막 장면에서 멈춤
4. **넣기 칸** — 인트로·아웃트로(기본값 + 직접) · 표시광고 켜기·끄기 · 중간 쉼(클립)
5. (다음 차례) 2단계 꾸미기 — 테마 미리보기 · 세로 테마 추가 · 유튜브 패턴 조사

## 6. 구현 현황 (2026-10-21, 테스트 전)

| 항목 | 상태 |
|---|---|
| 왼쪽 순서: ① 영상 종류 + **화면 비율** → ② **화면 채우기** → ③ 인트로·아웃트로·표시광고 → 꾸미기(스타일 팩 등, 아래로) | 만듦 |
| 채우는 순서 고정 — 내 사진·영상 → 무료(켜기·끄기) → 그래도 빈 곳 [AI 그림 / 빈칸 / 내 사진 다시] | 만듦 (`fillCore`) — [화면 채우기]·[AI 편집 시작] 둘 다 같은 엔진 |
| AI 그림 스타일 고르기 ([스타일 팩에 맞춤] + AI 사진 칸 스타일, 9개 → [모두 보기]) | 만듦 (`aiStyle`) |
| **[화면 채우기]** — 꾸미기 없이 화면만, 한 번에 되돌리기 | 만듦 (`fillOnly`) |
| 짧은 영상 — 화면 채우기로 넣은 것만 마지막 장면에서 멈춤 (예전 클립은 2026-10-18 결정대로 반복) | 만듦 (`clip.visualHold` · Player · render.js) |
| 오른쪽 **화면 편집판** — 출처 표시(내 화면·무료·AI 그림·매물 사진·빈칸) · [바꾸기 ▾](넣은 사진·내 자료·PC·무료 찾기·AI 그림 1장·빼기) · 🗑 | 만듦 |
| 인트로·아웃트로 — 기본값(내 자료) + 자동 / 편집판 [인트로 넣기]·[아웃트로 넣기] | 만듦 (`clip.card` intro·outro) |
| 중간 쉼 — 클립 사이 [+ 중간 쉼] (앞 화면 이어서 · 내 자료 · 검은 화면, 1초) | 만듦 (`clip.card` pause) |
| 표시·광고 끝 화면 — 회원이 켜고 끔, 기본값 매물 소개 = 켬 | 만듦 (`endCard`) — 만들어지는 때는 [AI 편집 시작] |
| 내 자료에 인트로·아웃트로·쉼 표시 칩 | **아직** |
| 중간 쉼 길이 고르기 | **아직** (1초 고정) |

- 앱 쪽(`render.js`)을 고쳤으므로 짧은 영상 멈춤은 내보낼 때 앱을 다시 켜야 적용된다.

## 7. AI 요청 3단계로 (2026-10-21 회의 결정)

> AI 편집 = 클립마다 화면을 먼저 쭉 깔아 두는 것 (레이아웃 컷편집을 쉽게). 세부는 클립 편집 칸에서.

| 단계 | 하는 일 | AI 요청 |
|---|---|---|
| ② 내 사진·영상 채우기 | 회원이 사진·영상 등록 → **직접 넣기**(화면 편집판) 또는 **[AI로 맞춰 넣기]**(대본에 맞게). 영상은 **앞뒤 자르기** | 1번 (선택) |
| ③ 빈 곳 채우기 | 화면 편집판에서 빈칸을 고르고(안 고르면 빈칸 모두) **[빈 곳 AI로 채우기]** — 무료 → AI 그림 → 내 사진 다시 | 2번 |
| 꾸미기 | 자막·정보 바·음악·그래픽 설정은 저장 → **[AI 편집 시작]** — 화면은 건드리지 않음 | 3번 |

- **AI 동영상은 나중에** (지금은 AI 그림만). 붙일 때: 회원 로그인(Sora·Veo) 또는 회원 키 — 별도 회의.
- **앞뒤 자르기**: `clip.visual.e` (끝). 쓰는 부분이 문장보다 짧으면 끝 장면에서 멈춤, 길면 문장 길이까지만. 창에서 "쓰는 길이 / 문장 길이"를 견줘 보여 준다. 편집 화면(썸네일 메뉴)과 화면 편집판이 같은 창(`VideoStart`)을 쓴다.
