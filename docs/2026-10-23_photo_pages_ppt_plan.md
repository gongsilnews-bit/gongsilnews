# 보고서를 디자인 그대로 고치기 — 이미지 편집 여러 쪽 · PPT (2026-10-23 사장님 회의)

## 정한 것
- AI 매물보고서 · 인테리어/리모델링 예측 보고서를 **디자인이 깨지지 않게** 열어 고치는 곳은 **이미지 편집**.
  (이미지 편집 = 글자·사진·도형 레이어를 제자리에 두는 편집기 = PPT 슬라이드와 같은 구조)
- 바깥 프로그램(파워포인트·구글 슬라이드·한컴 쇼)과 주고받는 형식은 **PPT(.pptx)** — PSD 를 포토샵과 주고받는 것과 같은 자리.
- 워드(.docx) 저장 · 문서편집에 "떠 있는 개체" 넣기는 미룬다. 문서편집은 계약서·확인설명서 같은 글 문서용.
- 외부 PPT 뷰어(인터넷에 파일을 올리는 방식)는 쓰지 않는다 — 매물·손님 정보가 밖으로 나간다.

## 순서
1. **이미지 편집 여러 쪽 문서** — 쪽 목록(고르기·순서 바꾸기·더하기·지우기). 지금은 파일 하나 = 한 장, 보고서는 최대 8쪽.
2. **보고서 → [이미지 편집에서 열기]** — 화면에 그려진 보고서를 쪽마다 레이어로: 글 → 글자 레이어(같은 글꼴·크기·색·굵기),
   사진 → 사진 레이어, 색 칸·선 → 도형 레이어, 도형으로 못 옮기는 장식(그라데이션 등)만 그림. 변환기 하나로 세 보고서 모두.
3. **PPT 저장** — 레이어 → 슬라이드의 글 상자·그림·도형 (A4 가로 슬라이드, 1쪽 = 1장). 글꼴을 파일 안에 넣는 것 시험.
4. **PPT 열기** — 우리가 저장한 PPT는 그대로. 다른 PPT는 글·그림·기본 도형까지 (차트·애니메이션은 빠질 수 있음).

## 위험
- 글꼴: 보고서 글꼴이 없는 PC에서 PPT를 열면 바뀌어 줄이 넘칠 수 있다 → PPT 안에 글꼴 넣기 시험, 안 되면 차선책.
- PSD 는 한 장짜리 형식 — 여러 쪽 문서를 PSD 로 저장할 때는 쪽마다 파일 (또는 지금 쪽만). 정해서 적을 것.
