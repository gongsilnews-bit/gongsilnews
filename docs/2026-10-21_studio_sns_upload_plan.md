# 공실뉴스 스튜디오 — 완성 영상 SNS 올리기 계획 (반자동, 크롬)

- 작성: 2026-10-21 회의
- 결정: **방법 A — 스튜디오 전용 크롬을 띄워 반자동으로.** 앱이 파일 첨부·글 채우기까지 하고, **마지막 [게시]는 회원이 직접 누른다.**
- 대상: 부동산 회원이 **각자 자기 계정**(유튜브 채널·인스타그램)에 올린다. 공실뉴스 계정에 모으는 기능이 아니다.

---

## 1. 원칙

1. **게시 단추는 대신 누르지 않는다.** 네이버 블로그 채우기(`studio-app/src/naver-write.js`)와 같은 원칙이다. 자동으로 게시까지 하면 자동화 계정으로 의심받을 수 있고, 올라간 글의 책임이 회원에게 있기 때문이다.
2. **비밀번호는 받지 않는다.** 회원이 스튜디오 전용 크롬에서 직접 로그인한다. 로그인 상태는 그 크롬 프로필에만 남는다.
3. **자동 조종 표시를 감추지 않는다.** 구글 로그인은 조종을 끈 평범한 크롬(`openPlain`)으로 하고, 조종은 그 뒤에 켠다. `studio-chrome.js`의 기존 방식 그대로 따른다.
4. **실패해도 막히지 않게.** 사이트 화면이 바뀌어 자동 채우기가 안 되면 **[글 복사] · [영상 폴더 열기] · [사이트 열기]**로 바로 내려간다. 지금 SNS 쓰기 1차 방식과 같다.
5. **표시·광고 정보는 코드가 붙인다.** 중개사무소 정보·출처 줄은 AI가 아니라 코드가 넣는다. 기존 `gwSnsCompose`와 같은 방식이다.
6. **AI 이미지가 들어간 영상은 알린다.** 채널마다 정한 AI 표시(유튜브 "변경되거나 합성된 콘텐츠", 인스타그램 "AI 정보")를 켜도록 안내하거나 채운다. 기존 `gwSnsAiLabelNote`를 이어 쓴다.

## 3. 회원이 쓰는 흐름

```
[내보내기] 완료
   └─ 완료 창: [폴더 열기]  [유튜브에 올리기]  [인스타그램에 올리기]
        │
        ▼
 게시 준비 칸 (편집기 오른쪽)
   - 채널: 유튜브 / 인스타그램
   - 제목 · 설명 · 해시태그  ← AI 초안 (대본·매물 정보로), 회원이 고침
   - 중개사무소 정보 · 출처 줄 (코드가 붙임, 지울 수 없음)
   - 유튜브만: 공개 범위(공개·일부 공개·비공개) · 쇼츠 여부(자동 판단 표시)
   - AI 이미지 포함 안내 (있을 때만)
   - [크롬에서 채우기]
        │
        ▼
 스튜디오 전용 크롬
   - 처음이면: "유튜브(구글)에 로그인해 주세요" → 평범한 크롬으로 로그인 → 돌아오면 이어서
   - 업로드 화면 열기 → 영상 파일 첨부 → 제목·설명 채우기 → (유튜브) 공개 범위 고르기
   - 여기서 멈춤: "내용 확인 후 [게시]를 눌러 주세요"
        │
        ▼
 회원이 [게시] 클릭 → 앱에 "올렸어요" 기록 (어느 영상 · 어느 채널 · 언제)
```

**쇼츠 자동 판단 (유튜브):** 세로(9:16)·정사각(1:1) 영상이고 길이가 유튜브 쇼츠 기준 안이면 쇼츠로 안내한다. 기준 길이는 만들 때 유튜브 공식 안내를 다시 확인해서 넣는다. 가로(16:9)는 일반 영상이다.

## 4. 단계

### 1단계 — 유튜브 (먼저)
1. 게시 준비 칸 UI (편집기 오른쪽 칸, 클립 메뉴와 같은 생김새)
2. 게시글 AI 초안: 영상 대본 + 매물 정보 → 제목·설명·해시태그 (`sns-prompt.js` 방식으로 새 지시문 `video-post`를 추가하고, 서버 묶음 `bundle.generated.ts`로 내려보냄)
3. 전용 크롬: YouTube Studio 업로드 화면 열기 → 파일 첨부(`setInputFiles`) → 제목·설명 채우기 → 공개 범위 → 멈춤
4. 로그인 안 된 경우 처리 (`openPlain` → 돌아오면 이어서)
5. 실패 시 내려가는 길: [글 복사] [영상 폴더 열기] [유튜브 열기]
6. 게시 기록 (PC에만)

### 2단계 — 인스타그램 (릴스)
1. instagram.com 만들기 화면 → 영상 첨부 → 자르기·비율 단계 넘기기 → 글(캡션)·해시태그 채우기 → 멈춤
2. 인스타 웹 업로드의 영상 길이·비율 제한을 만들 때 다시 확인해서 앱에서 미리 알려 줌 (안 맞으면 "앱에서 올려 주세요" 안내)
3. AI 정보 표시 안내

### 3단계 — 나중에 (회원이 많이 쓰면)
- 페이스북(페이지)·틱톡 추가 검토
- 유튜브 공식 API 완전 자동 (구글 심사 필요 — 심사 전에는 API로 올린 영상이 비공개로만 올라감)
- 예약 게시

### 썸네일 (결정 2026-10-21)

앱이 썸네일을 자동으로 만들어 주고, 회원은 이미지 편집기에서 고쳐서 같이 올린다. 일반 영상과 쇼츠는 유튜브 사정이 달라 나눈다.

| | 일반 영상 (가로 16:9) | 쇼츠 (세로 9:16) |
|---|---|---|
| 만드는 곳 | 내보내기 때 썸네일 그림(1280×720)을 같이 만든다. 바탕은 첫 클립 화면(회원이 다른 클립으로 바꿀 수 있음), 위에 제목을 크게 — 예능 자막·템플릿 디자인 그대로 | 영상 맨 앞에 제목이 크게 들어간 썸네일 장면을 아주 짧게 넣는다 (내보내기 설정 [첫 장면을 썸네일로] 켜기·끄기) |
| 고르기·고치기 | 게시 준비 칸에 후보 2~3장 → 하나 고르기 또는 [이미지 편집에서 고치기] (기존 이미지 편집기) | 내보내기 전 미리보기에서 확인 |
| 올리기 | 크롬 채우기 때 썸네일 파일까지 자동 첨부 | 영상 안에 들어 있음 (따로 올리지 않음) |
| 조건 | 유튜브 채널 휴대폰 인증이 된 채널만 직접 만든 썸네일을 올릴 수 있음. 인증이 안 됐으면 앱이 안내하고 인증 페이지를 열어 준다 | 없음 |

- 쇼츠 썸네일 규칙은 자주 바뀐다. 만들 때 유튜브 공식 안내를 다시 확인한다.
- 만들 파일에 추가: 썸네일 만들기(편집기 화면 그림 + 템플릿 글자) — 이미지 편집기 부품을 다시 쓴다.

## 7. 하지 않는 것

- [게시] 단추를 대신 누르기
- 회원 비밀번호 받기·저장
- 자동 조종 표시(`navigator.webdriver` 등) 감추기
- 여러 계정 한꺼번에 올리기, 같은 영상 반복 올리기
- 공실뉴스 계정으로 모아 올리기
