# 공실뉴스 부동산회원 매뉴얼 (원고 초안)

**작성일:** 2026년 09월 28일
**대상:** 부동산회원 관리자 화면(`/realty_admin`)을 쓰는 중개사 소장님
**상태:** HTML로 옮김 (2026-09-28) → `public/manual/realtor/` (주소 `/manual/realtor/`). 이후 수정은 HTML에서 한다.
캡처 52장은 임시 계정(manual-test-realtor@example.com, 캡처 후 삭제)과 gongsilmarketing 계정으로 찍었다.
회원가입부터 승인까지 한 단계씩 보여 주도록 "처음 시작하기"를 6편(가입 → 신청·서류 → 승인 → 공실 → 기사 → 웹페이지)으로 늘렸다.

---

## 0. 만드는 방식 (회의 결정)

| 항목 | 결정 |
|---|---|
| 형식 | 독립 HTML `/manual/realtor/`. 로그인 없이 공유하고, realty_admin [매뉴얼] 메뉴에도 같은 페이지를 띄운다 |
| 화면 | 왼쪽 목차·검색 + 오른쪽 본문, 맨 아래 [← 이전] [다음 →] |
| 한 항목의 틀 | 제목 → 한 줄 요약 → ①②③ 단계(캡처 + 한 줄 설명) → 💡 알아두세요 → ❓ 자주 묻는 질문(접힘) |
| 가독성 | 항목 하나에 할 일 하나, 단계당 한 줄, 단계는 3~5개, 버튼 이름은 화면과 똑같이 **[굵은 대괄호]** |
| 색 | 검정 본문, 파랑 버튼 이름, 빨강 번호·주의 |
| 캡처 | gongsilmarketing 계정(공실뉴스부동산 등급). 화면의 이름은 캡처할 때만 **홍길동**으로 바꾼다. 고객 개인정보는 흐리게 |
| 숫자 | 등급별 한도 숫자는 쓰지 않는다 → "내 한도는 [대시보드]에서 확인" (한도를 바꾸면 매뉴얼이 틀려지므로) |
| 등급 표시 | 유료 등급 전용 기능에는 `🔒 공실뉴스부동산·공실스터디부동산` 배지 + [공실스터디 신청하기] 연결 |

원고 안의 `📷 캡처 N` 은 찍어야 할 화면이고, ①②는 캡처 위에 올릴 빨간 번호 위치다.

# 🚀 처음 시작하기

가입한 뒤 이 순서대로 따라 하면 공실뉴스를 바로 쓸 수 있습니다.

## 1. 정보설정 — 사무소 정보와 서류 내기

> 공실뉴스를 쓰려면 먼저 중개사무소 정보와 서류를 내야 합니다. 관리자가 확인하면 **정상승인**이 됩니다.

📷 **캡처 1-1** 정보설정 화면, [부동산정보] 탭

① 왼쪽 메뉴 맨 아래 **[정보설정]**을 누르세요.
② 위쪽 **[부동산정보]** 탭을 누르세요.
③ 상호, 대표자, 등록번호, 주소를 적으세요.

📷 **캡처 1-2** 서류 첨부 부분

④ **[중개사무소 등록증 사진 첨부하기]**, **[사업자등록증 사진 첨부하기]**를 눌러 사진을 올리세요.
⑤ 맨 아래 **[저장하기]**를 누르세요.

💡 **알아두세요**
- 저장하면 **승인대기**가 되고, 관리자가 서류를 확인한 뒤 **정상승인**이 됩니다.
- 승인 전에는 일부 기능이 제한될 수 있습니다.

❓ **자주 묻는 질문**
- **"서류 보완이 필요합니다"가 떴어요.** → [대시보드]에 **반려 사유**가 보입니다. 정보를 고친 뒤 **[📋 수정 후 재심사 신청]**을 누르세요.
- **부동산 소개는 꼭 써야 하나요?** → 선택입니다(100자 이내). 물건접수웹페이지 맨 아래에 나옵니다.

## 2. 첫 공실 등록하기

> 비어 있는 매물을 공실뉴스 지도와 홈페이지에 올립니다.

📷 **캡처 2-1** 공실관리 목록

① 왼쪽 메뉴 **[공실관리]**를 누르세요.
② **[+ 공실광고 등록]**을 누르세요.

📷 **캡처 2-2** 공실등록 화면 윗부분 (분류·주소)

③ 매물 종류를 고르세요. (예: 아파트·오피스텔 → 아파트)
④ **[🔍 주소 먼저 검색]**을 눌러 주소를 고르세요. 시/도와 상세 주소가 자동으로 들어갑니다.

📷 **캡처 2-3** 거래·금액과 사진 부분

⑤ 거래유형(매매·전세·월세)과 금액을 넣으세요.
⑥ 사진을 끌어다 놓거나 눌러서 올리세요. **(최대 5장)**

📷 **캡처 2-4** 의뢰인 정보와 등록 버튼

⑦ 의뢰인 이름과 연락처를 넣고 **[광고등록]**을 누르세요.

💡 **알아두세요**
- 등록할 수 있는 공실 수는 등급마다 다릅니다. 내 한도는 **[대시보드]**에서 확인하세요.
- 다 못 썼으면 **[💾 임시저장]**을 누르세요. 공실관리 목록에서 이어서 쓸 수 있습니다.
- 사진에는 워터마크가 자동으로 들어갑니다.

❓ **자주 묻는 질문**
- **건물 정보를 일일이 넣어야 하나요?** → 주소를 넣으면 건축물대장에서 층수·주용도·승강기 등을 자동으로 채웁니다. 면적은 직접 넣어 주세요.
- **상세 설명 쓰기가 어려워요.** → **[✨ AI초안글쓰기]**를 누르면 초안을 써 줍니다. 꼭 읽고 실제와 맞게 고쳐 주세요.
- **주소를 다 보여 주기 싫어요.** → **주소 노출 범위 설정**에서 "기본주소만공개" 등을 고르세요.
- **지난번 매물과 비슷해요.** → **[↻ 이전 공실광고 불러오기]**로 불러와 고치면 빠릅니다.

## 3. 첫 기사 쓰기

> 내 매물이나 지역 소식을 공실뉴스 기사로 냅니다. 관리자 승인 후 발행됩니다.

📷 **캡처 3-1** 기사관리 목록

① 왼쪽 메뉴 **[기사관리]**를 누르세요.
② **[+ 새 기사 작성]**을 누르세요.

📷 **캡처 3-2** 기사쓰기 화면 (AI 초안 패널 열린 상태)

③ 공실 매물로 쓰려면 **[AI 공실뉴스초안작성]** → 매물을 고르고 **[공실뉴스 매물 기사 작성하기 >>]**를 누르세요. 초안이 본문에 들어갑니다.
④ 섹션, 제목, 본문을 확인하고 고치세요.

📷 **캡처 3-3** 아래쪽 버튼

⑤ **[✓ 승인신청]**을 누르세요. 다 못 썼으면 **[임시저장 (작성중)]**을 누르세요.

💡 **알아두세요**
- 승인신청하면 관리자 검토 후 **발행됨**이 됩니다. 반려되면 사유가 알림으로 오고, 고쳐서 다시 신청할 수 있습니다.
- 발행된 기사의 **본문 수정은 3번까지**입니다. 배너·공실 연결 변경은 횟수에 들어가지 않습니다.
- 한 달에 쓸 수 있는 기사 수는 등급마다 다릅니다. 내 한도는 **[대시보드]**에서 확인하세요.

❓ **자주 묻는 질문**
- **"기사 작성 권한이 없습니다"가 떠요.** → 기사 작성은 유료 등급에서 열립니다. **[공실스터디 신청하기]**를 확인하세요.
- **사진은 어떻게 넣나요?** → 오른쪽 **[사진]**에서 끌어다 놓으세요(10MB까지, 자동 압축). **[대표지정]**으로 대표 사진을 고릅니다.

## 4. 물건접수웹페이지 열기

> 임대인이 물건을 맡기는 **내 사무소 전용 페이지**입니다. 명함이나 문자로 주소를 보내세요.

📷 **캡처 4-1** 물건접수웹페이지 [기본설정]

① 왼쪽 메뉴 **[물건접수웹페이지]**를 누르세요.
② **웹페이지 주소**를 정하세요. (영문 소문자·숫자·하이픈 2~30자) → **[변경하기]**
③ 상호와 헤더 표시 방식을 고르세요.

📷 **캡처 4-2** 오른쪽 미리보기

④ 위쪽 탭(**디자인·섹션·접수항목·회사정보**)에서 원하는 대로 고치세요. 오른쪽 **미리보기**에 바로 보입니다.
⑤ **[저장하기]**를 누르고 **[공유하기]**로 주소를 보내세요.

💡 **알아두세요**
- **추천공실**에는 공실관리에 올린 매물이, **기사·칼럼**에는 승인된 기사 최신 4건이 자동으로 나옵니다.
- 회사 정보(대표, 전화, 소재지)는 **[정보설정]**에서 자동으로 가져옵니다.
- 🔒 로고 올리기는 공실뉴스부동산·공실스터디부동산 등급에서 열립니다.

❓ **자주 묻는 질문**
- **접수 칸이 너무 많아요.** → [접수항목]에서 끄세요. 이름과 연락처는 항상 받습니다. 칸이 적을수록 접수가 많아집니다.
- **접수된 물건은 어디서 보나요?** → **[고객문의]**에 들어옵니다.

> 내 공실·기사 현황과 승인 상태를 한눈에 봅니다.

- ① 위쪽: **승인 상태** (정상승인 / 서류 검토 중 / 서류 보완 필요 + 반려 사유)

- ④ **⚡ 바로가기**: 자주 쓰는 메뉴로 바로 이동

💡 숫자가 안 바뀌면 **[⟳ 새로고침]**을 누르세요.

## 공실관리

> 올린 공실을 보고, 광고를 켜고 끄고, 고칩니다.

📷 **캡처 G-1** 공실관리 목록

- ① 위쪽 검색: 번호, 카테고리, 거래구분, 주소·연락처로 찾기
- ② **[+ 공실광고 등록]**: 새 공실 등록 → [처음 시작하기 2] 참고
- ③ **광고설정**: 광고중 / 광고종료 전환
- ④ 오른쪽 관리: **[수정]**, **[삭제]**
- ⑤ **AI물건보고서**: 매물 소개 보고서를 AI로 만듭니다
- ⑥ **공실마케팅**: 외관 리모델링·인테리어 이미지, 전단지 등

💡 **알아두세요**
- 반려된 공실은 고친 뒤 체크하고 승인신청할 수 있습니다.
- 노출 범위: **부동산노출**(중개사만) 또는 **부동산노출 + 일반인노출**(모두)

## 기사관리

> 내가 쓴 기사의 상태를 보고, 배너와 공실을 기사에 붙입니다.

📷 **캡처 A-1** 기사관리 목록

- ① 상태 탭: **작성중 · 승인대기 · 발행됨 · 예약됨 · 반려**
- ② **[+ 새 기사 작성]** → [처음 시작하기 3] 참고
- ③ **[📋 승인신청]**: 작성중·반려 기사를 체크해서 한 번에 신청
- ④ **배너광고** 칸: 기사 아래에 나올 배너 고르기 (업체프로필 / 내 배너 / 배너없음)
- ⑤ **공실선택** 칸: 기사 아래에 내 공실 1개 연결
- ⑥ **[🏷️ 기사 배너 일괄적용]**, **[🏢 공실 일괄적용]**: 여러 기사에 한 번에

💡 **알아두세요**
- 🔒 기사 배너광고·공실 일괄적용은 공실뉴스부동산·공실스터디부동산 전용입니다.
- 공실 연결은 **부동산노출 + 일반인노출**로 등록된 광고중 매물만 됩니다.

## 광고관리

> 기사 아래에 나오는 **내 배너**를 만들고 성과(노출·클릭)를 봅니다.

📷 **캡처 B-1** 새 배너 등록 화면 (미리보기 포함)

① **[새 배너 등록]**을 누르세요.
② 배너명과 이미지(**1200×400px**)를 넣으세요.
③ 누르면 이동할 **링크 URL**과 노출 기간을 정하세요. (비우면 상시 노출)
④ 아래 **실시간 미리보기**(PC·모바일)로 확인하고 **[배너 등록하기]**를 누르세요.

📷 **캡처 B-2** 📊 배너 성과 분석

- 배너별 **노출수, 클릭수, 클릭률(CTR)**을 봅니다.

💡 **알아두세요**
- 🔒 공실뉴스부동산·공실스터디부동산 전용입니다. 무료 등급은 **[멤버십 안내 보기]**가 나옵니다.
- 만든 배너는 [기사관리]의 **배너광고** 칸에서 기사에 붙입니다.

## 특강관리

> 내 강의를 올리고 판매합니다. **최고관리자 승인 후** 판매중이 됩니다.

📷 **캡처 S-1** 내 강의 목록 (위쪽 등록 한도 안내 포함)

① 위쪽 안내에서 **강의 등록 몇 개 중 몇 개**를 썼는지 확인하세요.
② **[+ 새 강의 등록]**을 누르세요.

📷 **캡처 S-2** 강의 작성 화면 아래 버튼

③ 강의 정보를 넣고 **[📨 승인 요청]**을 누르세요. 다 못 썼으면 **[💾 임시저장]**.
④ 목록에서 상태를 확인하세요: **승인대기 → 판매중**, 또는 **반려**(사유가 빨간 글씨로 보임)

💡 **알아두세요**
- 🔒 강의 등록은 공실스터디부동산·공실뉴스부동산·비즈니스회원만 할 수 있습니다.
- **판매중인 강의를 고치면 다시 승인대기**가 됩니다. 승인되면 다시 판매중입니다.
- 승인·반려 결과는 알림(🔔)으로 옵니다.

## 고객문의

# ❓ 확인이 필요한 것

원고를 쓰다가 코드만으로는 확실하지 않았던 것들이다.

1. **공실등록보상 포인트**가 얼마인지. 매뉴얼에는 금액을 쓰지 않았다.
2. **기사 승인신청 후 "AI 심사"** 문구가 목록에 있다. AI가 먼저 보고 관리자가 확정하는 구조인지 확인이 필요하다.
3. **크롬 확장 작성기**(gongsilwriter20)를 부동산회원 매뉴얼에 넣을지. 넣는다면 "부록"으로.
4. 기존 공개 페이지 `/newsrealty/guide/manual`(이용가이드)과의 관계. 그 페이지는 소개용이라 이 매뉴얼과 겹치지 않지만, 거기서 이 매뉴얼로 링크를 걸면 좋다.
