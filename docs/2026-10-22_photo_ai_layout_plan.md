# 이미지 편집 — AI 자동 디자인 · 떠 있는 창 · 저장 계획서

2026-10-22 회의 정리 (사장님 + Claude)

## 1. 목표

등록한 **공실** 또는 **기사**를 가져오면, AI가 거기에 맞는 배경과 문구를 만들고, 그 위에 글자와 그래픽을 **포토샵처럼 레이어별로** 쌓아 준다.

- 결과는 한 장짜리 그림이 아니다. **레이어 묶음(PSD)** 으로 나온다.
- 회원은 레이어를 하나씩 고칠 수 있다.
- 구조는 포토샵식 레이어다. 하지만 실제 작업은 **템플릿으로 빠르고 쉽게** 한다.
- 문서 크기 분류(유튜브 · 블로그 · SNS · 부동산마케팅)마다 그 크기에 맞는 레이아웃대로 바로 작업한다.

## 3. 작업 흐름

1. **새 문서**에서 분류와 크기를 고른다. 예: SNS → 인스타 정사각.
2. **레이아웃 고르기**: 그 크기용 틀이 몇 개 나온다.
3. **공실 / 기사 가져오기**
   - 가격 · 면적 · 주소 · 중개사 정보는 **공실 데이터 값을 그대로** 넣는다. AI를 거치지 않는다 (가짜 데이터 금지).
   - 제목 · 부제 · 강조 문구는 AI가 쓴다.
4. **배경** — 셋 중 하나를 고른다.
   - **실제 사진 그대로** (공실 기본값)
   - **실제 사진 + AI 다듬기**: 이미지 프롬프트로 하늘 · 조명 · 주변 정리
   - **AI로 새로 만들기**: 이미지 프롬프트와 그림 스타일을 쓴다 (기사 기본값)
5. 편집기에 **레이어로 쌓여서** 열린다. 회원이 고친 뒤 저장한다.

### 레이어 쌓는 순서 (예: 매물 홍보)

| 순서 | 레이어 | 종류 |
|---|---|---|
| 맨 위 | 중개사 정보 · 로고 | 글자 |
| | 스티커 "급매" "역세권" | 그래픽 |
| | 가격 띠 + 가격 | 도형 + 글자 |
| | 제목 · 부제 | 글자 (글자 사전설정 · 고급효과) |
| | 어둡게 깔기 | 도형 (글자를 잘 보이게) |
| 맨 아래 | 배경 | 실제 사진 또는 AI 그림 |

### 원칙

- **AI에게는 "글자 없는 배경 그림"과 "문구"만 맡긴다.** 글자를 그림에 넣으면 한 장으로 굳어서 레이어가 안 되고 한글도 깨진다. 레이어는 우리 코드가 쌓는다.
- **위치는 AI가 아니라 레이아웃 틀로 정한다.** AI는 틀을 고르고 칸만 채운다. AI가 좌표를 정하면 결과가 매번 들쭉날쭉하다.
- **실제 매물 사진을 AI로 다듬을 때 건물이나 실내 자체는 바꾸지 않는다** (허위 광고 소지). 다듬기 범위를 하늘 · 조명 · 주변 정리로 묶어 둔다. 다듬은 사진에는 "AI 보정" 표시를 작게 넣는다.

## 4. 만들 것

### 4-1. 글자 고급효과를 동영상과 똑같이

- 이미지 편집에 **그라데이션 글자 (`gradTo` 등)** 와 **이중 테두리 (`outline2`)** 를 넣는다. 지금은 단색으로 나오고 테두리도 하나만 나온다.
- `TextTabs.tsx` 의 `kind !== "photo"` 조건을 풀어서 이미지 편집에서도 이 두 효과를 고를 수 있게 한다.
- `model.ts` `renderText` · `effectsFromLook` · `lookFromLayer` 를 고친다. 저장했다 다시 열어도 효과가 그대로 돌아와야 한다.

### 4-2. 디자인 템플릿 → 레이어로 떼어내기

- 템플릿은 글자 · 도형 · 장식을 한 캔버스에 같이 그린다.
- 그리는 도구 함수(`txt` · `rr` 등)를 "기록 모드"로 감싸서 호출을 가로챈다. 그러면 템플릿 127개를 하나하나 고치지 않아도 된다.
  - 글자 → **고칠 수 있는 글자 레이어**
  - 판 · 장식 → **그래픽 레이어**
- 템플릿 크기는 지금 고정 px다. 문서 크기에 맞게 **배율 인자**를 넣는다. 늘리면 흐려지기 때문이다.
- 어떤 템플릿의 어떤 칸이었는지 레이어에 기억해 둔다 (6 참고).

### 4-3. 레이아웃 틀

- 크기 분류마다 틀 몇 개로 시작한다.
- 틀 하나 = 칸 목록이다. 칸마다 다음을 정한다.
  - 위치 · 크기 (문서 비율)
  - 쓰는 글자 사전설정, 템플릿, 스티커
  - 채울 값 (공실 필드 / AI 문구)
- **내 템플릿으로 저장**: 회원이 꾸민 디자인을 틀로 저장한다. 다른 공실을 가져오면 글과 사진만 바뀌어 들어간다.

### 4-4. 공실 · 기사 가져오기 + 자동 채우기

- 동영상 편집기의 가져오기를 그대로 부른다.
- AI ① 기획: 내용을 읽고 다음을 JSON으로 정한다.
  - 제목 · 부제 · 강조 문구
  - 스티커
  - 레이아웃 틀
  - 배경 장면 설명

### 4-5. 배경 AI

- `imagePrompt` + 그림 스타일 16종 + `ai.imagePrompts` 를 그대로 쓴다.
- 실제 사진을 다듬을 때는 사진을 첨부해서 고쳐 그린다 (나노바나나 / gpt-image edits).
- 만든 그림은 바로 PC에 원본으로 저장한다 (6 참고).

### 4-6. 떠 있는 창 (포토샵처럼) — **먼저 만듦 (2026-10-22 작업 중)**

- 문서 탭을 아래로 끌어내면 작업 영역 안에 떠 있는 창이 된다.
  - 제목줄로 옮기고, 오른쪽 아래 모서리로 크기를 바꾼다.
  - 탭 줄에 다시 놓거나 제목줄을 두 번 누르면 탭으로 돌아간다.
- 떠 있는 창을 누르면 그 문서가 "지금 문서"가 된다. 오른쪽 속성 칸과 레이어 칸이 그 문서로 바뀐다.
- **문서끼리 레이어 옮기기** — 두 가지 방법이 있고, 둘 다 복사로 들어간다.
  - 이동 도구로 그림을 다른 창이나 탭 그림판에 끌어다 놓는다. 손을 뗀 자리에 들어간다.
  - 레이어 칸의 레이어를 다른 창에 끌어다 놓는다.
- 창 메뉴: 떠 있는 창으로 빼기 · 탭으로 붙이기 · 모두 탭으로 합치기 · 바둑판식으로 나란히 보기
- 창은 **앱 화면 안에서만** 뜬다. 앱 밖의 별도 창은 상태를 맞추기 어렵고 저장이 꼬일 위험이 있다.

### 4-7. 포토샵처럼 쓰기 — 도구창 · 단축키 · 글자 고치기 (2026-10-22 작업)

포토샵을 써 본 회원이 헷갈리지 않게 만든다.

**도구창**
- 순서와 글쇠를 포토샵과 같게 했다: 이동 V · 선택 윤곽 M (사각형/타원형) · 올가미 L (올가미/다각형) · 자동 선택 W · 자르기 C · 스포이트 I · 브러시 B · 지우개 E · 그레이디언트/페인트 통 G · 문자 T · 도형 U (사각형/타원/선) · 손 H · 돋보기 Z
- 작은 세모가 있는 도구는 묶음이다. 오른쪽 클릭이나 길게 누르면 펼쳐지고, Shift+글쇠로 묶음 안의 다음 도구로 넘어간다.

**선택 영역**
- 만들기: Shift = 더하기, Alt = 빼기. 움직이는 점선(개미 행렬)으로 보인다.
- 메뉴 [선택]: 모두 · 해제 · 다시 선택 · 반전, 수정(테두리 · 매끄럽게 · 확대 · 축소 · 페더)
- 선택 영역 안에서만 되는 것: 브러시 · 지우개 · 페인트 통 · 그레이디언트 · Delete 지우기 · 보정
- **[편집 › 획]**: 두께 · 위치(안쪽/가운데/바깥쪽) · 모양(실선/파선/점선) · 색 · 불투명도. 파선·점선은 모양을 아는 선택(사각형 · 타원 · 올가미)에서만 되고, 자동 선택에서는 실선만 된다.
- **[편집 › 칠]**: 전경색 · 배경색 · 색 고르기 · 그레이디언트(방향 4가지, 끝을 투명으로도)
- 획과 칠은 기본으로 **새 레이어**에 들어간다.

**단축키**
- 사장님이 준 포토샵 표대로 맞췄다. 한글 입력 상태에서도 된다.
- **아직 없는 것 (다음 단계)**:
  - 대화상자가 필요한 보정: Ctrl+L 레벨 · Ctrl+M 곡선 · Ctrl+U 색조/채도 · Ctrl+B 색상 균형
  - 자유 변형의 회전
  - 복제 도장 S · 복구 브러시 J · 펜 P

**글자 고치기**
- 고치는 동안에도 상자 · 색 · 효과가 그대로 보이고, 치는 대로 바로 바뀐다.
- 문자 도구로 글자를 끌면 옮겨지고, 그냥 누르면 고치기가 된다.
- Esc 를 누르면 고치기 전으로 돌아간다. 고친 내용은 되돌리기 기록에 한 번으로 남는다.

## 5. 저장 형식 (사장님 지시)

| 동작 | 형식 |
|---|---|
| **저장 (Ctrl+S)** | 레이어가 여러 개면 **PSD**. 레이어가 하나뿐이면(사진 한 장) 원래 형식 **JPG / PNG** 그대로 |
| **웹용으로 저장** | **JPG · PNG · GIF** 중 골라 가볍게 (화질 · 크기 조절) |
| 내보내기 | 지금처럼 PNG · JPG, 인쇄용 CMYK PDF · TIFF |

- 레이어가 하나뿐인데 효과 · 숨김 · 불투명도처럼 PSD에만 남는 정보가 있으면, 저장 전에 알리고 PSD를 권한다.
- 레이어가 여러 개인 문서를 JPG로 저장하려 하면 "레이어가 합쳐져요. PSD도 같이 저장할까요?"라고 묻는다.

## 6. 내가 만든 것은 무조건 저장 (사장님 지시)

1. **다시 열어도 그대로 고칠 수 있게** — PSD 메모(`<gongsil:photolab>`)에 다음을 더 넣는다.
   - 템플릿에서 떼어낸 레이어: 어떤 템플릿이었는지, 칸마다 무슨 글이었는지
   - 그라데이션 글자 · 이중 테두리 (지금은 다시 열면 사라짐)
   - 배경에 쓴 AI 프롬프트, 가져온 공실 · 기사 번호 ("배경만 다시 만들기"에 씀)
2. **자동 저장** — 지금은 없다. 앱이 꺼지면 작업이 사라진다.
   - 고칠 때마다 몇 초 뒤 임시 파일에 저장한다.
   - 앱이 비정상으로 꺼졌다 다시 켜지면 "저장 안 된 작업을 복구할까요?"라고 묻는다.
3. **내 템플릿 저장** (4-3)
4. **AI 그림은 만들자마자 파일로** — `문서\공실뉴스 이미지\AI그림\날짜\`. 문서를 저장하지 않았더라도 남는다.

원본은 모두 회원 PC에 둔다. 동영상 편집기와 같은 방식이다.
