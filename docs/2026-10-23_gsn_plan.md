## 만드는 법
- **.gsn = 그 작업 폴더(media\<id>)를 통째로 묶은 파일** (zip). 안에 `gsn.json` { id, kind(vacancy|column|sim), name, savedAt, version }.
- **작업은 지금처럼** 안 보이는 media\<id> 에서 (빠르게). 블로그·SNS·유튜브 글을 저장할 때마다(조금 쉬었다가) .gsn 을 다시 쓴다.
  - 작업 id → .gsn 위치를 기억(`gsn-index.json`). 회원이 파일 이름을 바꾸거나 옮겼으면 → 다음 저장 때 새 파일 대신 **기억한 자리에 없으면 새로 만든다** (덮어쓰기 사고 없게).
- **열기**: 탐색기에서 .gsn 을 두 번 누르면(파일 연결 · 실행 인자 — .gss 와 같은 길) 앱이 media\<id> 로 풀고 **뉴스·SNS발행 메뉴에서 그 작업을 연다**.
  - 이 PC에 같은 작업이 이미 있으면: 더 최근 것이 어느 쪽인지 보여 주고 [파일 것으로 열기 / 지금 것 그대로] 를 묻는다.
- **다른 PC로 옮기기**: .gsn 하나만 옮기면 사진·글·공실 정보까지 그대로 열린다.
- 개인정보: 공실 정보는 이미 개인정보를 뺀 것(analysis)만 들어 있다 — 파일에 집주인·의뢰인 연락처를 넣지 않는다.
