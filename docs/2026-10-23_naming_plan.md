# 이름 정리 (2026-10-23 사장님 회의)

> **고침 (같은 날 사장님):** 유료 회원은 **기존 "공실뉴스부동산"**(`news_premium`)을 이름 그대로 쓴다 — "공실뉴스 멤버십"이라는 새 이름은 만들지 않는다.
> **공실스터디는 그대로 둔다** — 강의 개설 여부에 따라 달라지므로 이름·등급(`study_premium`)·/study 화면 모두 지금대로. **등급은 합치지 않는다.**
> 그래서 아래 1번 표의 "공실뉴스 멤버십" 줄, 4-1(공실스터디 이름 바꾸기), 6-1은 하지 않는다. 앱 이름 공실스튜디오(4-2)는 반영함.

## 1. 정한 이름

| 이름 | 무엇 | 어디서 쓰나 |
|---|---|---|
| **공실뉴스** | 회사 · 사이트 · 뉴스 유튜브 채널 | 사이트, 기존 유튜브 채널, 스마트스토어 상품명 |
| **공실뉴스부동산** | 유료 회원 (기존 등급 그대로) | 사이트 안, 스마트스토어 상세 설명 |
| **공실스튜디오** | 중개사용 데스크톱 앱 + 부동산마케팅 유튜브 채널 | 앱 이름, 새 유튜브 채널 (지금의 "공실뉴스 스튜디오") |

- **"공실스터디"라는 이름은 쓰지 않는다** — "공실스튜디오"와 글자·소리가 거의 같아 헷갈린다.
- 앱 안·영상에서 짧게 부를 때는 그냥 **"스튜디오"**.

## 2. 유튜브 채널 두 개

| 채널 | 보는 사람 | 올릴 영상 |
|---|---|---|
| **공실뉴스** (지금 채널) | 중개사 · 일반인 · 임대인 | 부동산 뉴스, 시장 소식, 공실 매물, 임대 정보 |
| **공실스튜디오 \| 부동산마케팅** (새 채널) | 중개사 | 앱 사용법(매뉴얼 시리즈), 신기능, 블로그·릴스·매물보고서 만들기, 중개사 마케팅 노하우 |

- 왜 따로: 시청자가 다르다. 사용법 영상을 뉴스 채널에 섞으면 일반인·임대인이 건너뛰어 두 쪽 추천이 다 약해진다.
- 채널 이름에 "부동산마케팅"을 붙인다 — "공실 스튜디오"는 부동산에서 "비어 있는 원룸"으로도 읽혀 검색이 섞이므로.
- 서로 잇기: 공실뉴스 영상 중 중개사가 볼 만한 것에만 끝 화면·고정 댓글로 스튜디오 채널 안내. 스튜디오 채널 설명란에 멤버십·앱 받기 링크.
- 두 채널은 같은 구글 계정의 브랜드 계정으로 관리.

## 4. 바꿀 곳

### 4-1. 사이트 — "공실스터디" → "공실뉴스 멤버십" (코드에서 108개 파일)
- 멤버십 소개·가격·신청·혜택 화면: `src/app/(main)/study`, `src/app/m/study`, `src/app/(main)/gongsilstudy`, `src/components/study`
- 관리자 화면: `src/components/admin/sections`, `src/components/admin/study`, `src/app/m/admin`
- 회원 등급 표시 "공실스터디부동산"(등급 코드 `study_premium`) — 화면에 보이는 이름만 바꾼다
- 안내 문구: 권한 안내(`permissionCheck`, `extensionMember`, `studioUsage`), 강의(`lecture*`), 확장 프로그램 API
- **그대로 두는 것**: 주소 `/study`(이미 퍼진 링크가 깨지지 않게), 등급 코드 `study_premium`, DB 값

### 4-2. 앱 — "공실뉴스 스튜디오" → "공실스튜디오" (코드에서 60개 파일)
- 창 제목, 설치 파일·바탕화면 아이콘 이름(`studio-app/package.json` productName·shortcutName), 파일 형식 이름("공실뉴스 스튜디오 파일")
- 앱 안 안내 문구 (영상 편집기, 공실마케팅, 문서편집, 시뮬레이션 등)
- **그대로 두는 것**: 앱 ID `com.gongsilnews.studio`(바꾸면 자동 업데이트가 끊긴다), 연결 주소 `gongsilstudio://`
- **꼭 지킬 것**: 앱 이름을 바꾸면 회원 PC의 앱 저장소(로그인·AI 키·설정·공실 없는 보고서 등, `AppData\Roaming\공실뉴스 스튜디오`)가 새 이름 폴더로 바뀌어
  **모두 사라진 것처럼 보인다** → 저장소 위치는 예전 이름 그대로 고정한다 (`app.setPath("userData", …)`). 전용 크롬 폴더(`studio-chrome.js`)도 같다.

## 5. 회원 PC 폴더 정리

지금은 문서 폴더에 세 갈래로 흩어져 있고, 매물별 폴더가 영상·녹화 폴더와 한 줄에 섞여 있다.

```
문서\공실뉴스 스튜디오\   영상\ 녹화영상\ AI오디오\ 대본\ + 매물마다 폴더(논현동 빌라_88633\ …) + 칼럼·시뮬레이션 폴더
문서\공실뉴스 이미지\     이미지 편집 저장 · 내 템플릿\
문서\공실뉴스 문서\       문서편집 저장
```

정리 안 — **하나로 모으고, 종류별로 한 단계 아래에**:

```
문서\공실스튜디오\
  매물\          매물마다 폴더 (논현동 빌라_88633\ 홍보지\ 매물보고서\ 인스타그램\ 유튜브\ 영상\ …)
                 공실 없이 만든 보고서도 여기 (20261023 논현동 무지개빌라 전세\)
  칼럼\          뉴스칼럼
  시뮬레이션\    인테리어·리모델링 예측 (공실 사진으로 한 것은 그 매물 폴더 안)
  영상\          영상 편집기 프로젝트
  녹화영상\
  AI오디오\
  대본\
  이미지\        이미지 편집 저장 (내 템플릿\)
  문서\          문서편집 저장
```

- 이미 설치한 회원: 예전 폴더의 파일은 **옮기지 않고 그대로 열린다**(최근 파일·영상 목록이 예전 자리도 본다). 새로 저장하는 것부터 새 폴더로.
- 영상 편집기 [저장 폴더]에서 회원이 직접 고른 폴더는 그대로 둔다.

## 6. 정할 것
1. **"공실뉴스부동산" 등급과의 관계** — 지금 유료 등급이 둘이다: 공실뉴스부동산(`news_premium`) · 공실스터디부동산(`study_premium`).
   "공실뉴스 멤버십"이 study 쪽을 가리키면 "공실뉴스부동산"과 이름이 겹쳐 보인다 → 두 등급의 고객용 이름을 함께 정해야 한다.
2. 예전 폴더(공실뉴스 스튜디오·이미지·문서)를 처음 켤 때 **새 폴더로 옮겨 줄지** (안: 옮기지 않고 그대로 둠)
3. 강의 메뉴 이름 — "공실스터디"를 빼면 강의 쪽은 그냥 "강의" 또는 "공실뉴스 강의"로
4. 유튜브 핸들(@주소) — 만들 때 쓸 수 있는 것으로 (예: @gongsilstudio)
