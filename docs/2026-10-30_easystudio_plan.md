# 이지스튜디오(EasyStudio) 계획서 — 2026-10-30

> 공실마케팅studio에서 **포토studio · 동영상studio만 떼어 낸 별도 앱**. 나중에 글로벌(여러 언어)로 낸다.
> 이 문서는 1단계(조사·계획)다. **아직 코드는 바꾸지 않았다.**

## 정한 것 (2026-10-30 사장님)
| 항목 | 결정 |
|---|---|
| 이름 | **이지스튜디오 (EasyStudio)** — 코드 안에서는 브랜드 설정 한 곳에만 둔다 (상표 확인 결과에 따라 바꾸기 쉽게) |
| 회원 계정 | 공실마케팅studio과 **같은 계정** (Supabase members 그대로) |

⚠ 상표: "easy"·"studio" 모두 흔한 낱말이라 등록이 어렵고, 같은 분야에 `easystudioai`(썸네일·상품 사진 AI) 등이 이미 있다. 출시 전 키프리스·USPTO 확인과 변리사 상담이 필요하다 (사장님 쪽에서).

## 큰 그림 — 코드는 하나, 제품은 둘
```
              공통 엔진 (포토 · 동영상 편집기)
              /                          \
공실마케팅studio (한국 부동산)          이지스튜디오 (일반·글로벌)
- 공실·기사·보고서·홈페이지 연동      - 내 사진·영상만
- 메뉴 전부                          - 메뉴: 포토studio · 동영상studio
```
- 편집기를 고치면 두 앱에 동시에 들어간다. 따로 복사해 만들지 않는다 (유지보수).
- 공실마케팅studio 은 지금과 똑같이 동작해야 한다 — 단계마다 확인.

### 다국어 규모
- 편집기 두 묶음에 한국어 글자가 약 **8,000곳**(코드 안 글 6,900 + 화면 글 1,400), PC 앱 125 파일.
- 한 번에 다 옮기지 않는다 — 영어판 단계에서 **화면에 자주 보이는 것부터** 언어 파일로 뺀다.

## 설계
### ① 브랜드 설정 (한 파일)
`src/lib/brand.ts` (가칭)
```ts
type Brand = {
  id: "gongsil" | "easy";
  name: string;            // 공실마케팅studio / 이지스튜디오
  menus: string[];         // 보일 메뉴 — easy 는 ["photo", "video"]
  realty: boolean;         // 공실·기사·중개사무소 연동을 켤지
  sampleCats: string[];    // 포토 샘플 종류 — easy 는 부동산 제외
  stickerTabs: string[];   // 그래픽 탭 — easy 는 부동산 제외
  locale: "ko" | "en";
};
```
- 웹: 앱이 접속할 때 `?brand=easy` (또는 별도 주소 `/easy`)로 브랜드를 정한다.
- PC 앱: 빌드할 때 `BRAND=easy` → 이름·아이콘·첫 주소·파일 연결을 바꾼 설치 파일을 따로 만든다.

### ② 엔진 분리
- `realty` 가 꺼져 있으면: 새로 만들기의 [내 공실]·[내 기사·칼럼], 중개사무소 자동 채우기, 부동산 샘플·그래픽, 대본의 공실·기사 가져오기, 홍보 현황 올리기를 **숨긴다**.
- 처음에는 **조건으로 숨기기**로 시작하고(작업 적고 안전), 굳으면 파일을 부품으로 나눈다.

### ③ 이지스튜디오 첫 화면
- `/realty_admin` 대신 가벼운 첫 화면: [새 이미지] [새 영상] · 최근 작업 · 템플릿.
- 로그인은 같은 계정.

### ④ 일반 샘플 (부동산 대신)
- 유튜브 · SNS · 쇼핑 · 카페·음식 · 행사 · 교육 등. 사진은 지금처럼 픽사베이에서 받아 서버에 둔다.

### ⑤ 다국어 (영어판 단계)
- 언어 파일 `src/i18n/{ko,en}.json` + `t("키")`. 회원 AI(ChatGPT·Gemini)·성우·받아쓰기는 여러 언어에서 그대로 돈다.
- 글꼴: 한글 위주 → 일본어·중국어 등은 Noto 계열 추가.

### ⑥ 결제·가입 (글로벌 단계)
- 해외 카드 결제(Stripe 또는 Paddle) · 해외 가입. 한국어판은 지금 결제 그대로.
