# 경매·공매 열람 정책 계획

> 작성일: 2026-09-03
> 상태: 합의 완료, 구현 반영

## 정책

- 비회원은 경매·공매 매물을 열람할 수 없습니다.
- 일반회원은 경매·공매 매물의 상세정보와 사진을 무료로 열람할 수 있습니다.
- 승인 완료된 부동산회원도 경매·공매 매물을 무료로 열람할 수 있습니다.
- 승인대기 또는 반려 상태의 회원은 일반회원 권한으로 취급합니다.

## 비회원 안내

- 잠금 문구는 부동산회원 전용이 아니라 로그인 안내로 표시합니다.
- 안내 문구에는 로그인 회원의 무료 열람 가능 내용을 포함합니다.
- 로그인 버튼은 PC `/login`, 모바일 `/m/login`으로 연결합니다.
- `returnTo`를 사용해 로그인 후 원래 보던 경매·공매 매물로 돌아옵니다.

## 일반 공실과의 구분

- 일반 공실의 기존 중개업소 전용 열람 제한은 유지합니다.
- 경매·공매와 일반 공실은 잠금 문구와 연결 페이지를 서로 다르게 사용합니다.

## 등록자 정보의 다른 매물

- 등록자 정보에서 보여주는 다른 매물 목록에는 경매·공매를 포함하지 않습니다.
- PC와 모바일 모두 일반 공실 매물만 표시합니다.
- 공실등록현황의 전체 건수도 경매·공매를 제외한 수로 계산합니다.
