## 1. 인수인계 문서 분석 (2026-10-19)

### 1-1. 문서가 말하는 것
- 포토샵과 같은 배치·더 단순한 이미지 편집기 **포토랩** (메뉴: 공실뉴스 스튜디오 > 포토랩)
- 핵심: **PSD 양방향 호환**
  - A. 우리 앱 결과 → PSD 저장 → 디자이너가 포토샵에서 이어서
  - B. 디자이너 PSD 템플릿 → 우리 앱에서 열어 글·사진만 바꿔 사용
- 가장 중요: **레이어 속성 · 혼합 옵션(레이어 스타일 창)**
- 1차: 시작 화면, 툴 5개(이동·선택·문자·손·돋보기), 레이어 패널, 혼합 옵션, PSD 저장, 웹용으로 저장(GIF·JPEG·PNG-8·PNG-24)

### 1-3. 지금 상황과 다른 점
1. 문서: 스튜디오 화면이 "순수 HTML/JS"라 포토랩을 **따로 React+Vite 프로젝트**로 만들어 빌드 결과를 복사해 붙이자
   - 실제: 동영상 편집기는 **웹사이트(Next.js·React) 화면을 앱이 띄우는 구조** (`src/components/admin/studio-video` + 앱 `video/ipc.js` 통로)
2. 이미 만든 부품을 그대로 쓸 수 있다: 글꼴 목록(최근·즐겨찾기), 캡컷식 색판, 스티커 그리기, 글자 칸 탭(TextTabs), 사전설정 저장, AI 그림 통로
3. 문서는 v0.1.9 기준 — 지금 0.1.10 (Whisper·내 목소리·애니메이션 굽기 등 더 있음)

## 3. 동영상 편집기 글자 칸을 포토랩 글자 레이어에 (2026-10-19 사장님 질문: "자막 부분을 적용 — 효과 애니메이션은 빼더라도")

- 답: **된다.** 글자 칸(TextTabs)은 부품 하나 → 포토랩에서는 [애니메이션] 탭만 빼고 [텍스트(기본·말풍선·편집효과)] · [사전설정] 그대로
- 그리고 항목마다 **PSD 글자 속성·레이어 스타일과 짝**이 있어 포토샵에서 열어도 고칠 수 있다

| 글자 칸 | PSD (ag-psd) | 포토샵에서 |
|---|---|---|
| 글꼴 · 글자 크기 · 색상 | `text.style.font / fontSize / fillColor` | 문자 패널 |
| 패턴 B · I · U | `fauxBold / fauxItalic / underline` | 문자 패널 (가짜 굵게·기울임·밑줄) |
| 대소문자 TT | `fontCaps` (모두 대문자) · tt·Tt 는 글자 자체를 바꿔 저장 | 문자 패널 |
| 문자 간격 · 줄 간격 | `tracking` · `leading` (자동 = `autoLeading`) | 자간·행간 |
| 정렬 | `paragraphStyle.justification` | 단락 패널 |
| 투명도 | 레이어 `opacity` (또는 `fillOpacity`) | 불투명도·칠 |
| 테두리 (색·두께·투명도) | 레이어 스타일 `stroke` (바깥쪽) | 획 |
| 그림자 (색·거리·투명도) | `dropShadow` | 드롭 섀도 |
| 빛 (색·크기·투명도) | `outerGlow` | 외부 광선 |
| 글자 뒤 상자 (색·여백·투명도) | 글자 뒤에 **사각형 레이어** 하나 더 (그룹으로 묶음) | 모양 레이어 |
| 편집효과 견본 · 사전설정 | 위 값들의 묶음 → 그대로 저장 | 레이어 스타일로 보임 |
| 말풍선 | 스티커 그림 레이어 + 글자 레이어 (또는 그림 한 장) | 이미지 레이어 |

- 빼는 것: 애니메이션 탭, 메인자막 전용(이 클립 자막·적용 범위·위치 자동), 나오는 구간
- 바꾸는 것: 위치 = 캔버스 위 끌기·정렬(맞춤 및 분포), 글자 크기 단위 = pt/px

## 3-1. 화면은 쉽게, 파일은 PSD — 포토샵 호환이 핵심 (2026-10-19 사장님)
- 사장님: "대신 파일 저장은 PSD 가 가능하다는 거야. 포토샵과 호환이 된다는 점이지"
- Claude 안: **저장 = .psd 그 자체** (따로 우리 파일 형식을 만들지 않는다)
  - [저장] → `이름.psd` (포토샵에서 바로 열림 · 글자는 글자로, 효과는 레이어 스타일로, 묶음은 그룹으로)
  - [내보내기] → PNG · JPG · GIF (웹용)
  - [열기] → 디자이너 PSD 그대로 (템플릿)
- 포토샵에 없는 우리만의 정보(스티커 모양·글자 칸의 자동 간격·말풍선 등)는 **PSD 안 메모(XMP)** 에 함께 담는다 → 포토랩으로 다시 열면 그대로 고칠 수 있고, 포토샵은 그 메모를 그냥 무시 (화면에는 같은 그림)
- 포토샵으로 나타낼 수 없는 것은 저장할 때 그림으로 굳히고 레이어 이름에 "(그림으로 저장됨)" 표시
- 시험: 저장한 PSD 를 포토샵에서 자동으로 열어 레이어·효과를 검사 (인수인계 5-5 방법), 마스크처럼 화면에서만 나는 문제는 사람이 확인
