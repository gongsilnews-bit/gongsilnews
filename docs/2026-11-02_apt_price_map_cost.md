# 공실열람 실거래가 지도 — 자동 갱신(크론)과 비용

2026-11-02 정리. 공실열람 아파트·오피스텔 실거래가 지도의 자료를 매일 밤 갱신하는 방식과, 그때 드는 비용을 정리한다.

## 1. 지금 돌아가는 것

| 항목 | 내용 |
|---|---|
| 크론 주소 | `/api/cron/apt-prices?lawd=시군구코드[&kind=offi]` |
| 등록된 크론 | 강남·서초·송파 × 아파트·오피스텔 = 하루 6번 (새벽 4시대, `vercel.json`) |
| 한 번에 하는 일 | 실거래(최근 36개월) → 위치 → 공급면적·세대수 → 단지 정보 → 경매 단지 잇기 |
| 한 번 최대 시간 | 5분 (`maxDuration = 300`) |
| 코드 | `src/utils/aptMap.ts` · `src/utils/auctionMatch.ts` · `src/app/api/cron/apt-prices/route.ts` |

서울 나머지 22개 구와 경기 남부는 자료를 한 번 넣어 두었지만, **매일 밤 자동 갱신 목록에는 아직 없다** (6절).

### 2026-11-03 바꿈 — 전국 아파트·오피스텔을 매일 밤 (배포 전)

| 크론 | 시각 (한국) | 하는 일 |
|---|---|---|
| `/api/cron/apt-prices/round?mode=recent` | 새벽 2:00~6:55, 5분마다 60번 | 모든 시군구 × 아파트·오피스텔을 60 덩이로 나눠 **최근 3개월만** (`syncRecent`) — 그 달 거래만 바꿔 끼운다. 새 단지가 생기면 위치·평형·정보도. 경매 단지 잇기 |
| `/api/cron/apt-prices/round?mode=full` | 밤 0:00~1:55, 5분마다 24번 | 그날 차례 시군구 하나씩 **36개월 전체** (`syncTrades`) — 28일에 한 바퀴 |

- 어디까지 했는지 따로 적지 않고 시각으로 차례를 안다. 하루 빠져도 다음 날 다시 돈다.
- 예전 구마다 크론 6개(강남·서초·송파)는 뺐다.
- 시험(2026-11-03 강남 아파트): 처음 한 번은 353곳을 다시 썼고(거래 차례가 맞춰지며), 바로 다시 돌리면 0곳. 36개월 거래 수는 그대로.

## 2. 비용 — 항목별

| 항목 | 비용 | 이유 |
|---|---|---|
| 공공데이터포털 API (국토부 실거래가 · 건축물대장 · 공동주택 기본정보) | 무료 | 호출 횟수 한도만 있다. 돈은 들지 않는다 |
| 카카오 주소·장소 검색 | 무료 | 하루 무료 한도 안. 위치는 단지마다 한 번만 찾는다 |
| Supabase (DB) | 추가 없음 | Pro 요금 안. 서버 Micro(월 $9.68, Nano 와 같은 값). 2026-11-02 기준 DB 0.45GB / 8GB |
| Vercel (크론 실행) | 거의 없음 — **확인 필요** | 함수가 일한 시간만큼 사용량이 잡힌다. 지금 규모는 Pro 포함 사용량 안으로 본다 |
| AI (Claude · Gemini) | 없음 | 시세 크론은 AI 를 쓰지 않는다 |
| PC 캡처 자동 심사 (`scripts/apt-review`) | 따로 없음 | 사장님 클로드 구독 안에서 돈다 (사용량은 조금 씀). 기다리는 요청이 없으면 클로드를 켜지 않는다 |

Vercel 요금 기준은 자주 바뀐다. 배포 며칠 뒤 **Vercel 대시보드 → Usage → Functions** 사용량을 한 번 확인한다.

## 3. 이미 가볍게 해 둔 것

- **바뀐 단지만 다시 쓴다** — 단지마다 거래 지문(`fp`: 건수·최근 거래)을 두고, 같으면 DB 에 쓰지 않는다.
- **한 번만 찾는 것** — 위치(`geo_tried_at`) · 공급면적·세대수(`unit_map`) · 단지 정보(`info_tried_at`)는 처음 한 번만 찾는다.
- **조금씩 나눠 쓴다** — 한 번에 10곳씩 쓰고 사이에 쉰다. 전월세는 단지마다 최근 100건만 둔다.
  - 2026-11-02 오전, Nano 서버에 큰 자료를 한꺼번에 넣다가 DB 가 멈춘 일이 있어서 바꿨다.

## 4. 넓힐 때 바꿀 것 (서울 전체 · 경기도를 매일 밤)

크론 실행 시간이 지금의 10~15배가 된다. 그 전에 아래처럼 바꾼다.

1. **매일 밤은 최근 2~3개월만** 실거래를 받는다. 실거래는 계약 후 30일 안에 신고되므로 최근 몇 달만 바뀐다.
2. **36개월 전체는 한 달에 한 번** 받는다 (오래된 달이 빠지고 새 달이 들어가게).
3. **크론 하나가 여러 구를 차례로** 돈다 — Vercel 크론 개수 한도 때문에 구마다 크론을 만들지 않는다. 예: 한 번 부를 때 다음 차례 구 몇 개만 하고, 어디까지 했는지 DB 에 적어 둔다.

이렇게 하면 서울·경기 전체로 넓혀도 비용은 거의 늘지 않을 것으로 본다. 넓힌 뒤에도 2절의 Vercel 사용량을 다시 확인한다.
