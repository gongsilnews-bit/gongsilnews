# [작업 지시서] 크롬 확장 프로그램 뉴스메이커(v1.0.0) 
## 2단계 기사 소재: '아파트 단지 시세' & '우리동네 시세' 기능 구현

> **수신**: Claude Code (클로드 코드)  
> **프로젝트**: 공실뉴스 (GongsilNews)  
> **대상 모듈**: `chrome-extension/newsmaker10`  
> **작업 일자**: 2026-10-03  

---

## 1. 작업 개요 및 목표

공실뉴스 크롬 확장 프로그램(`chrome-extension/newsmaker10`)의 **[STEP 2: 기사 소재 입력]** 영역을 고도화하여, 공인중개사와 기자가 **네이버 부동산/국토부 실거래가 단지 시세** 및 **우리동네(행정동 단위) 종합 시세** 기사를 10초 만에 작성할 수 있도록 신규 탭과 스마트 입력 도구를 추가한다.

또한 생성된 기사가 공실뉴스 메인 및 **`우리동네뉴스 (지도형 뉴스: /news_map)`**와 100% 호환되도록 메타데이터 및 프롬프트를 연계한다.

---

## 2. 2단계 소재 선택 탭 재구성 (순서 확정)

기존의 `[뉴스 가져오기] / [주제 입력]` 2개 탭 구조를 **4개 탭**으로 확장하며, **'주제 직접입력'을 4번째 맨 뒤로 배치**한다.

| 탭 순서 | 탭 이름 | 영문 식별자 (`source-mode`) | 핵심 용도 및 특징 |
|:---:|:---|:---:|:---|
| **①** | **뉴스 가져오기** | `news` | (기존 유지) 현재 브라우저 탭의 기사 본문 자동 추출 |
| **②** | **단지 시세 분석** | `complex` | **[신규]** 특정 아파트 단지의 실거래가·호가 변화 분석 기사 작성 |
| **③** | **우리동네 시세** | `local` | **[신규]** 동네(행정동) 대장 아파트 비교 및 지도 연동 시세 기사 작성 |
| **④** | **주제 직접입력** | `topic` | (순서 이동) 자유 주제/서론·본론·결론 직접 기획 기사 작성 |

## 3. 세부 기능 구현 명세

### 3.1. [탭 ②] '단지 시세 분석' (`data-source-mode="complex"`)

특정 아파트 단지의 시세 변동과 실거래 데이터를 집중 분석하는 입력 폼이다.

#### ① 스마트 데이터 입력 (3가지 방식 지원)
1. **[지금 보는 네이버부동산 가져오기] 원클릭 버튼**:
   - 현재 활성화된 탭이 `land.naver.com` 또는 `new.land.naver.com`인 경우 클릭 한 번으로 단지명, 주소, 세대수, 면적타입, 최근 실거래가, 현재 매물 호가를 스크랩하여 폼에 자동 입력.
2. **'스마트 텍스트 붙여넣기' (Ctrl+V 스마트 파서)**:
   - 국토부 실거래가 조회 창이나 네이버 부동산 텍스트를 복사해서 붙여넣으면 정규식/AI 파서가 `단지명`, `전용면적(㎡)`, `거래금액`, `층수`, `거래일`을 자동 추출하여 입력 칸에 채움.
3. **수동 입력 필드**:
   - 단지명 (예: 대치 은마, 반포자이)
   - 전용면적/평형 (예: 84㎡ / 34평형)
   - 최근 실거래가 및 이전 대비 변동 (예: 24억 5,000만 원, 전고점 대비 +1.5억)
   - 현재 매물 호가 범위 (예: 매매 25억 ~ 27억 / 전세 11억 ~ 12억)

#### ② 캡처 이미지 붙여넣기 박스 (`Ctrl+V`)
- 네이버 부동산 매물 화면이나 실거래가 그래프를 캡처(`Win+Shift+S`)한 뒤 폼의 드롭존을 클릭하고 `Ctrl+V`를 누르면 즉시 미리보기 썸네일 노출.
- 이미지 파일 첨부/삭제 지원. (기사 발행 시 썸네일 또는 본문 첨부 이미지로 자동 전달)

#### ③ 기사 분석 관점 (라디오 버튼 / 칩 선택)
- `[신고가/반등]` : 전고점 회복 및 신고가 갱신 중심 상승세 분석
- `[급매소진/눈치]` : 급매물 소진 후 매수-매도자 간 호가 눈치싸움 분석
- `[전세가율/갭]` : 전세가 상승에 따른 갭투자 수요 및 전세가율 분석
- `[객관적 브리핑]` : 중립적이고 사실에 기반한 시세 브리핑

---

### 3.2. [탭 ③] '우리동네 시세' (`data-source-mode="local"`)

특정 동네(읍·면·동) 단위의 부동산 흐름과 2~3개 대표 단지를 비교 분석하는 입력 폼이다.

#### ① 지역 타겟팅
- **지역명/행정동 입력**: (예: `서울시 강남구 대치동`, `경기도 성남시 분당구 정자동`)
  - 공실뉴스 `news_map` 및 기사 메타데이터의 `region_gu`, `region_dong`으로 자동 매핑됨.

#### ② 동네 대표 대장 단지 비교 (최대 3개)
- 단지 1: (예: 래미안대치팰리스 / 84㎡ / 매매 33억 / 전세 18억)
- 단지 2: (예: 대치 은마아파트 / 76㎡ / 매매 24.5억 / 전세 8억)
- 단지 3: (선택 입력)

#### ③ 동네 분위기 및 핵심 테마 키워드 (체크박스/태그)
- `[학군 수요]`, `[역세권/교통 호재]`, `[재건축/재개발 속도]`, `[거래량 급증]`, `[전세 품귀]` 등 칩 선택

#### ④ 동네 지도/시세표 캡처 이미지 붙여넣기 (`Ctrl+V`)
- 네이버 지도 화면이나 아실/호갱노노 동네 지도 캡처 이미지 붙여넣기 지원.

---

### 3.3. [탭 ④] '주제 직접입력' (`data-source-mode="topic"`)
- 기존의 '주제 입력' 탭을 4번째 맨 마지막으로 이동.
- 기존 입력 필드(주제, 취재내용/핵심사실, 서론·본론·결론 가이드) 정상 동작 유지.

## 4. 프롬프트 생성 엔진 (Prompt Engine) 연동

사용자가 `[단지 시세 분석]` 또는 `[우리동네 시세]`를 선택하고 `[기사 생성]` 또는 ChatGPT/Gemini 복사 버튼을 눌렀을 때, 고품질 부동산 전문기자 프롬프트가 생성되어야 한다.

### 4.1. [단지 시세 기사] 생성 프롬프트 규격
```text
당신은 대한민국 1위 부동산 전문 기자입니다. 
아래 제공된 [아파트 단지 시세 데이터]와 [분석 관점]을 바탕으로, 공실뉴스(GongsilNews)에 송고할 독점 부동산 심층 분석 기사를 작성하십시오.

■ 단지 정보 및 시세 데이터:
- 단지명: {complexName}
- 소재지: {regionText}
- 평형/전용면적: {areaSize}
- 최근 실거래가: {recentPrice} (거래일/층수: {dealDetails})
- 이전 거래 대비 변동: {priceChange}
- 현재 호가 현황: {askingPrice}
- 분석 관점: {analysisView}

■ 기사 작성 원칙:
1. 헤드라인: 독자의 클릭을 부르는 전문적이고 생생한 경제 헤드라인 (3개 추천안 제시).
2. 리드문: 최근 실거래 사례를 구체적으로 언급하며 시장 분위기를 짚어줄 것.
3. 본문 구성:
   - 1단락: 최근 실거래 팩트와 가격 변동 폭 심층 분석
   - 2단락: 현장 중개업소 호가 흐름 및 집주인-매수자 간 심리(눈치싸움 등)
   - 3단락: 향후 전망 및 전문가 제언 (금리, 대출, 입주물량 영향)
4. 신뢰도: 숫자는 정확하게 명시하고, 중개 현장의 생생한 목소리를 인용 형식으로 포함할 것.
```

### 4.2. [우리동네 시세 기사] 생성 프롬프트 규격
```text
당신은 지역 부동산 전문 기자입니다.
아래 제공된 [지역 정보]와 [동네 대장 아파트 비교 데이터]를 바탕으로, 공실뉴스 [우리동네뉴스 지도판]에 게재될 지역 부동산 동향 종합 기사를 작성하십시오.

■ 지역 정보:
- 대상 지역: {targetRegion} ({guName} {dongName})
- 주요 테마: {themeKeywords}
- 대표 비교 단지 현황:
  * 단지 A: {complexA_Info}
  * 단지 B: {complexB_Info}
  * 단지 C: {complexC_Info}

■ 기사 작성 원칙:
1. 헤드라인: 지역명이 명확히 드러나고 동네 주민과 투자자의 이목을 끄는 헤드라인.
2. 기사 성격: 특정 단지만 띄우는 것이 아닌, {dongName} 일대의 전반적인 매매/전세 흐름과 대장 아파트들의 견인 효과를 비교 분석.
3. 공실뉴스 지도 연동 메타데이터 태그 포함:
   - CATEGORY: 우리동네뉴스
   - REGION_GU: {guName}
   - REGION_DONG: {dongName}
```

## 5. 수정 대상 파일 및 개발 가이드

크롬 확장 프로그램 디렉토리: `chrome-extension/newsmaker10/`

### 1) `panel.html`
- **소재 탭 버튼 영역 수정**:
  - `data-source-mode="news"` (뉴스 가져오기)
  - `data-source-mode="complex"` (단지 시세 분석 - NEW)
  - `data-source-mode="local"` (우리동네 시세 - NEW)
  - `data-source-mode="topic"` (주제 직접입력 - 4번째 위치로 이동)
- **컨테이너 추가 및 배치**:
  - `#sourceNewsBox` (기존 뉴스 박스)
  - `#sourceComplexBox` (신규: 네이버 원클릭 버튼, 스마트 파서 붙여넣기, 단지 입력 폼, Ctrl+V 이미지 드롭존, 관점 라디오)
  - `#sourceLocalBox` (신규: 지역/동 입력, 단지 비교 폼, 키워드 칩, 지도 캡처 드롭존)
  - `#sourceTopicBox` (기존 주제 박스를 4번째로 이동)

### 2) `panel.css`
- 신규 탭 칩 스타일 (`.source-chip`), 반응형 4분할 그리드 또는 플렉스 래핑
- 캡처 이미지 붙여넣기 드롭존 스타일 (`.paste-dropzone`, hover/focus 상태, 썸네일 미리보기 `.image-preview-badge`)
- 네이버 부동산 원클릭 연동 배너/버튼 스타일 (`.btn-naver-sync`)
- 단지 비교 다중 카드 스타일

### 3) `panel.js`
- **탭 전환 핸들러 업데이트**:
  - `renderSourceMode(mode)`에서 `news`, `complex`, `local`, `topic` 4가지 상태 완벽 분기 처리
- **클립보드 이미지 붙여넣기(`paste`) 이벤트 리스너**:
  - `paste-dropzone` 요소에서 `e.clipboardData.items` 중 `image/*`를 감지하여 DataURL(Base64)로 변환 후 미리보기 및 state 저장
- **스마트 텍스트 파서 함수 구현**:
  - 국토부/네이버 부동산 텍스트 입력 시 정규식 패턴(`/\d+억\s*\d*만?원?/`, `/\d+\.?\d*㎡/`) 매칭하여 폼 필드 자동 완성
- **프롬프트 빌더 확장**:
  - `buildPrompt()` 함수 내에서 `currentSourceMode === 'complex'` 및 `'local'`에 맞춘 전용 프롬프트 리턴
- **원클릭 네이버 스크래퍼 메시지 전송**:
  - `chrome.tabs.query`로 현재 활성 탭이 네이버 부동산인지 체크 후, 스크립트 실행(`chrome.scripting.executeScript`)하여 단지 데이터 추출 수신

### 4) `content-naver.js` (또는 네이버 단지 스크래퍼)
- 네이버 부동산 단지 페이지(`new.land.naver.com/complexes/...`)에서:
  - 단지명: `.complex_title`, `.title` 등
  - 면적 정보, 매매 실거래가, 매물 호가 추출 로직 보강
