# 공실뉴스 AI 유튜브작성기 `youtubewriter10` 독립 개발 계획

**작성일:** 2026년 9월 26일  
**상태:** 1~4단계 1차 구현 완료 · 음성 단계 제외  
**신규 대상:** `chrome-extension/youtubewriter10/`  
**확장 프로그램 이름:** 공실뉴스 AI 유튜브작성기  
**관련 기존 확장:** `chrome-extension/gongsilwriter10/`

---

## 0. 결정 사항

기존 공실뉴스 AI 기사작성기에 유튜브 탭을 추가하지 않는다. 기사·블로그 작성기는 그대로
보존하고, 유튜브 대본과 이미지는 새로운 전용 Chrome 확장 프로그램에서 작성한다.

```text
기존: gongsilwriter10
      1 매물·AI → 2 초안 다듬기 → 3 블로그 작성

신규: youtubewriter10
      1 자료 가져오기 → 2 유튜브 대본 → 3 유튜브 이미지
```

새 확장은 다음 회원만 사용할 수 있다.

- 공실뉴스부동산 회원
- 공실스터디부동산 회원
- 최고관리자

---

## 1. 폴더와 기존 기능 보호 원칙

### 신규 폴더

```text
chrome-extension/youtubewriter10/
```

### 주의

현재 `chrome-extension` 아래에는 철자가 빠진 빈 폴더 `youtubewrter10`이 있다. 새 확장은
올바른 철자인 `youtubewriter10`에 만들고, 기존 폴더는 명시적인 정리 요청 전까지 삭제하거나
덮어쓰지 않는다.

### 불변 범위

- `gongsilwriter10`의 기사 작성 기능을 제거하지 않는다.
- `gongsilwriter10`의 블로그 작성 기능을 제거하지 않는다.
- `auctionwriter`, `autionwriter10`을 변경하지 않는다.
- 새 유튜브 작업 상태와 이미지는 기존 작성기 저장 상태와 섞지 않는다.
- 공통 코드를 재사용할 때도 신규 확장이 독립 설치·실행될 수 있어야 한다.

## 2. 제품 목표와 범위

### 1차 목표

완성된 기사, 공실 매물 또는 직접 입력한 자료를 바탕으로 다음 결과물을 만든다.

1. 유튜브용 제목과 대본
2. 장면별 내레이션·자막·화면 설명
3. 장면별 실제 사진 또는 AI 이미지
4. 프리미엄 PPT 스타일 장면
5. 유튜브 썸네일
6. 대본과 이미지 내보내기

### 이번 1차 범위에서 제외

- 유튜브 채널 자동 업로드
- 완성 영상 렌더링
- AI 아바타와 립싱크
- AI 음성 파일 생성
- 배경음악 자동 삽입
- 댓글 자동 응답

단, 향후 아래 순서로 확장할 수 있도록 데이터 구조를 준비한다.

```text
1 자료 → 2 대본 → 3 이미지 → 4 음성·자막 → 5 영상 완성
```

## 4. 전체 권한 정책

기존 기사작성기의 3단계 블로그 권한과 같은 회원 범위를 사용하되, 이름은 유튜브 전용으로
분리한다.

### 허용 대상

| 구분 | 내부 판정 예 | 허용 |
|---|---|---:|
| 최고관리자 | 유효 플랜 `admin`, 역할 `ADMIN`, `SUPER_ADMIN`, `최고관리자` | O |
| 공실뉴스부동산 | 유효 플랜 `news_premium` | O |
| 공실스터디부동산 | 유효 플랜 `study_premium` | O |
| 기간 만료 회원 | `getEffectivePlan()` 결과가 무료 | X |
| 무료부동산·일반회원 | 그 외 플랜 | X |
| 비로그인 | 회원 없음 | X |

### 구현 원칙

1. `/api/extension/auth/me`에 의미가 분명한 `canYoutubeWriter` 값을 추가한다.
2. `canBlog` 값을 유튜브 권한으로 암묵적으로 재사용하지 않는다.
3. 회원 범위가 현재 같더라도 두 권한은 나중에 독립적으로 바꿀 수 있게 한다.
4. 사이드패널 잠금은 안내용이며, 보호 데이터 API도 서버에서 권한을 다시 확인한다.
5. 최고관리자의 모든 역할 표기를 테스트해 누락되지 않게 한다.
6. 로그인 쿠키 또는 유효한 Bearer 토큰으로만 회원을 판정한다.
7. 이메일 쿼리나 임의의 클라이언트 값으로 권한을 부여하지 않는다.

### 잠금 화면

```text
공실뉴스 AI 유튜브작성기는 회원 전용입니다.

공실뉴스부동산·공실스터디부동산 회원과
최고관리자만 사용할 수 있습니다.

[공실뉴스 로그인] [회원 신청하기] [다시 확인]
```

권한 확인에 실패한 경우에는 미가입으로 단정하지 않고 `회원 정보를 확인하지 못했습니다`와
재시도 버튼을 표시한다.

## 5. 화면 구조

```text
┌ 공실뉴스 AI 유튜브작성기 v1.0 ─────── [초기화] ┐
├ [1 자료 가져오기] [2 대본 작성] [3 이미지 작성] ┤
│                                                  │
│ 선택한 단계의 작업 화면                          │
│                                                  │
└──────────────────────────────────────────────────┘
```

탭 이름은 좁은 화면에서 `1 자료 / 2 대본 / 3 이미지`로 줄일 수 있다. 각 화면 내부 제목은
`자료 가져오기`, `유튜브 대본 작성`, `유튜브 이미지 작성`으로 온전히 표시한다.

### 단계 잠금

- 권한 확인 전에는 모든 작업 버튼을 비활성화한다.
- 자료가 없으면 2단계 생성을 시작할 수 없다.
- 대본과 장면이 없으면 3단계 이미지 생성을 시작할 수 없다.
- 사용자가 이전 단계로 돌아가는 것은 항상 허용한다.

## 6. 1 · 자료 가져오기

### 자료 종류

| 자료 | 가져오는 내용 |
|---|---|
| 공실뉴스 기사 | 제목, 부제, 본문, 키워드, 대표 이미지, 기사 URL |
| 공실 매물 | 매물명, 유형, 거래조건, 가격, 면적, 주소, 시설, 주변환경, 실제 사진 |
| 직접 입력 | 사용자가 붙여넣은 기사·메모·보도자료 |

### 화면

```text
자료 종류
[공실뉴스 기사] [공실 매물] [직접 입력]

[열린 페이지에서 가져오기]

또는
[기사 URL/공실번호                         ]
[자료 불러오기]

가져온 자료
┌───────────────────────────────────────┐
│ 제목                                  │
│ 핵심 정보                             │
│ 원문 요약                             │
│ 실제 사진 6장                         │
└───────────────────────────────────────┘
```

### 기존 기사작성기에서 보내기

최종 사용 흐름에는 `gongsilwriter10`의 초안 화면에 아래 버튼을 둘 수 있다.

```text
[유튜브작성기로 보내기]
```

단, 서로 다른 확장 프로그램은 `chrome.storage.local`을 자동으로 공유하지 않는다. 따라서
구현 전에 아래 전달 방식 중 하나를 확정해야 한다.

| 방식 | 설명 | 판단 |
|---|---|---|
| 현재 페이지에서 다시 읽기 | 열린 기사 또는 매물 페이지를 신규 확장이 직접 읽음 | 1차 구현에 가장 단순 |
| JSON 복사·붙여넣기 | 기존 작성기에서 유튜브용 자료를 복사하고 신규 작성기에 붙여넣음 | 안전한 보조 경로 |
| 단기 전달 토큰 | 서버에 짧게 보관하고 토큰으로 신규 확장이 받음 | 최종형으로 가장 안정적 |
| 확장 간 메시지 | 고정된 확장 ID로 직접 전달 | 개발·배포 ID 관리가 필요 |

**1차 권장:** 열린 공실뉴스 페이지에서 직접 가져오기 + JSON 붙여넣기 보조 기능.  
**최종 권장:** 서버의 단기 전달 토큰을 이용한 `유튜브작성기로 보내기`.

자료를 긴 URL 쿼리 문자열에 직접 넣는 방식은 길이 제한과 개인정보 노출 위험 때문에 사용하지 않는다.

## 7. 2 · 유튜브 대본 작성

### 영상 설정

| 설정 | 선택값 |
|---|---|
| 콘텐츠 유형 | 매물 소개 / 부동산 뉴스 / 지역 분석 |
| 영상 길이 | 60초 쇼츠 / 약 2분 / 약 5분 / 직접 입력 |
| 장면 길이 | 짧게 / 중간 / 길게 |
| 화면 비율 | `9:16` / `16:9` |
| 말투 | 뉴스 앵커형 / 친근한 설명형 / 전문가 분석형 |

### 장면 길이 규칙

| 선택 | 한 장면의 목표 길이 | 결과 |
|---|---:|---|
| 짧게 | 약 3~5초 | 빠른 전환, 장면과 이미지가 많아짐 |
| 중간 | 약 6~9초 | 정보 전달과 화면 변화가 균형을 이룸 |
| 길게 | 약 10~15초 | 한 화면을 오래 보여주며 이미지가 적어짐 |

장면 수와 이미지 수는 특정 숫자로 고정하지 않는다. 영상의 예상 재생시간을 장면 목표 길이로
나눈 값을 참고하되, AI가 문장과 의미가 자연스럽게 끝나는 위치에서 나눈다.

### 장면 결과

```text
장면 01 · 오프닝
내레이션: 서울 강남구 논현동에 50억 원대 단독주택이 나왔습니다.
자막: 논현동 단독주택 · 매매가 50억
화면 설명: 논현동 주택가와 대상 건물 외관

[직접 수정] [AI 수정] [나누기] [삭제]
```

### 대본 편집 기능

- 유튜브 제목과 설명문
- 전체 내레이션
- 장면별 내레이션·자막·화면 설명
- 장면 추가·삭제
- 장면 합치기·나누기
- 드래그 또는 버튼으로 순서 변경
- 직접 타이핑 수정
- 같은 ChatGPT·Gemini 대화에 이어서 AI 수정 요청
- 수정 결과 가져오기
- 예상 재생시간과 전체 장면 수 표시
- `대본 확정하고 이미지 작성으로 이동`

### 장면 ID

- 모든 장면에 변하지 않는 `sceneId`를 부여한다.
- 장면을 정렬해도 `sceneId`는 유지한다.
- 이미지, 썸네일 후보, 수정 이력을 모두 `sceneId`에 연결한다.
- 장면을 삭제하면 이미지를 즉시 없애지 않고 보관함으로 이동한다.
- 화면 설명이 크게 변경되면 해당 장면에 `이미지 재확인 필요`를 표시한다.

## 8. 3 · 유튜브 이미지 작성

3단계는 2단계에서 확정한 장면을 읽기 전용 원본으로 받아 시작한다. 이미지 화면에서 대본을
바꾸려면 `대본 수정으로 돌아가기`를 사용한다.

### 상단 설정

- 현재 대본 제목
- 화면 비율
- 전체 장면 수
- 실제 사진 수
- 선택한 이미지 스타일
- 스타일 잠금
- 전체 진행률

### 전체 작업 버튼

```text
[전체 장면 이미지 만들기]
[전체 장면 이미지 직접 넣기]
[실패한 이미지만 다시 만들기]
```

### 전체 장면 이미지 직접 넣기

사용자가 ChatGPT·Gemini 등에서 완성한 여러 이미지를 한 번에 선택해 장면에 넣을 수 있게 한다.

1. 여러 이미지 파일 선택 또는 드래그 앤 드롭
2. 파일명의 `scene-001` 같은 장면 번호가 있으면 우선 자동 매칭
3. 장면 번호가 없으면 파일명 자연 정렬 순서로 임시 배치
4. 적용 전 `장면 ↔ 이미지` 미리보기 표시
5. 사용자가 드래그하여 순서 조정
6. 기존 이미지 처리 방법 선택
   - 빈 장면만 채우기 — 기본값
   - 기존 이미지까지 바꾸기
7. 최종 확인 후 적용

이미지가 장면보다 적으면 나머지 장면은 비워두고, 이미지가 더 많으면 초과 이미지를 미배치
보관함에 둔다. 개수가 다르다고 임의로 삭제하거나 반복 삽입하지 않는다.

### 장면별 이미지 카드

```text
장면 01 · 오프닝
┌───────────────────────────────────────┐
│             완성된 이미지             │
└───────────────────────────────────────┘
[수정하기] [바꾸기] [이전 이미지] [삭제]
```

- `수정하기`: 현재 이미지를 기준으로 AI 수정 지시
- `바꾸기`: 다른 생성 이미지 또는 컴퓨터의 파일로 교체
- `이전 이미지`: 이전 후보 목록에서 되돌리기
- `삭제`: 장면 연결만 해제하며 원본은 보관함에서 복구 가능
- 수정·교체 후에도 같은 `sceneId`를 유지

### 다량 이미지 처리

- 이미지 총개수는 대본 길이와 장면 길이 설정으로 자동 결정한다.
- 전체 요청은 기본 5장 단위의 큐로 순차 처리한다.
- 상태는 `대기 / 생성 중 / 완료 / 실패 / 재확인 필요`로 표시한다.
- 중지해도 완료된 이미지는 유지한다.
- 실패한 장면만 다시 생성할 수 있다.
- 생성 완료 순서와 관계없이 `sceneId + jobId`로 정확히 배치한다.
- 장면별 여러 후보를 보존하고 최종 선택 이미지를 별도로 기록한다.

## 9. 이미지 스타일

스타일과 장면 종류를 분리한다.

- 스타일: 전체 영상의 색감과 표현 방식
- 장면 종류: 건물 외관, 실내, 거리, 지도, 통계 등 화면의 대상

### 한국형 이미지 스타일 7종

| # | 스타일 | 용도 |
|---:|---|---|
| 1 | 한국형 보도 실사 | 국내 뉴스 현장 사진처럼 자연스러운 기본 스타일 |
| 2 | 부동산 시네마틱 | 고가 주택·빌딩을 고급스럽게 표현 |
| 3 | 현장 취재 다큐 | 재개발·공실·상권 변화를 사실적으로 표현 |
| 4 | 밝은 매물 홍보 | 밝은 채광과 정돈된 광고 사진 분위기 |
| 5 | 한국형 인포그래픽 | 가격·면적·교통·수익률 설명 |
| 6 | 한국형 일러스트·웹툰 | 쇼츠와 어려운 개념 설명 |
| 7 | 프리미엄 PPT 프레젠테이션 | 사진·한글·수치·지도·도표를 슬라이드로 구성 |

### 한국형 공통 규칙

- 한국의 건물·도로·차선·골목·상권 형태 반영
- 지역 정보가 있으면 해당 도시의 분위기 반영
- 필요한 경우 맥락에 맞는 한국인 성인 사용
- 원화, `㎡`, 평 등 국내 부동산 표기 사용
- 외국식 주택가·간판·도로 요소 혼입 방지
- 가짜 한글을 이미지에 직접 생성하지 않음
- 실제 매물과 다른 구조를 사실처럼 단정하지 않음
- 필요한 장면에 `AI 생성 이미지` 표시

### 스타일 잠금

영상 전체에 색상, 카메라 분위기, 시간대, 사실성, 글꼴, 도표 디자인과 비율을 고정한다.
특정 장면만 변경하면 `개별 스타일` 표시를 붙인다.

## 10. 실제 사진 우선순위

1. 사용자가 특정 사진을 지정하면 최우선으로 사용한다.
2. 기사·매물에 연결된 실제 보도·현장 사진을 먼저 배치한다.
3. 실제 영상 또는 사용할 수 있는 캡처가 있으면 우선 활용한다.
4. 실제 자료가 없는 장면만 한국형 AI 이미지를 만든다.
5. AI 이미지 생성에 실패하면 직접 삽입으로 대체한다.

모든 이미지에는 `actual / generated / uploaded / rendered` 출처를 기록한다.

## 11. 프리미엄 PPT 프레젠테이션

PPT 스타일은 AI가 글자까지 그린 한 장의 그림으로 만들지 않는다.

```text
AI 또는 실제 사진: 배경·건물·인물
작성기 렌더러: 정확한 한글·가격·면적·도표·로고
최종 결과: 두 레이어를 합성한 장면 이미지
```

### 테마

- 공실뉴스 브랜드형 — 기본값
- 뉴스 브리핑형
- 프리미엄 부동산형
- 데이터 리포트형

### 레이아웃

- 표지
- 핵심 요약 3개
- 큰 사진 + 짧은 설명
- 사진 2분할 비교
- 핵심 숫자 강조
- 지도·교통·생활권
- 가격·면적·수익률 차트
- 장점과 주의점
- 결론과 문의 안내

`16:9`와 `9:16`은 같은 이미지를 자르는 방식이 아니라 비율별 레이아웃으로 각각 렌더링한다.

## 12. 썸네일 작성기

썸네일은 3단계 이미지 화면의 마지막 구역에 둔다.

- 대본 기반 썸네일 문구 3개 추천
- 문구 직접 수정
- 실제 사진 또는 AI 이미지 선택
- 공실뉴스 브랜드형·뉴스형·고급 매물형
- 문구 포함·미포함
- 여러 후보 생성 및 최종 선택
- 정확한 한글을 별도 렌더링
- `16:9` 다운로드

가격·면적·지역명은 원본 데이터에서만 가져오고 과장하거나 지어내지 않는다.

## 14. 저장과 복원

| 저장소 | 내용 |
|---|---|
| `chrome.storage.local` | 프로젝트 설정, 대본, 장면 메타데이터, 진행 상태 |
| `IndexedDB` | 원본 이미지, 미리보기, 수정 후보, 썸네일 |

- 다량 이미지를 Base64로 `chrome.storage.local` 한곳에 저장하지 않는다.
- 사이드패널을 닫거나 브라우저를 다시 시작해도 마지막 작업을 복원한다.
- 자료가 바뀌면 기존 프로젝트를 자동으로 덮어쓰지 않는다.
- 초기화는 삭제 대상을 먼저 표시하고 사용자가 확인한 뒤 실행한다.
- 장면을 삭제해도 연결 이미지는 바로 영구 삭제하지 않는다.

## 16. 단계별 구현 계획

### 1단계 — 독립 확장 뼈대와 권한

- 올바른 `youtubewriter10` 폴더 생성
- 별도 manifest, 이름, 아이콘, 버전
- 전역 사이드패널
- 회원 확인과 전체 잠금 화면
- `canYoutubeWriter` 서버 판정

**완료 기준:** 기존 확장과 동시에 설치되고, 허용 회원만 작업 화면을 볼 수 있다.

### 2단계 — 자료 가져오기

- 열린 공실뉴스 기사·매물 읽기
- URL 또는 공실번호 불러오기
- 직접 입력과 JSON 붙여넣기
- 실제 사진과 출처 수집
- 자료 저장·복원

**완료 기준:** 세 종류의 자료가 신규 확장에 독립 저장되고 새로 열어도 복원된다.

### 3단계 — 대본 작성

- 영상 설정
- ChatGPT·Gemini 선택·프롬프트·전송·응답 읽기
- 장면 JSON 검증
- 장면 길이에 따른 가변 분할
- 직접 수정과 AI 수정
- 장면 추가·삭제·합치기·나누기·정렬

**완료 기준:** 선택한 영상 길이와 장면 길이에 맞는 장면 대본이 만들어지고 수정 가능하다.

### 4단계 — 한 장면 이미지

- 실제 사진 우선 연결
- 장면별 AI 이미지 만들기
- 완성 이미지 가져오기
- 이미지 아래 `수정하기 / 바꾸기 / 이전 이미지 / 삭제`
- 후보 이력과 장면 ID 유지

**완료 기준:** 한 장면의 이미지가 다른 장면으로 이동하지 않고 수정·교체·복원이 된다.

### 5단계 — 전체 이미지와 직접 삽입

- 전체 장면 이미지 만들기
- 5장 단위 생성 큐
- 전체 장면 이미지 직접 넣기
- 자동 매칭 미리보기와 순서 조정
- 실패한 이미지만 다시 만들기
- 중지·재개·진행률

**완료 기준:** 장면 수가 달라져도 모든 이미지가 장면 ID에 맞게 연결된다.

### 6단계 — PPT 스타일과 썸네일

- 공실뉴스 브랜드 템플릿
- 한글·숫자·그래프 별도 렌더링
- `16:9`·`9:16` 레이아웃
- 썸네일 문구와 후보
- 다운로드

**완료 기준:** 한글과 숫자가 정확하고 모든 장면의 디자인이 통일된다.

### 7단계 — 기존 작성기 전달과 안정화

- `유튜브작성기로 보내기`의 최종 전달 방식 구현
- AI 사이트 화면 변경 대응
- 대용량 저장·복원·성능 점검
- 생성 중 종료와 재시작 복구
- 권한 만료 중 작업 처리
- README와 설치·사용 안내

## 20. 최종 완료 정의

다음 조건을 모두 만족하면 `youtubewriter10` 1차 버전이 완성된 것으로 본다.

1. 기존 작성기와 완전히 독립적으로 설치·실행된다.
2. 지정된 두 회원 플랜과 최고관리자만 사용할 수 있다.
3. 기사·매물·직접 입력 자료를 가져올 수 있다.
4. 장면 길이 설정에 맞춰 가변 개수의 대본 장면을 만든다.
5. 실제 사진을 우선 사용하고 부족한 장면에 AI 이미지를 만든다.
6. 전체 이미지 자동 생성과 전체 이미지 직접 삽입을 모두 지원한다.
7. 모든 장면 이미지 아래에서 수정·바꾸기·되돌리기가 된다.
8. 프리미엄 PPT 스타일과 유튜브 썸네일을 만든다.
9. 장면 수와 이미지 생성 순서가 달라도 잘못 연결되지 않는다.
10. 브라우저를 닫았다 열어도 프로젝트가 안전하게 복원된다.
