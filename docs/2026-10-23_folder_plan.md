# 회원 PC 폴더 정리 — 모두 `문서\공실스튜디오` 하나로 (2026-10-23 사장님 회의)

앱 이름을 **공실스튜디오**로 바꾸면서(docs/2026-10-23_naming_plan.md), 회원 PC에 흩어진 저장 폴더를 **`문서\공실스튜디오` 한 곳**에 모은다.
(앱 내부 저장 공간 `AppData\Roaming\공실뉴스 스튜디오` — 로그인·AI 키·설정 — 은 회원 눈에 안 보이는 곳이라 그대로 둔다.)

문제
- 폴더가 **네 곳**으로 흩어져 있다 (예전 이름·새 이름·이미지·문서).
- 한 폴더 안에 **종류 폴더(영상·녹화영상…)와 매물·칼럼·시뮬레이션 폴더가 섞여** 있어 찾기 어렵다.
- 같은 매물이 **두 폴더**로 갈라진 것이 있다 (`논현동 빌라 연립_88633` / `_137ef106`) — 공실번호를 모를 때 id 앞자리를 붙여서.

규칙
- 맨 위에는 **메뉴·종류 폴더만**. 매물·칼럼·시뮬레이션은 `뉴스SNS발행\` 안으로.
- 매물 폴더 이름은 `매물 이름_공실번호`. 공실번호를 모르면 나중에 알게 됐을 때 **같은 폴더를 계속 쓴다** (id 앞자리 폴더를 새로 만들지 않음).
- 영상 편집기 [저장 폴더]에서 회원이 **직접 고른 폴더는 그대로** (옮기지 않음).

## 3. 이미 있는 파일 옮기기

새 버전을 처음 켤 때 **한 번만** 예전 폴더의 내용을 새 자리로 옮긴다.

| 예전 | 새 자리 |
|---|---|
| `문서\공실뉴스 스튜디오\AI그림·AI영상·AI보이스·녹화영상·대본·영상·음악·캡쳐·휴지통` | `문서\공실스튜디오\` 같은 이름 폴더 |
| `문서\공실뉴스 스튜디오\<매물 이름_번호>` | `문서\공실스튜디오\매물\<매물 이름_번호>` |
| `문서\공실뉴스 스튜디오\칼럼_…` · `뉴스칼럼_…` | `문서\공실스튜디오\칼럼\…` |
| `문서\공실뉴스 스튜디오\인테리어_…` · `리모델링_…` | `문서\공실스튜디오\시뮬레이션\…` |
| `문서\공실뉴스 이미지\` (내 템플릿 포함) | `문서\공실스튜디오\이미지편집\` |
| `문서\공실뉴스 문서\` | `문서\공실스튜디오\문서\` |

옮길 때 지킬 것
- **같은 이름이 이미 있으면 덮어쓰지 않고 안의 파일을 합친다.** 같은 파일 이름이 있으면 옮기지 않고 그대로 둔다(잃어버리는 파일 없게).
- **앱이 기억하는 위치도 같이 고친다** — 영상 프로젝트(.gss) 안의 사진·영상 위치, 최근 파일(이미지·문서·영상), 내 자료 목록, 매물 폴더 이름 기억(folders.json).
  그래도 못 고친 곳이 있으면 열 때 "예전 자리 → 새 자리"로 한 번 더 찾아 본다.
- 다 옮기고 비게 된 예전 폴더는 지운다. 남은 파일이 있으면 예전 폴더를 그대로 두고 그 안에 `여기 남은 파일.txt`로 알린다.
- 옮기는 중에 앱을 끄면 다음에 켤 때 이어서 한다. 옮긴 결과는 앱 기록(log)에 남긴다.
- 옮기기 전에 회원에게 한 번 알린다: "저장 폴더를 문서\공실스튜디오 하나로 모았어요" (+ [폴더 열기]).

## 4. 고칠 곳 (코드)
- `studio-app/src/studio-root.js` — 종류 폴더 위치를 모두 여기서 (매물·칼럼·시뮬레이션·이미지·문서 …)
- `out-folder.js`(매물·칼럼·시뮬레이션 자리), `photo/ipc.js`(이미지), `doc/ipc.js`(문서), `video/folders.js`·`library.js`·`ipc.js`·`project.js`(영상·녹화·AI·캡쳐·휴지통)
- 새로: `studio-app/src/folder-move.js` — 3번 옮기기 (처음 켤 때 한 번, 위치 기억 고치기 포함)
- 앱 메뉴 [내 저장 폴더 열기] · 화면 안내 문구의 폴더 이름

## 5. 정할 것
1. 3번 **옮기기를 할지** — 안: 한다 (사장님 "공실스튜디오에 다 모아두자"). 안 하면 예전 파일은 예전 자리에 남고 새 것만 새 자리.
2. 예전 폴더가 비면 **지울지** — 안: 지운다 (남은 게 있으면 그대로 두고 안내 파일).

## 6. 순서
1. 새 저장 자리(2번) — 새로 저장하는 것부터 새 구조로
2. 옮기기(3번) — 이 PC(개발판)에서 먼저 해 보고 영상 프로젝트·최근 파일이 그대로 열리는지 확인
3. 설치판에 넣어 배포 (배포는 사장님이 말할 때)
