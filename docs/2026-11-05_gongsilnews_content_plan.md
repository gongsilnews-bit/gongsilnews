# 공실뉴스 회사 매체 운영 계획 — 기사·SNS·블로그를 매일 꾸준히 (어사이드 · 노트북LM)

- 날짜: 2026-11-05 (사장님 회의)
- 상태: **방향 정함 · 코드 시작 전.** 아래 "정할 것"을 정한 뒤 만든다
- 한 줄: 최고관리자(공실뉴스 회사)는 **매체(발행인)** 다. 우리동네부동산 자료(실거래·단지·공실·경매)와 시사로 기사를 매일 채우고, SNS·블로그로 퍼뜨려 **임대인·중개사를 공실뉴스 가입으로** 데려온다

---

## 1. 회원과 최고관리자는 성격이 다르다

| | 회원 (중개사) | 최고관리자 (공실뉴스 회사) |
|---|---|---|
| 역할 | 광고주 — 내 공실 홍보 | 매체 — 소식·정보 발행 |
| 목적 | 손님 문의 | **가입** (임대인 공실 등록 · 중개사 공실뉴스부동산) |
| 글 AI | 회원 본인 ChatGPT·Gemini (서버 키 안 씀) | 서버 AI 써도 됨 (기사 에이전트 규칙) · 어사이드 |
| 기사 | 한 달 4건 등 등급 한도 | 제한 없이, 바로 발행(APPROVED) |

## 2. 무엇을 쓰나

### 2-1. 부동산 데이터 기사 (우리만 쓸 수 있는 것 — 중심)
| 기사 틀 (예) | 자료 |
|---|---|
| 강남구에서 살 수 있는 10억 미만 아파트 5곳 | 단지 실거래 (최근 3개월 평균) |
| 이번 주 신고가 나온 단지 | 새 실거래 |
| 역세권 전세 3억 이하 빌라 | 빌라 전월세 실거래 + 역 위치 |
| 이번 주 ○○동에 새로 나온 공실 | 회원 공실 + 그 회원 사무소 |

### 2-2. 경매·공매 소개 (가입 입구)
- 공개 자료(온비드)라 광고 규정 걱정이 적다. "감정가 반값" 같은 말이 눌러 보게 만든다
- 기사·SNS 에는 요약(사진·감정가·최저가·입찰일)만 → **"자세히 보기는 공실뉴스에서"** → 상세는 무료 회원가입(지금 잠금 화면 그대로)
- 틀 예: 감정가 대비 반값 이하 TOP5 · 이번 주 입찰 마감 임박 · 유찰 2회 이상 · 1억 미만

### 2-3. 회원 공실 소개 (회원 혜택)
- 회원 공실 + **그 회원 사무소 표시 항목 전부**(상호·대표·등록번호·소재지·연락처, 매물 표시 항목)
- 카드 틀 1번 = 어사이드 시안(로드뷰 배경 · #동네 거래 · 단지 이름 · 방·층 · 가격 · 면적 · 동/역 · 사무소). 글자는 DB 값으로 자동, 로드뷰 출처 표시

### 2-4. 정치·경제·시사·생활 (매체를 다양하게)
- 경제·재테크(금리·대출·세금 → 집 살 때 영향), 정책·시사(부동산 정책·지역 개발), 생활(동네 맛집·여행·건강)
- 이미 있는 서버 **기사 자동 작성(크론)**: 하루 4번(8·14·17·20시), 12개 분야 — **지금 꺼져 있음** (agent_settings `article_cron` isActive false)

## 3. 지킬 것

1. **매물 광고 규정** — 중개사가 아닌 공실뉴스가 "○○ 매물, 연락 주세요"로 올리면 안 된다. **정보 기사** 로 쓰고, 매물마다 그 회원 사무소를 붙인다. 정확한 선은 시작 전 법률 확인
2. **회원 동의** — 공실 등록 화면·약관에 "공실뉴스 SNS·블로그 소개에 동의" (기본 켬, 끌 수 있게)
3. **숫자는 지어내지 않는다** — DB(재료 표) 그대로. 자료가 모자라면 있는 만큼만. 사무소 정보는 화면에서 읽지 말고 DB 값 (11-05 어사이드 카드: 착한임대 번호가 DB 02-542-3011 과 다르게 나옴)
4. **남의 기사·사진 베끼지 않기** — 여러 출처를 읽고 우리 말로 요약 + 출처 + 우리 시각. 네이버·다음 부동산·다른 언론사 사진 금지
5. **사진 출처** — 로드뷰·지도 캡처는 "사진: 카카오맵 로드뷰"·"지도: 카카오맵". 보도·정보 글에만, 광고 카드에는 드론·공매 사진·우리 사이트 캡처. 얼굴·번호판 또렷한 사진은 빼기. 각 회사 지도 이미지 이용 안내는 시작 전에 확인
6. **양보다 질** — AI 글을 대량으로 찍으면 구글·네이버가 낮게 본다. 하루 몇 건이라도 쓸모 있게
7. **정치 기사** — 정책 소개 위주, 치우치지 않게. 발행 전 사람 확인 권고
8. **주소** — 회원 공실은 건물 주소 대신 동·역까지만 쓰는 선택지

사진 순서 (기사 규칙과 같게): 우리 사이트 캡처·공매·회원 사진 → 드론 장면 → 로드뷰(출처) → AI 실사(나노바나나) → 스톡

## 4. 누가 무엇을

| 누가 | 하는 일 |
|---|---|
| **공실뉴스 서버** | 매일 새벽 **[기사 재료]** 표 만들기(숫자의 원본) · 회원 공실 카드 틀 채우기 · (켜면) 서버 자동 기사 |
| **어사이드** | 재료 표로 기사 쓰기(노트북LM·ChatGPT) → 공실뉴스 [기사 쓰기]에 등록 · 로드뷰 캡처 · SNS 게시 누르기 |
| **노트북LM** | 주간 브리핑 오디오·영상(→ 쇼츠릴스studio 로 유튜브), 인포그래픽·슬라이드. 숫자·한글 깨짐은 확인 |
| **사장님** | 정치 기사 확인 · 계정 보안(2단계 인증) · 결과 보고 방향 조정 |

### 하루 흐름 (예)
1. 새벽 — 서버가 [기사 재료] 갱신
2. 아침 — 어사이드: 재료 → 기사 1~2건 등록 · 시사 1건 · 사진 캡처
3. 기사 → 뉴스·SNS자동화로 블로그·인스타·스레드·페북 글 + 쇼츠
4. 어사이드가 채널마다 [채우기] → [게시] (사람 속도, 하루 몇 건)
5. 게시 주소 → 홍보현황 · 링크 꼬리표로 **어느 글이 가입을 데려왔는지** 대시보드에

### 요일 구성 (예)
월·수·금 데이터 기사 · 화·목 경매 · 토 회원 공실 · 매일 시사·경제 1건 · 주 2~3 생활 · 주 1회 노트북LM 브리핑

## 5. 만들 것 (순서)

1. **[기사 재료] 화면** (최고관리자) — 오늘 쓸 주제와 정확한 숫자·링크·사진·사무소 표시 항목을 표로. 매일 새벽 자동. 어사이드는 복사만
2. **어사이드용 [기사 규칙] 문서** — 제목 모양 · 본문 순서(요약 → 표 → 설명 → 공실뉴스 링크 → 가입 안내) · 3장 지킬 것
3. **[공실뉴스 홍보] 메뉴** — 탭: 데이터 기사 · 경매 소개 · 회원 공실 소개 · 오늘 올릴 것(채널별 한 줄 [채우기]·[올림 완료], 어사이드가 다루기 쉽게)
4. **회원 공실 카드 틀** — 어사이드 시안을 틀로, 글자는 DB
5. **가입 꼬리표·대시보드** — 링크마다 꼬리표, 글별 가입 수
6. (2단계) **메타 API** — 인스타·페북·스레드 게시까지 완전 자동 (비즈니스 계정·앱 심사) · 유튜브는 구글 심사 · 네이버 블로그는 계속 반자동

## 6. 최고관리자 메뉴 정리 (같은 회의, 안)

| 묶음 | 메뉴 |
|---|---|
| 매일 업무 | 대시보드 · 회원관리 · 공실관리 · 기사관리 · **공실뉴스 홍보(새로)** · 문의(1:1문의 + 문의관리 탭) |
| 돈 | 멤버십관리 · 포인트 · 광고(광고 + 스튜디오 광고 탭) |
| 콘텐츠 | 단지 정보 요청 · 게시판 · 특강관리 |
| 도구 | AI 비서실 · 부동산마케팅 · 부동산홈페이지 · 받아쓰기 낱말장 |
| 설정 | 통계 · 정보설정 · 매뉴얼 |

- 19개 → 합쳐서 16개 + 공실뉴스 홍보. (선택) 회원 화면처럼 [메뉴 편집]
- 거의 안 쓰는 메뉴는 사장님이 알려 주면 [더보기]로
