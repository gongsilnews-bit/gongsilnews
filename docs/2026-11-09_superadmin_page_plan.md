## 2. 새 최고관리자 페이지 — 세 부분

겉틀(왼쪽 메뉴·위쪽 머리줄)만 회원 관리자 모양으로 바꾸고, **각 메뉴 속은 그대로** 둔다. 주소는 `/admin` 그대로.
`StudioSidebar` 는 **가져다 쓰기만** 하고 파일은 고치지 않는다 (앱에 번지지 않게).

### ① 총괄 — 공실뉴스 전체 관리

**홈 화면 맨 위 = 가입 현황**
- 오늘 · 이번 주 · 이번 달 가입 수, 흐름 그래프
- 등급별: 부동산회원(무료) · 공실뉴스부동산(유료) · 유료로 바꾼 사람 · 만료 다가오는 사람
- 어디서 왔는지: 어느 기사·SNS 글을 보고 가입했는지 (링크 꼬리표)

**그 아래**
- 회원 활동: 공실 등록 · 기사 신청 · 포인트 사용
- 매출: 멤버십 · 포인트 결제
- 처리할 일: 문의 · 단지 정보 요청 · 기사 승인 대기 · 반려 뒤 재작성 중
- 전체 숫자(공실·기사·회원·문의 합계)는 맨 아래에 작게

모든 숫자는 DB 실제 값. 없으면 빈칸 (예시 값 금지).

### ② 공실뉴스 홍보 — 꾸준히

회원용 도구를 **그대로 같이 쓴다** — 뉴스·SNS자동화 · 포토studio · 쇼츠릴스studio. 관리자용을 따로 만들지 않는다 (고칠 곳 한 군데).
최고관리자일 때만 아래가 다르다.

| | 회원 | 최고관리자 |
|---|---|---|
| 홍보 대상 | 내 공실 | **공실뉴스** |
| 글의 재료 | 내 공실 | 서비스 소개 · 정보 기사(데이터·경매·시사) · 회원 혜택·소식 · 회원 공실 소개 |
| 한도 | 등급별 | 없음 |
| 발행 | 승인 신청 | 바로 발행 (APPROVED) |
| AI | 회원 본인 ChatGPT·Gemini | 서버 AI 써도 됨 (기사 에이전트 규칙) · 어사이드 |
| 글 끝 | 사무소 법정 표시 | "공실뉴스에서 더 보기 / 가입하기" 링크 |

**홍보 재료 예**
| 재료 | 예 |
|---|---|
| 서비스 소개 | "보고서·홍보지 1분 만에", "공실 사진으로 쇼츠 만들기" 기능 하나씩 |
| 정보 기사 | 데이터·경매·시사 기사 (매체 운영 계획 2장) |
| 회원 혜택·소식 | 금액, 특강, 새 기능 |
| 회원 공실 소개 | 회원 혜택으로 (그 회원 사무소 표시 붙임) |

**꾸준히 하는 장치**: 홍보 화면에 **이번 주 홍보 달력** — 채운 날·빈 날이 바로 보이게
**결과 보기**: 홍보현황 — 게시 주소 + 링크 꼬리표로 어느 글이 가입을 데려왔는지

### ③ 회원에게 연락 — 문자 · 카톡 · 사이트 알림

| | 내용 |
|---|---|
| 받는 사람 | 회원 목록에서 바로 고르기 (등급별 · 가입일 · 만료 예정 · 수신 동의한 사람만) |
| 보내는 길 | 문자(뿌리오) · 카톡 · 사이트 알림 |
| 기록 | 언제 · 누구에게 · 무엇을 · 성공했는지 — **실제 기록**으로 |
| 꾸준히 | 예약 발송 · 정기 발송 (예: 매주 월요일 소식) |

**지킬 법 (정보통신망법)**
1. **광고 문자는 수신 동의한 회원에게만.** 그래서 마케팅 수신 동의 칸부터 만든다
2. 광고 문자는 맨 앞 "(광고)" · 끝에 무료 수신거부 방법
3. 밤 9시 ~ 아침 8시 광고는 따로 동의 필요 → 그 시간엔 보내지 않게 막는다
4. 수신 동의는 2년마다 다시 확인 안내
5. **카톡 알림톡은 광고 불가** — 가입 완료·만료 안내 같은 정보성 글만. 홍보 카톡은 공실뉴스 카카오 채널 친구에게 따로 (친구톡·브랜드 메시지)
6. 정보성 안내(만료·공지·새 기능)는 동의 없이 보낼 수 있다

## 4. 진행 순서 (권고)

1. **겉틀 + 메뉴 묶음** — 위험 적고 바로 보인다
2. **마케팅 수신 동의 칸** — 가입 화면 · 회원 정보 · 회원관리 목록
3. **문자 실제 발송** — 정보성 안내부터 · 보낸 기록 저장 · 수신 동의자만 고르기
4. **홈 화면** — 가입 현황 · 처리할 일
5. **홍보 도구 연결** — 회원 도구 세 가지를 최고관리자에 열고 재료를 공실뉴스로
6. **홍보현황 가입 연결** — 링크 꼬리표 · 홍보 달력
