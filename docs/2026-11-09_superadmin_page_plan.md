## 2. 새 최고관리자 페이지 — 세 부분

겉틀(왼쪽 메뉴·위쪽 머리줄)만 회원 관리자 모양으로 바꾸고, **각 메뉴 속은 그대로** 둔다. 주소는 `/admin` 그대로.
`StudioSidebar` 는 **가져다 쓰기만** 하고 파일은 고치지 않는다 (앱에 번지지 않게).

### ① 총괄 — 공실뉴스 전체 관리

**홈 화면 맨 위 = 가입 현황**
- 오늘 · 이번 주 · 이번 달 가입 수, 흐름 그래프
- 등급별: 부동산회원(무료) · 공실뉴스부동산(유료) · 유료로 바꾼 사람 · 만료 다가오는 사람
- 어디서 왔는지: 어느 기사·SNS 글을 보고 가입했는지 (링크 꼬리표)

**그 아래**
- 회원 활동: 공실 등록 · 기사 신청 · 포인트 사용
- 매출: 멤버십 · 포인트 결제
- **처리할 일 (승인함)** — 숫자를 누르면 그 화면으로 바로 간다
  | 처리할 일 | 가는 곳 |
  |---|---|
  | 회원 승인 대기 | 회원관리 승인대기 |
  | 공실뉴스부동산 가입 신청 | 승인·결제 → 가입 신청 |
  | 결제 확인 (스마트스토어 주문 연결 안 된 것) | 승인·결제 → 결제 |
  | 기사 승인 대기 | 기사관리 승인대기 |
  | 문의 · 단지 정보 요청 | 각 메뉴 |
  | 반려 뒤 재작성 중 기사 | 기사관리 |
- 전체 숫자(공실·기사·회원·문의 합계)는 맨 아래에 작게

모든 숫자는 DB 실제 값. 없으면 빈칸 (예시 값 금지).

### ② 공실뉴스 홍보 — 꾸준히

회원용 도구를 **그대로 같이 쓴다** — 뉴스·SNS자동화 · 포토studio · 쇼츠릴스studio. 관리자용을 따로 만들지 않는다 (고칠 곳 한 군데).
최고관리자일 때만 아래가 다르다.

| | 회원 | 최고관리자 |
|---|---|---|
| 홍보 대상 | 내 공실 | **공실뉴스** |
| 글의 재료 | 내 공실 | 서비스 소개 · 정보 기사(데이터·경매·시사) · 회원 혜택·소식 · 회원 공실 소개 |
| 한도 | 등급별 | 없음 |
| 발행 | 승인 신청 | 바로 발행 (APPROVED) |
| AI | 회원 본인 ChatGPT·Gemini | 서버 AI 써도 됨 (기사 에이전트 규칙) · 어사이드 |
| 글 끝 | 사무소 법정 표시 | "공실뉴스에서 더 보기 / 가입하기" 링크 |

**홍보 재료 예**
| 재료 | 예 |
|---|---|
| 서비스 소개 | "보고서·홍보지 1분 만에", "공실 사진으로 쇼츠 만들기" 기능 하나씩 |
| 정보 기사 | 데이터·경매·시사 기사 (매체 운영 계획 2장) |
| 회원 혜택·소식 | 금액, 특강, 새 기능 |
| 회원 공실 소개 | 회원 혜택으로 (그 회원 사무소 표시 붙임) |

**공실뉴스 회사 채널 (11-09 확인)**: 유튜브 · 블로그 · 인스타 · 스레드 · 페이스북 · 카카오 채널

| 채널 | 무엇을 (안) |
|---|---|
| 유튜브 | 쇼츠 (기능 소개·데이터·경매) · 주 1회 노트북LM 브리핑 |
| 블로그 | 정보 기사 요약 + 공실뉴스 링크 |
| 인스타 | 카드뉴스 · 릴스 |
| 스레드 | 짧은 한 줄 소식 · 기사 링크 |
| 페이스북 | 기사 링크 · 카드 |
| 카카오 채널 | 친구에게 주간 소식 · 홍보 메시지 (③ 회원에게 연락과 이어짐 — 광고 카톡은 이 채널 친구에게만) |

**꾸준히 하는 장치**: 홍보 화면에 **이번 주 홍보 달력** — 채널 6곳 × 요일, 채운 칸·빈 칸이 바로 보이게
**결과 보기**: 홍보현황 — 게시 주소 + 링크 꼬리표로 어느 글이 가입을 데려왔는지

### ③ 회원에게 연락 — 문자 · 카톡 · 사이트 알림

| | 내용 |
|---|---|
| 받는 사람 | 회원 목록에서 바로 고르기 (등급별 · 가입일 · 만료 예정 · 수신 동의한 사람만) |
| 보내는 길 | 문자(뿌리오) · 카톡 · 사이트 알림 |
| 기록 | 언제 · 누구에게 · 무엇을 · 성공했는지 — **실제 기록**으로 |
| 꾸준히 | 예약 발송 · 정기 발송 (예: 매주 월요일 소식) |

**지킬 법 (정보통신망법)**
1. **광고 문자는 수신 동의한 회원에게만.** 그래서 마케팅 수신 동의 칸부터 만든다
2. 광고 문자는 맨 앞 "(광고)" · 끝에 무료 수신거부 방법
3. 밤 9시 ~ 아침 8시 광고는 따로 동의 필요 → 그 시간엔 보내지 않게 막는다
4. 수신 동의는 2년마다 다시 확인 안내
5. **카톡 알림톡은 광고 불가** — 가입 완료·만료 안내 같은 정보성 글만. 홍보 카톡은 공실뉴스 카카오 채널 친구에게 따로 (친구톡·브랜드 메시지)
6. 정보성 안내(만료·공지·새 기능)는 동의 없이 보낼 수 있다

## 6. 나중에 — 직원 등록과 권한

사장님 (11-09): "직원도 써야 함 · 추후 직원 등록을 하고 권한을 주려고 함 · 지역별로, 항목별로 권한을 줄지 생각 중"

### 6-1. 지금 상태
- 권한은 **최고관리자 아니면 회원**, 둘뿐이다 — [src/utils/permissionCheck.ts](../src/utils/permissionCheck.ts) `isAdminRole` (ADMIN·SUPER_ADMIN 등이면 전부 열림)
- 직원(일부만 여는 관리자) 개념이 없다

### 6-2. 권한 짜는 법 (안)
| 칸 | 고르는 것 |
|---|---|
| 역할 | 최고관리자 (전부) · 직원 (준 것만) |
| 항목별 | 메뉴마다 **안 보임 / 보기만 / 처리까지** — 예: 회원 승인 처리 · 결제 보기만 · 문자 안 보임 |
| 지역별 | 맡은 지역 (시·구) — 그 지역 회원·공실·기사·승인만 보이고 처리 |

- 예: "강남·서초 담당 직원 — 회원 승인·기사 승인 처리, 공실 보기만, 결제·문자 안 보임"
- 직원 등록: 최고관리자가 기존 회원 계정을 골라 직원으로 지정 → 항목·지역 체크

### 6-3. 꼭 지킬 것
1. **메뉴를 숨기는 것만으로는 안 된다.** 서버에서도 같은 권한을 확인한다 (주소를 직접 쳐서 들어와도 막히게)
2. **누가 처리했는지 기록** — 승인·반려·발송·결제 확인마다 처리한 사람 이름
3. 돈(결제·환불)과 직원 권한 바꾸기는 최고관리자만

### 6-4. 지금 할 것 (1단계에서)
- 권한 화면은 나중이지만, **1단계 메뉴를 짤 때 메뉴마다 이름표(key)를 붙여 둔다** → 나중에 그 이름표에 권한만 걸면 된다
- 승인·처리 기능에 "누가 했는지" 남기는 자리를 처음부터 둔다

### 6-5. 에이전트와 이어짐
클로드 에이전트도 **직원 한 명처럼** 권한을 준다 — 같은 항목·지역 체크로 "에이전트가 무엇을 처리까지 할 수 있는지"를 정한다. 권한 장치 하나로 직원과 에이전트를 함께 다룬다.

사장님: "추후에 이 모든 일을 클로드가 에이전트를 만들어 자동화했으면"

### 7-1. 원칙
1. **사람 화면을 먼저 만든다.** 에이전트는 그 화면이 쓰는 같은 서버 기능(승인·발송·발행)을 그대로 부른다 → 사람이 하든 에이전트가 하든 결과가 같고, 고칠 곳이 한 군데
2. **위험한 일은 준비만, 마지막 한 번은 사장님이 누른다.** 익숙해지면 하나씩 "혼자 해도 됨"으로 옮긴다
3. **모든 일을 기록한다** — [에이전트 작업 기록]: 언제·무엇을·왜·결과. 되돌릴 수 있는 것은 되돌리기 단추
4. **숫자는 DB 그대로** — 지어내지 않는다

### 7-2. 무엇을 어디까지

| 일 | 에이전트가 | 사장님이 |
|---|---|---|
| 아침 보고 (어제 가입·결제·처리할 일 요약 → 사장님 카톡·문자) | 혼자 | 읽기 |
| 공실뉴스 기사 쓰기·발행 | 혼자 (기사 에이전트 규칙 — 바로 APPROVED, 반려 시 재작성) | 반려로 고치기 |
| 공실뉴스 홍보 글·카드·쇼츠 만들기 | 혼자 만들어 홍보 달력에 채움 | 게시 확인 (처음엔) |
| 스마트스토어 주문 → 회원 연결·멤버십 부여 | 혼자 (이름·전화가 딱 맞을 때만), 애매하면 표시 | 애매한 것만 |
| 회원 승인 (중개사·사업자 서류) | 서류 읽고 "맞음 / 다름 / 흐림" 표시 | 승인 누르기 |
| 공실뉴스부동산 가입 신청 | 결제·서류 확인해서 정리 | 승인 누르기 |
| 회원 기사 승인 | 규정(매물 광고·사실 확인) 점검 결과 표시 | 승인 누르기 |
| 회원에게 문자·카톡 | 글 쓰기·대상 고르기(수신 동의자만)·시간 맞추기 | 발송 누르기 |
| 문의 답 | 답 초안 | 보내기 |
| 단지 정보 요청 | 읽고 채울 값 정리 | 반영 확인 |
| 환불·돈 · 회원 삭제 | **하지 않음** | 직접 |

### 7-3. 만드는 방법 (안)
- 공실뉴스 서버에 **Claude API (Agent SDK)** 로 에이전트를 둔다. 도구 = 위 서버 기능들
- 정해진 시간에 깨우기: Vercel 크론 (아침 보고 · 기사 · 주문 확인 등)
- 관리자 [AI 비서실] 메뉴를 에이전트의 집으로 — 작업 기록 · 켜고 끄기 · "혼자 해도 됨" 범위 설정
- 비용: 쉬운 일은 작은 모델, 판단이 필요한 일만 큰 모델

### 7-4. 순서
화면 정리(4장) 끝난 뒤 → ① 아침 보고 → ② 스마트스토어 주문 연결 → ③ 승인 준비(회원·가입·기사) → ④ 홍보 글 → ⑤ 문자·카톡
