## 3. 논의

### 3-1. 사장님 제안 — AI 쓰는 방법을 두 가지로

1. **내 계정으로** (지금 방식): 구독 중인 ChatGPT·Claude·Gemini 에 로그인해 두면, 스튜디오가 그 창을 띄워 글·그림을 받는다.
2. **내 API 키로** (추가): 회원이 자기 API 키를 등록하면, 스튜디오의 모든 AI 기능이 그 키로 돈다.

### 3-2. Claude 의견 (권고)

**추가하는 게 맞다. 키가 있으면 API 가 우선, 없으면 계정 방식.**

| | 내 계정으로 | 내 API 키로 |
|---|---|---|
| 돈 | 구독료 안에서 | 쓴 만큼 회원 카드로 결제 (AI 회사에 직접) |
| 속도·안정 | 창을 띄워 사람처럼 입력 — 느리고, AI 화면이 바뀌면 고장 | 바로 주고받음 — 빠르고 고장 적음 |
| 약관 | 개인 계정 자동 사용 제한 → 계정 정지 위험 | 정식 사용 방법 — 위험 없음 |
| 준비 | 로그인만 | 키 발급(카드 등록) 필요 — 60대 회원에겐 어려움 |

- **키 보관: 회원 PC 안에만**, 윈도우 암호화(Electron safeStorage)로. 공실뉴스 서버에 올리지 않는다 → 유출 책임 없음. 화면엔 `sk-…abcd` 처럼 끝 4자리만.
- **고르는 법**: [내 AI 연결] 창에서 AI 마다 [계정으로] / [API 키로]. 둘 다 있으면 API 키 우선.
- **[키 확인]** 단추: 등록할 때 짧게 한 번 불러 맞는 키인지 바로 알려 준다.
- **수정 요청 이어 쓰기**: API 에는 "대화 창 주소"가 없으므로, 처음 쓴 대화 내용을 PC 에 저장해 두고 이어서 보낸다.
- **그림**: ChatGPT 키·Gemini 키는 그림도 됨. Claude 키는 글쓰기만 (지금과 같음).
- **키 발급 안내**: AI 별로 "키 만드는 법" 사진 안내 + [발급 페이지 열기] 단추.

- AI 가 하나도 연결 안 된 채 AI 기능을 누르면 → 이 창을 바로 띄운다.

### 3-5. 위쪽 "기본 AI" 에서 방법까지 보이고 바로 바꾸기 — Claude 권고

사장님 지적: 기본 글쓰기 AI·기본 그림 AI 에서 **계정인지 API 인지 보이고, 거기서 바로 설정**할 수 있어야 한다. → 맞다. 두 곳에서 한다.

**① 맨 위 [AI 설정] 단추를 누르면 바로 아래로 작은 판이 펼쳐진다 (빠른 설정)**

```
 [● AI 설정 ▾]
 ┌────────────────────────────────────────┐
 │ 글쓰기  ChatGPT · API 키      [바꾸기 ▾] │
 │ 그림    Gemini · 내 계정      [바꾸기 ▾] │
 │ ────────────────────────────────────── │
 │ [자세히 설정]                            │
 └────────────────────────────────────────┘
 [바꾸기 ▾] → ChatGPT · API 키 ✓
              Claude · 내 계정 ✓
              Gemini · 연결 안 됨 → 누르면 그 AI 설정으로
```

**② [AI 설정] 창 위쪽 기본 AI 칸 — 단추마다 방법 표시**

```
 기본 글쓰기 AI  (ChatGPT·API ✓) (Claude·계정 ✓) (Gemini·연결 안 됨)
 기본 그림 AI    (ChatGPT·API ✓) (Gemini·연결 안 됨)
```

- 연결된 것만 고를 수 있다. "연결 안 됨" 을 누르면 아래 그 AI 줄로 내려가 열린다.
- 맨 위 파란 줄 단추 글자도 지금 쓰는 것: `● ChatGPT · API`

### 3-6. API 키 만드는 법 안내 페이지 — Claude 권고

- **웹 페이지로** 만든다 (앱 새 버전 없이 고칠 수 있게). 앱의 [만드는 법 보기] 가 이 페이지를 연다.
- 한 페이지, 위에 탭 [ChatGPT] [Claude] [Gemini]. 탭마다:
  1. 이 키로 되는 것 (글쓰기 / 그림)
  2. 돈은 어떻게 나가나 — 쓴 만큼, AI 회사에 직접. 금액은 적지 않고 각 회사 요금 페이지 링크 (가격이 자주 바뀜)
  3. 단계별 사진 안내: 가입·로그인 → 결제(충전) 등록 → 키 만들기 → 복사 → 스튜디오 [AI 설정]에 붙여넣기 → [키 확인]
  4. 꼭 할 것: 월 사용 한도 걸기, 키를 남에게 보여 주지 않기, 새 나가면 지우고 새로 만들기
- 사진은 실제 화면을 찍어서 쓴다. 이메일·키 값은 흐리게 (매뉴얼 영상 규칙과 같음).
- 발급 페이지 (확인 필요): ChatGPT `platform.openai.com/api-keys`, Claude `console.anthropic.com/settings/keys`, Gemini `aistudio.google.com/apikey`

### 3-7. 내 목소리로 성우 만들기 (무료 목소리 복제) — 조사

- 지금 성우: Gemini TTS (`src/app/api/studio/video/voice/route.ts`) — 정해진 목소리만, 내 목소리 복제 안 됨
- 무료·상업 사용 가능·한국어 되는 후보 (블로그 정리 기준, 공식 저장소에서 다시 확인 필요)
  - **Qwen3-TTS** (Apache 2.0): 3초 녹음으로 복제, 한국어 포함 10개 언어. 0.6B(약 2.5GB)·1.7B(약 4.5GB)
  - **OpenVoice V2** (MIT): 짧은 녹음으로 복제, 한국어 포함 6개 언어
  - 제외: F5-TTS·Voxtral(비상업), Fish Audio(상업 사용 별도 계약 여부 불분명)
- 무료 = 회원 PC 에서 직접 돌림. 그래픽카드 없는 PC 에서 쓸 만한 속도인지는 확인 안 됨
- Claude 권고: **Qwen3-TTS 를 먼저 사장님 PC 에서 사장님 목소리로 시험** → 한국어 품질·속도 보고 정함. 본인 목소리만 등록(남의 목소리 금지) 동의 문구 필요
