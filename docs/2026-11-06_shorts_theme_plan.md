# 쇼츠릴스 테마 — 단지소개 · 뉴스칼럼 테마 만들기 계획

작성일: 2026-11-06 · 상태: 회의 중 (만들기 전)

## 1. 목표

쇼츠 만들기 › ② 테마의 세 탭을 채운다.

| 탭 | 지금 | 목표 |
|---|---|---|
| 공실소개 | 기존 5개 (깔끔 남색 · 노랑 임팩트 · 고급 블랙·골드 · 상큼 민트 · 뉴스 속보) | 그대로 |
| 단지소개 | 비어 있음 ("준비 중") | **새 테마 5개** |
| 뉴스칼럼 | 비어 있음 ("준비 중") | **새 테마 5개** |

- 회원은 테마를 **누르기만** 하면 성우 · 자막 · 제목 상자 · 그래픽 · 전환 · 음악 · 끝 장면 표시광고가 한 번에 들어간다.
- 대본 종류에 따라 탭이 저절로 열린다. 공실 대본은 공실소개, 뉴스칼럼·자유 글쓰기 대본은 뉴스칼럼이 열린다. 단지소개는 회원이 직접 탭을 누른다.

## 2. 테마 하나에 들어가는 것

코드 위치: `src/components/admin/studio-video/webThemes.ts` (`ShortsTheme`), `webThemeKit.ts` (`ThemeKit`)

| # | 항목 | 내용 |
|---|---|---|
| 1 | 자막 | 글꼴 · 크기 · 색 · 테두리 · 자리 · 움직임 · 말하는 단어 강조색 |
| 2 | 제목 상자 | 첫 장면 위쪽 동네·종류 상자 (글꼴 · 색 · 상자 색 · 움직임) |
| 3 | 사무소 상자 | 마지막 사무소 이름 상자 |
| 4 | 그래픽 | 화면 글 장식 (예: "꼭 보세요"). **숫자가 든 글은 넣지 않는다** — 공실마다 다르기 때문 |
| 5 | 화면 전환 | 클립 사이 전환 종류 · 길이 · 휙 소리 |
| 6 | 음악 | 이미 있는 음악 목록(`SHORTS_MUSIC`)에서 |
| 7 | 성우 | 지금 쓰는 일레븐랩스 성우 목록에서 |
| 8 | 드론 자리 | 그 동네 공실뉴스 드론 영상을 넣을 클립 |
| 9 | 끝 장면 표시광고 | 모양만. 내용은 회원 실제 사무소 정보 (빈 값은 빈칸) |

## 3. 만드는 방법 — 권고: "편집기에서 만들고 저장"

이미 있는 기능을 쓴다. 지금 공실소개 기본 테마 5칸이 이 방식이다.

1. 최고관리자(또는 공실마케팅 계정)가 쇼츠 편집기에서 견본 영상을 직접 꾸민다.
2. [테마로 저장] › **[기본 테마 N으로 저장]** → 모든 회원의 그 테마가 그 모양으로 바뀐다.
   - 저장 위치: DB `agent_settings` 의 `shorts_themes`
   - 코드: `src/app/actions/shortsThemes.ts`
3. 코드에 있는 처음 모양은 저장된 것이 없을 때만 쓰인다.

**좋은 점**
- 눈으로 보며 고칠 수 있다.
- 코드를 다시 올리지 않아도 바로 바뀐다.

**해야 할 일 (코드)**
- 지금은 칸이 5개(`SLOTS = 5`)뿐이다. **15칸으로 늘리고**, 칸마다 탭(공실소개 · 단지소개 · 뉴스칼럼)을 정한다.
- 편집기 [기본 테마로 저장] 목록을 탭별로 나눈다.
- 새 10개 테마의 **처음 모양**(아래 4장 표)을 코드에 넣는다. 그 위에 편집기에서 다듬는다.

### 다른 방법 (권하지 않음)

- **코드로만 만들기:** 색·크기를 숫자로 적는다. 화면을 보며 고칠 수 없어서 몇 번씩 오가야 한다.
- **외부 디자이너에게 맡기기:** 테마 형식(자막·상자·그래픽 수치)을 따로 설명해야 한다. 나중에 맡길 일이 생기면 이 문서 2장을 넘긴다.

## 4. 새 테마 10개 — 처음 안

> 이름 · 색 · 음악 · 성우는 처음 안이다. 견본을 보고 사장님이 고른다.

테마마다 **다섯 가지를 모두 다르게** 한다 (2026-11-06 사장님: "자막 스타일부터 음악, 화면 전환, 그래픽부터 여러 가지로, 그리고 들어가는 화면").
같은 탭 안에서 색만 바뀌는 테마가 되지 않게 한다.

| 다르게 할 것 | 고를 수 있는 것 (이미 편집기에 있는 것) |
|---|---|
| 자막 스타일 | 자리(가운데 아래·아래·위) · 크기 · 테두리/상자 · 단어 강조(색·크기) · 나타나기(톡·위로·타자기·확대) |
| 음악 | `SHORTS_MUSIC` 15곡 (잔잔·경쾌·기업·피아노·어쿠스틱·칠·펑키·공개하듯 등) |
| 화면 전환 | 페이드 · 확대 · 밀기 · 휙 · 번쩍 · 블러 등 + 휙 소리 |
| 그래픽 | 형광펜 · 네온 · 말풍선 · 딱지 · 띠 등 모양 + 숫자 없는 문구 |
| 들어가는 화면 | 첫 장면 · 가운데 장면 차례 · 끝 장면에 무엇을 넣는지 (아래 "화면 차례") |

### 단지소개 — 차분하고 믿음 가는 쪽

| # | 이름 | 자막 스타일 | 음악 | 화면 전환 | 그래픽 | 들어가는 화면 (차례) |
|---|---|---|---|---|---|---|
| 1 | 프리미엄 네이비·골드 | 가운데 아래 · 흰 글씨 + 금색 단어 강조 · 톡 | 잔잔한 피아노 | 느린 페이드 | 금색 띠 "단지 한눈에" | 단지 외관 → 드론 → 실내 사진 → 끝 장면 |
| 2 | 화이트 미니멀 | 아래 · 흰 상자에 검정 글씨 · 위로 | 깔끔한 기업 | 밀기 | 얇은 선 딱지 "생활권 체크" | 지도 캡처 → 단지 외관 → 실내 → 끝 장면 |
| 3 | 그린 라이프 | 가운데 아래 · 초록 단어 강조 · 확대 | 어쿠스틱 기타 | 확대 + 페이드 | 말풍선 "살기 좋은 동네" | 드론 → 공원·주변 → 단지 외관 → 끝 장면 |
| 4 | 시티 나이트 | 가운데 · 큰 글씨 + 하늘색 네온 · 번쩍 | 칠 바이브 | 휙 + 소리 | 네온 "역세권 단지" | 단지 외관 → 지도(역) → 실내 → 끝 장면 |
| 5 | 시세 브리핑 | 위 · 파란 상자 · 타자기 | 경쾌하게 | 컷(빠르게) | 그래프 딱지 "최근 실거래" | 실거래 화면 캡처 → 단지 외관 → 실내 → 끝 장면 |

### 뉴스칼럼 — 뉴스 방송 쪽

| # | 이름 | 자막 스타일 | 음악 | 화면 전환 | 그래픽 | 들어가는 화면 (차례) |
|---|---|---|---|---|---|---|
| 1 | 속보 레드 | 아래 빨간 띠 · 흰 글씨 · 밀려 들어오기 | 공개하듯 (긴장감) | 번쩍 + 소리 | 빨간 "속보" 딱지 (첫 3초) | 기사 제목 화면 → 기사 사진 → 핵심 문장 → 끝 장면 |
| 2 | 뉴스룸 네이비 | 아래 남색 자막 띠 · 방송 뉴스 모양 | 깔끔한 기업 | 밀기 | 남색 머리표 "오늘의 부동산" | 머리표 화면 → 기사 사진 → 칼럼 화면 캡처 → 끝 장면 |
| 3 | 칼럼 크림 | 가운데 · 아이보리 상자 + 명조체 · 페이드 | 잔잔하게 | 느린 페이드 | 신문 오려 붙인 모양 "칼럼" | 제목 카드 → 기사 사진 → 인용 문장 카드 → 끝 장면 |
| 4 | 이슈 옐로 | 가운데 아래 · 노란 형광펜 단어 강조 · 톡 | 펑키 비트 | 휙 + 확대 | 형광펜 "지금 이슈" | 질문 한 줄 화면 → 기사 사진 → 핵심 정리 → 끝 장면 |
| 5 | 데이터 브리핑 | 위 · 검정 상자 + 민트 숫자 강조 · 타자기 | 굿 바이브 | 컷(빠르게) | 민트 딱지 "핵심 정리" | 숫자 강조 화면 → 차트·캡처 → 기사 사진 → 끝 장면 |

**들어갈 수 있는 화면 재료**

| 재료 | 어디서 오나 | 쓰는 테마 |
|---|---|---|
| 공실·단지 사진 | 등록 사진 | 전부 |
| 첨부 화면 (캡처) | 지도 · 로드뷰 · 실거래 화면 · 공실열람 검증 화면 · 칼럼 "사진·화면" | 단지소개 2·4·5, 뉴스칼럼 2·5 |
| 드론 영상 | 공실뉴스 드론 자료 (그 동네) | 단지소개 1·3 (+ 원하면 전부) |
| 기사 화면 · 기사 사진 | 내 공실뉴스 기사 · 칼럼 | 뉴스칼럼 전부 |
| 글 카드 | 제목 · 인용 문장 · 질문 한 줄 (대본에서) | 뉴스칼럼 1·3·4 |
| NEWS 딱지 (말머리) | 메인자막 위 왼쪽에 붙어 자막과 같이 움직이는 작은 글 ("NEWS" · "속보" · "단독"). 편집기 자막 설정의 **[말머리]** (`look.tag` · `look.tagColor`). 앱 대본 마법사는 뉴스 자막에 늘 붙였는데, **웹 테마에는 안 옮겨져 있음** | **단지소개 전부 · 뉴스칼럼 전부** (기본 "NEWS") — 사장님: "단지뉴스 할 때 좋았던 것 같아서" |

> NEWS 딱지: 편집기 미리보기(`Player.tsx`)는 말머리를 그린다. 웹 테마 `sub` 에 `tag: "NEWS", tagColor` 만 넣으면 된다. 웹 [내보내기] 결과에도 나오는지는 만들 때 한 번 확인한다.

**화면 차례 메모**
- "끝 장면"은 모든 테마 공통이다. 상호 · 연락처 + 부동산 표시광고를 넣는다.
- 숫자를 보여 주는 화면(실거래 · 숫자 강조)은 **자료에 있는 숫자만** 쓴다. 없으면 그 화면을 건너뛴다.
- 사진이 모자라면 있는 사진을 차례대로 다시 쓴다.

## 5. 지킬 원칙

- **가짜 숫자 금지:** 테마 그래픽에는 숫자를 넣지 않는다. 세대수 · 준공 · 시세 같은 숫자는 대본·자료에 있는 것만 자막으로 나온다.
- **부동산 표시광고:** 끝 장면은 회원 실제 사무소 정보로만 채운다. 없으면 빈칸으로 둔다.
- **공실소개 5개는 그대로:** 새 테마는 단지소개 · 뉴스칼럼 탭에만 더한다.
- **성우 포인트:** 테마를 바꿔도 성우 요금은 그대로다 (1자 1P).
