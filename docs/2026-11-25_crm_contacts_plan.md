## 2. 지킬 것 — 문자는 보내도 되는 사람에게만

- 광고 문자는 **미리 동의**했거나 **거래가 끝난 지 6개월 안**인 사람에게만 (정보통신망법 50조). 동의를 묻는 첫 문자도 광고로 본다
- 그래서 카드마다 **문자 상태** 칸 하나로 막는다. 문자 화면은 `보냄 가능` 만 고를 수 있다 — 10만 명에게 잘못 나가는 일을 구조로 막음
- 광고 문자에는 `(광고)` · 회사 이름·연락처 · 무료 수신거부 080. 밤 9시~아침 8시 안 보냄. 월 2번까지
- 수신거부 한 번이면 어느 명단에서 왔든 다시 안 나간다
- 전국 명단(동의 없음)은 **문자 금지** — 우편 엽서 DM · 광고 지역 고르기 · 기사 자료로만

## 3. DB — Supabase 안에 `crm` 칸막이

공실뉴스 회원 표와 같은 DB 라서 가입·등급·결제가 **자동 연결**된다. 이름부터 `crm.` 으로 나눠 회원 화면과 섞이지 않게. 웹 화면이 직접 읽지 못하게 잠그고 최고관리자 서버 기능(service role)만 읽고 쓴다 — `message_logs` 와 같은 방식

### 3-1. `crm.contacts` — 사람 카드 (휴대폰 하나 = 한 줄)
| 칸 | 내용 |
|---|---|
| `phone` | `01012345678` 한 모양으로 (유일) |
| `name` · `office_name` | 이름 · 상호 |
| `sido` · `sigungu` · `address` | 지역 |
| `sms_status` | `보냄가능` · `확인전` · `보내지않음` · `수신거부` |
| `member_id` | 공실뉴스 가입했으면 `members.id` (자동) |
| `member_grade` | 부동산회원(무료) · 공실뉴스부동산(유료) · 비즈니스회원 · 일반회원 · 없음 (자동) |
| `paid_until` | 공실뉴스부동산 만기 (자동) |
| `last_sent_at` · `last_reaction_at` | 마지막으로 보낸 때 · 마지막 반응 |
| `memo` | 짧은 메모 |

### 3-2. `crm.contact_tags` — 특징 꼬리표 (한 사람에 여러 개)
- 출처 꼬리표는 가져올 때 자동: `공실닷컴` · `공실닷컴_이용중` · `공실닷컴_인증` · `전국명단` · `교육참여`
- 사장님이 화면에서 새 꼬리표를 만들고 붙인다 (예: `VIP` · `강의문의` · `전화함`)

### 3-3. `crm.contact_events` — 있었던 일 (날짜순으로 쌓임)
| 종류 | 기록 |
|---|---|
| 문자 보냄 | 자동 — 보내는 순간 (캠페인 번호와 함께) |
| 링크 누름 | 자동 — 사람마다 다른 짧은 링크 |
| 공실뉴스 가입 · 등급 바뀜 · 결제 · 만기 끝남 | 자동 — 회원 정보에서 |
| 수신거부 | 080 거부 목록 받아 반영 + 손으로 |
| 답장 · 전화 · 메모 | 손으로 (답장 자동 받기는 나중) |

### 3-4. `crm.campaigns` — 보낸 문자 한 번의 묶음
- 이름(예: "11월 사전모집 1차") · 보낸 글 · 고른 조건 · 보낸 수 · 누른 수 · 가입 수 · 결제 수
- 기존 `message_logs` 와 연결 (보낸 기록은 지금 표 그대로 쓰고 칸만 더함)

### 크기
카드 약 10만 7천 장. 있었던 일은 1년 수십만 줄 — 지금 Supabase 요금제로 충분

## 4. 단계 (사람이 어디쯤 있나)

```
모르는 부동산 ─▶ 공실뉴스 가입(무료) ─▶ 공실뉴스부동산(유료) ─▶ 만기 30일 안 ─▶ 끝남
```
[고객관리] 맨 위에 단계별 숫자. 누르면 그 사람들 목록. 단계마다 보낼 글이 다르다
- 가입 안 함: 가입 안내 (동의·거래 관계 있는 사람만)
- 무료: 공실뉴스부동산 혜택
- 유료: 사용 팁·새 기능 (안내 문자)
- 만기 30일 안: 연장 안내

## 5. 화면 — 최고관리자 왼쪽 메뉴 [고객관리] (회원에게 연락 묶음)

- **목록**: 꼬리표 · 지역 · 문자 상태 · 단계 · 마지막 반응으로 거르기. 번호는 `010-****-5678`
- **카드**: 꼬리표 · 자동 칸 · 있었던 일 전체 · 메모 쓰기. 카드 열 때만 전체 번호
- **보내기**: 거른 목록 → [문자·카톡 보내기] 로 넘김 (`보냄가능` 만 넘어감)
- **결과**: 캠페인마다 보냄 → 누름 → 가입 → 결제
- **내려받기**: 한 달 한 번 엑셀 백업 단추

## 6. 가져오기 (엑셀 → DB)

1. 번호 맞추기 — 하이픈·괄호 지우고 `01` 로 시작 10~11자리만 휴대폰으로
2. 같은 번호 한 줄로 합치고 출처 꼬리표 모두 붙임
3. 공실뉴스 `members` 번호 · `agencies` 등록번호와 맞춰 가입·등급 채움
4. 문자 상태 자동 배정 (아래 표)
5. **넣기 전에 결과 표를 사장님께 먼저** — 단계별 · 꼬리표별 수 · 이상한 번호 수 · 겹친 수
6. 사장님 확인 뒤 넣음. 프로그램은 엑셀을 프로젝트 밖에서 읽고 중간 파일을 남기지 않는다

## 6-2. 반응 없는 사람 (2026-11-25 사장님 질문)

반응 = 링크 누름 · 답장 · 전화 · 가입 · 결제. 문자 보낼 때마다 `no_reply_streak` +1, 반응 오면 0
- **3번 연속 반응 없음** → `쉬는중` 90일 (`rest_until`). 그동안 보내기 목록에서 자동으로 빠짐 — 스팸 신고·비용 줄이기
- 쉬는중 끝나면 `보냄가능` 으로 돌아와 1번 더 → 또 없으면 다시 쉬는중
- **문자 실패(없는 번호) 2번** → `번호오류`, 다시 안 보냄
- **수신거부** → 영원히 안 보냄 (080 거부 · 답장 "거부" · 손으로)
- [고객관리] 결과 화면에 캠페인마다 "반응 없음" 수와 쉬는중 인원을 보여 줌
