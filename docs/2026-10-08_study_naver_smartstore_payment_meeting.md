# 공실스터디 네이버 스마트스토어 결제·자동 권한 반영 회의 정리

**작성일:** 2026년 10월 8일 (목)
**상태:** 구현 전 설계안
**주제:** 공실스터디 결제를 네이버 스마트스토어에서 받고, 결제 완료 시 공실뉴스 회원 권한을 자동으로 반영한다

---

## 1. 목표

- 공실스터디 1년 이용권 결제는 네이버 스마트스토어·네이버페이에서 처리한다.
- 결제가 완료되면 관리자가 일일이 승인하지 않아도 공실뉴스의 `study_premium` 권한을 자동으로 부여한다.
- 정상 결제는 자동 처리하고, 회원을 찾지 못한 예외 주문만 최고관리자가 확인한다.
- 재결제, 중복 수신, 취소, 반품까지 안전하게 처리한다.

---

## 2. 기본 원칙

> **네이버는 결제와 주문을 담당하고, 공실뉴스는 회원 계정과 이용 권한을 관리한다.**

스마트스토어 주문 상태가 공실뉴스 회원 권한의 근거가 되지만, 실제 강의·기능 접근 권한은
기존 `members.plan_type`, `plan_start_date`, `plan_end_date`로 관리한다.

---

## 3. 사용자 흐름

```text
공실뉴스 로그인
    ↓
[네이버페이로 결제하기]
    ↓
회원 ID·이름·휴대폰·상품번호를 결제대기로 저장
    ↓
네이버 스마트스토어에서 결제
    ↓
공실뉴스 서버가 네이버 결제완료 주문 확인
    ↓
상품번호·결제상태·금액·회원 연락처 검증
    ↓
공실스터디 365일 권한 자동 부여
    ↓
신청 상태 승인완료 + 안내 문자 발송
```

자동 연결에 실패한 주문은 결제를 무효로 만들지 않고 `회원 연결 필요` 상태로 관리자에게
보여준다. 구매자가 네이버 상품주문번호를 입력하면 서버가 네이버 API로 실제 주문을 다시
검증한 뒤 해당 회원에게 연결할 수 있게 한다.

## 4. 현재 코드에서 활용할 부분

### 4-1. 신청서

- `src/app/actions/studyApply.ts`
- 공실스터디 신청을 `newsrealty_applications`에 `service='study'`로 저장한다.
- 신청서에 `member_id`, 신청자명, 휴대폰, 이메일, 중개사무소명이 들어간다.

### 4-2. 회원권 부여

- `src/app/actions/newsrealtyApply.ts`
- 현재는 관리자가 신청 상태를 `승인완료`로 바꾸면 `study_premium` 1년 권한을 부여한다.
- 이 권한 부여 로직을 관리자 화면 전용 코드에서 분리해 네이버 결제 동기화 작업도 함께
  사용할 수 있도록 해야 한다.

### 4-3. 결제 버튼

- PC: `src/app/(main)/study/apply/StudyApplyClient.tsx`
- PC 화면에는 `네이버결제` 버튼 자리가 있으나 현재 URL이 비어 있어 준비 중 안내가 나온다.
- 모바일: `src/app/m/study/apply/MobileStudyApplyClient.tsx`
- 모바일에는 동일한 네이버결제 진입 버튼을 새로 추가해야 한다.

### 4-4. 자동 실행 기반

- `vercel.json`
- 기존에도 `/api/cron/*` 경로를 Vercel Cron으로 실행하고 있으므로 같은 구조로 네이버 주문
  동기화 작업을 추가할 수 있다.

## 5. 서버 구성안

### 5-1. 네이버 커머스API 모듈

서버 전용 모듈에서 다음 기능을 담당한다.

1. OAuth2 인증 토큰 발급·갱신
2. 마지막 확인 시점 이후 변경된 상품주문 조회
3. 상품주문 상세정보 조회
4. 발주 확인
5. 배송없음 상품 발송 처리

`client_id`, `client_secret`은 브라우저나 저장소에 노출하지 않고 배포 환경변수에만 둔다.

### 5-2. 주문 동기화 크론

예정 경로:

```text
/api/cron/naver-orders
```

권장 실행 간격은 1~5분이다. 배포 요금제나 크론 제한상 더 짧게 실행하기 어렵다면 10분
주기로 시작할 수 있다. 크론은 마지막 동기화 위치를 저장하고 다음 실행에서 이어서 읽는다.

### 5-3. 원자적 권한 반영

결제 저장과 회원권 부여는 하나의 DB 함수 또는 트랜잭션으로 처리한다.

- 같은 네이버 상품주문번호는 한 번만 반영
- 중간 오류가 발생하면 전체를 되돌림
- 크론이 같은 주문을 다시 받아도 기간이 중복 연장되지 않음
- 성공 후 문자 발송이 실패해도 결제와 권한은 유지하고 문자만 재시도

## 6. 데이터 구조안

신청서와 실제 결제는 분리한다. 한 회원이 갱신할 때마다 새로운 결제가 생기기 때문이다.

### `membership_payments`

| 필드 | 용도 |
|---|---|
| `id` | 내부 결제 ID |
| `provider` | `NAVER_SMARTSTORE` |
| `service` | `study` |
| `member_id` | 연결된 공실뉴스 회원 |
| `order_id` | 네이버 주문번호 |
| `product_order_id` | 네이버 상품주문번호, `UNIQUE` |
| `product_id` | 네이버 상품번호 |
| `amount` | 실제 결제금액 |
| `status` | 결제완료·취소·반품 등의 내부 상태 |
| `paid_at` | 결제 완료 시각 |
| `granted_at` | 회원권 부여 시각 |
| `cancelled_at` | 취소 완료 시각 |
| `refunded_at` | 반품·환불 완료 시각 |
| `match_method` | 휴대폰 자동 일치·주문번호 확인·관리자 연결 |
| `created_at`, `updated_at` | 생성·수정 시각 |

### `naver_order_sync_state`

- 마지막으로 확인한 변경 시각
- 네이버 페이지 이어보기 값
- 마지막 성공 시각
- 마지막 오류 내용

네이버 전체 주문 응답과 불필요한 개인정보는 저장하지 않고 운영에 필요한 값만 보관한다.

---

## 7. 회원 연결 규칙

1. 공실뉴스에서 결제 버튼을 누른 로그인 회원을 우선 후보로 저장한다.
2. 네이버 주문의 휴대폰 번호를 숫자만 남겨 비교한다.
3. 상품번호, 결제금액, 결제완료 상태가 모두 맞아야 한다.
4. 이름과 휴대폰이 유일하게 일치하면 자동 승인한다.
5. 다른 연락처, 가족 명의, 선물 주문 등은 자동 승인하지 않고 관리자 확인으로 보낸다.
6. 사용자가 주문번호를 제출해도 그 값만 믿지 않고 네이버 API에서 실제 주문을 검증한다.
7. 하나의 상품주문번호를 여러 회원에게 연결할 수 없게 한다.

---

## 8. 회원권 기간 규칙

| 상황 | 처리 |
|---|---|
| 처음 결제 | 결제 시점부터 365일 |
| 기존 기간 만료 후 재결제 | 재결제 시점부터 365일 |
| 이용 기간 중 재결제 | 기존 만료일 다음 시점부터 365일 연장 |
| 동일 주문 재수신 | 무시, 중복 연장 금지 |
| 취소·반품 요청 중 | 권한 유지, 관리자 확인 표시 |
| 취소·반품 완료 | 해당 결제를 제외하고 이용 기간 재계산 |

현재 권한 부여 코드는 이미 `study_premium`인 회원을 그대로 두므로, 재결제 시 기존 만료일을
기준으로 365일 연장하도록 수정해야 한다.

---

## 9. 네이버 주문 상태별 처리

| 네이버 상태 | 공실뉴스 처리 |
|---|---|
| `PAYED` | 주문 검증 후 결제 저장 및 권한 부여 |
| `CANCEL_REQUEST` | 즉시 회수하지 않고 확인 필요 표시 |
| `CANCELED` | 취소 완료 기록 및 이용 기간 재계산 |
| `RETURN_REQUEST` | 즉시 회수하지 않고 확인 필요 표시 |
| `RETURNED` | 환불 완료 기록 및 이용 기간 재계산 |
| `PURCHASE_DECIDED` | 구매확정 시각 기록 |
| 이미 처리한 주문 | 안전하게 무시 |

취소 또는 반품의 **요청 단계**에서 바로 권한을 끊지 않는다. 요청이 철회될 수 있으므로 실제
완료 상태가 확인된 뒤 처리한다.

## 10. 스마트스토어 상품 운영 원칙

- 상품 형태: `공실스터디 1년 온라인 이용권`
- 가격: 현재 기획 기준 360,000원
- 배송 형태: 온라인 이용권/E쿠폰 성격의 **`배송없음` 상품**으로 설정
- 상품 상세에 공실뉴스 계정이 필요하다는 점과 이용 방법을 명시
- 결제 후 공실뉴스 회원 연락처와 구매자 연락처가 같아야 자동 연결된다는 점을 안내
- 권한 부여가 완료되면 네이버 주문도 정해진 발송기한 안에 발송 처리

스마트스토어 정책상 동영상 강의는 e쿠폰·모바일상품권 형태의 강의 이용권으로 판매 가능한지
상품 등록 단계에서 최종 확인한다. 공실스터디의 부가 기능이 함께 묶여 있으므로 실제 상품
분류와 상세 설명은 판매자센터 기준에 맞춘다.

### 10-1. 실물 배송과 송장번호는 사용하지 않는다

공실스터디는 실물 상품이 아니라 회원 이용권이므로 택배 배송완료를 만들 필요가 없다.

- 택배사 선택 없음
- 송장번호 입력 없음
- 가짜 송장번호 등록 금지
- 고객 주소로 발송하지 않음
- 네이버 주문 관리상 필요한 `발주확인`과 `발송처리`만 수행
- API 발송 방식은 배송이 없음을 뜻하는 `deliveryMethod: NOTHING` 사용

고객에게는 다음과 같이 안내한다.

> 본 상품은 실물 배송이 없는 공실스터디 온라인 이용권입니다. 결제 확인 후 공실뉴스
> 계정에 이용 권한이 자동 부여됩니다.

### 10-2. 배송없는 상품의 주문 처리 순서

```text
네이버 결제완료(PAYED)
    ↓
공실뉴스 회원·상품·금액 검증
    ↓
공실스터디 365일 권한 부여
    ↓
권한 부여 성공 확인
    ↓
네이버 주문 발주확인
    ↓
deliveryMethod: NOTHING으로 발송처리
    ↓
구매확정 대기
```

가장 중요한 순서는 **회원권 부여가 먼저, 네이버 발송처리가 나중**이라는 점이다. 회원권
부여에 실패했는데 주문부터 발송 처리하면 고객은 발송되었다는 표시를 보면서 서비스를 쓰지
못하는 상황이 생긴다.

| 처리 결과 | 네이버 주문 처리 |
|---|---|
| 회원권 부여 성공 | 즉시 발주확인 후 배송없음 발송처리 |
| 회원권 부여 일시 실패 | 발송하지 않고 다음 동기화에서 재시도 |
| 회원 자동 연결 실패 | `회원 연결 필요`로 보류하고 발송하지 않음 |
| 이미 처리한 주문 재수신 | 권한을 중복 연장하지 않고 기존 발송 상태 확인 |

### 10-3. 구매확정과 발송기한

배송없는 상품도 네이버 주문 관리에서는 발송처리가 필요하다. 스마트스토어 공식 안내 기준으로
배송없음 상품은 송장번호 없이 발송할 수 있고, 발송처리 후 구매자가 직접 구매확정하지 않으면
8일째 자동 구매확정된다.

결제 완료 주문을 발송하지 않은 채 두면 발송지연 페널티가 생길 수 있으므로, 정상적으로
회원권을 부여한 주문은 같은 자동 처리 안에서 발송까지 끝낸다. 구매확정은 공실뉴스 회원권의
시작 조건으로 사용하지 않는다. 회원권은 `PAYED` 확인과 검증이 끝난 시점부터 이용할 수 있게
한다.

### 10-4. 취소·반품과 회원권 처리

- 발송 전 취소가 완료되면 회원권을 부여하지 않거나 이미 부여한 기간을 재계산한다.
- 배송없음 발송처리 후 취소·반품이 요청되면 즉시 권한을 끊지 않고 완료 상태를 기다린다.
- 실제 `CANCELED` 또는 `RETURNED`가 확인되면 해당 결제를 제외해 회원권 기간을 재계산한다.
- 단순 요청이나 구매확정 보류 상태만으로는 권한을 회수하지 않는다.
- 환불 정책과 이미 사용한 온라인 콘텐츠의 처리 기준은 스마트스토어 상품 상세와 공실뉴스
  안내에 같은 내용으로 표시한다.

## 12. 기존 안내 문구 점검

스마트스토어 결제로 전환할 때 다음 문구를 함께 수정한다.

- `매월 전자세금계산서 자동 발행` 문구 제거 또는 네이버 결제 증빙 기준으로 변경
- 카드 무이자 할부 개월 수를 고정 보장하지 않음
- `네이버페이에서 제공되는 결제수단과 할부 이용 가능`처럼 실제 결제창 기준으로 안내
- 취소·환불 조건과 디지털 콘텐츠 이용 개시 후 정책을 상품 상세와 공실뉴스에 동일하게 표시

## 14. 구현 전 필요한 정보

- 스마트스토어 상품 URL
- 네이버 상품번호
- 정상 판매가격과 할인·쿠폰 허용 범위
- 네이버 커머스API `client_id`, `client_secret`
- 자동 확인 주기: 1분, 5분 또는 10분
- 연락처 불일치 주문을 처리할 최고관리자 운영 방법
- 취소·반품 완료 시 이미 사용한 기간을 어떻게 처리할지에 대한 최종 환불 원칙

비밀키는 문서·소스코드·브라우저 환경변수에 기록하지 않고 배포 서버의 비밀 환경변수로만
관리한다.

## 16. 현재 결론

공실스터디 결제를 네이버 스마트스토어에서 받고 자동으로 권한을 부여하는 것은 가능하다.
권장안은 **1~5분 주기의 주문 자동 확인, 휴대폰·상품정보가 일치하는 결제의 자동 승인,
일치하지 않는 주문만 관리자 확인**이다.

아직 구현을 시작하지 않았으며, 스마트스토어 상품 URL·상품번호와 커머스API 자격정보가
준비되면 위 순서로 진행한다.
