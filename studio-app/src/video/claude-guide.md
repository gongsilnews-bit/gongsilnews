# 공실마케팅 영상 JSON — AI(클로드)용 설명서

이 폴더(`문서\공실스튜디오\05 동영상제작\AI받기`)에 아래 형식의 `.json` 파일을 저장하면,
공실마케팅 앱의 **동영상제작 › 가져오기**에 나타나고, 누르면 영상 편집기 프로젝트로 열립니다.
사용자는 그 뒤 앱에서 AI 성우·자막·화면 꾸미기를 마무리하고 유튜브·인스타그램에 올립니다.

캡컷 프로젝트 폴더(안에 `draft_content.json`)를 이 폴더에 넣어도 가져올 수 있습니다.
하지만 새로 만든다면 **이 형식을 쓰세요** — 더 간단하고, 공실 사진·AI 성우를 바로 쓸 수 있습니다.

## 규칙

- 파일 하나 = 영상 하나. UTF-8 JSON. 반드시 `"format": "gongsil-video"`, `"version": 1`.
- 시간은 모두 **초** (소수 가능). 영상 전체 시간은 `clips` 를 차례로 이은 길이입니다.
- 파일 경로는 절대 경로(`C:\\...`) 또는 이 JSON 파일 기준 상대 경로. 없는 파일은 빠지고 사용자에게 알려 줍니다.
- 공실 사진: `"vacancy"` 에 공실번호(예: `"92199"`)를 적으면 `"file": "vacancy:1"` 처럼 그 공실의 분석 사진을 순서 번호로 씁니다
  (사용자가 앱에서 그 공실을 [분석·캡처]해 둔 사진: 등록 사진 → 넣은 AI 사진·내 사진 → 공실열람 검증·지도·로드뷰 화면).
- 모르는 값을 지어내지 마세요. 가격·면적 같은 매물 정보는 사용자가 준 것만 글자로 넣습니다.

## 형식

```json
{
  "format": "gongsil-video",
  "version": 1,
  "name": "논현동 빌라 매매 20억 소개",
  "ratio": "9:16",
  "vacancy": "92199",
  "voice": "Charon",
  "subtitles": true,
  "clips": [
    { "file": "vacancy:1", "say": "강남 논현동, 방 세 개 빌라가 매매로 나왔습니다." },
    { "file": "vacancy:2", "seconds": 3 },
    { "file": "C:\\Users\\me\\Videos\\walk.mp4", "from": 12.5, "to": 18 },
    { "file": "C:\\Users\\me\\Videos\\interview.mp4", "from": 0, "to": 9.2, "audio": true },
    { "blank": 1 }
  ],
  "texts": [
    { "text": "매매 20억", "start": 0, "end": 4, "position": "top", "size": 140, "color": "#FFFFFF" },
    { "text": "공실뉴스에서 자세히", "start": 14, "end": 18, "x": 0.5, "y": 0.8, "size": 90 }
  ],
  "music": [
    { "file": "C:\\Users\\me\\Music\\calm.mp3", "start": 0, "volume": 0.25, "loop": true }
  ],
  "overlays": [
    { "file": "C:\\Users\\me\\Pictures\\logo.png", "start": 0, "end": 18, "x": 0.88, "y": 0.08, "width": 0.18 }
  ]
}
```

### 맨 위

| 이름 | 뜻 |
|---|---|
| `name` | 프로젝트 이름 (파일 이름이 됩니다) |
| `ratio` | `"16:9"` 가로 · `"9:16"` 쇼츠·릴스 · `"1:1"` · `"4:5"` · `"4:3"` |
| `vacancy` | 공실번호 (없어도 됨) — `vacancy:N` 사진을 쓰려면 필요 |
| `voice` | AI 성우 (없으면 앱 기본). 예: `Charon` `Kore` `Puck` |
| `subtitles` | 메인자막 켜기 (기본 `true`) |

### clips — 영상의 큰 줄기 (차례대로 이어 붙음)

한 칸은 아래 중 하나입니다.

- **말하는 칸** `{ "file": "...", "say": "문장" }` — 화면에 그 사진·영상을 깔고, AI 성우가 `say` 를 읽습니다. 길이는 읽는 시간.
  목소리는 사용자가 앱에서 [목소리 만들기]를 누르면 생깁니다. 한 칸에 한두 문장이 좋습니다.
- **사진 칸** `{ "file": "사진", "seconds": 3 }` — 그 사진을 3초 보여 줍니다 (사진은 앱이 천천히 움직여 줍니다).
- **영상 칸** `{ "file": "영상", "from": 12.5, "to": 18 }` — 영상의 12.5초~18초 구간.
  `"audio": true`(기본)면 영상 자기 소리를 씁니다. 소리 없이 화면만 쓰려면 `"audio": false`.
  `"speed": 1.5` 빠르게, `"volume": 0.5` 소리 줄이기.
- **빈 칸** `{ "blank": 1 }` — 1초 검은 화면.

### texts — 화면 글자

| 이름 | 뜻 |
|---|---|
| `text` | 글자 |
| `start` · `end` | 나타나는 때 · 사라지는 때 (초, 영상 전체 기준). `end` 가 없으면 끝까지 |
| `position` | `"top"` · `"middle"` · `"bottom"` — 또는 `x`·`y` (0~1, 가운데 기준 자리) |
| `size` | 100 = 기본 크기 |
| `color` | `#RRGGBB` |
| `bold` | 굵게 (기본 `true`) |

### music — 배경 음악·소리

`file`, `start`·`end`(초), `volume`(0~1, 배경 음악은 0.2~0.3), `from`(음악 파일 안 시작 초), `loop`(모자라면 반복, 기본 `true`).

### overlays — 화면 위 사진·영상 (로고·작은 화면)

`file`, `start`·`end`, `x`·`y`(가운데 자리 0~1), `width`(화면 폭 비율 0~1), `from`(영상이면 시작 초).

## 잘 만드는 요령

- 부동산 소개 영상은 30~60초. 첫 칸에서 위치·물건 종류·가격을 말하고, 마지막 칸은 "공실뉴스에서 자세히 보세요".
- 공실 사진(`vacancy:N`)을 먼저 쓰고, 지도·로드뷰 화면은 위치를 말하는 문장에 둡니다.
- 쇼츠·릴스(`9:16`)는 글자를 화면 위쪽·가운데에 두세요 (아래쪽은 앱 단추에 가려집니다).
- 저장한 뒤 사용자에게 "앱의 동영상제작 › 가져오기에서 열어 보세요"라고 알려 주세요.
