AI 설정

기사·블로그·SNS·유튜브·영상을 쓸 AI를 고르세요. AI마다 쓰는 방법을 하나 고릅니다.
내 계정으로 — 구독 중인 AI에 스튜디오 전용 크롬에서 로그인해 두면, 그 창으로 씁니다. (평소 크롬과 따로, 처음 한 번 로그인)
API 키로 — 내 API 키를 넣으면 창 없이 바로 주고받아 빠르고 안정적이에요. 쓴 만큼 AI 회사에 직접 결제되고, 키는 이 PC에만 잠가서 저장돼요 (공실뉴스로 보내지 않음).

내 계정으로: AI 회사 약관은 개인 계정의 자동 사용을 제한하고 있어, 계정이 제한될 수 있습니다. 스튜디오는 소장님이 버튼을 누를 때만 한 건씩 사람처럼 작성합니다. Gemini는 업무용 구글 계정 말고 별도 계정을 권합니다.
API 키로: 각 AI 사이트 결제 화면에서 월 사용 한도를 꼭 걸어 두세요. 키는 남에게 보여 주지 말고, 새 나갔으면 그 사이트에서 지우고 새로 만드세요.
